# 번들 핫픽 E2E 테스트 체크리스트

## 번들 인트로 (`/bundle/[slug]`)

### 렌더링

- [ ] 번들 타이틀이 표시된다
- [ ] 카테고리 배지가 표시된다
- [ ] 질문 수 메타 정보가 표시된다
- [ ] 참여자 수 메타 정보가 표시된다
- [ ] CTA 버튼 "시작하기"가 표시된다
- [ ] 1:1 케미 비교 미리보기 카드가 표시된다
- [ ] 그룹 케미 비교 미리보기 카드가 표시된다

### 상태별 CTA

- [ ] 미완료 번들: CTA 텍스트 "시작하기"
- [ ] 완료 번들: CTA 텍스트 "결과 보기"
- [ ] 마감 번들: CTA "마감된 번들입니다" + disabled

### 네비게이션

- [ ] "시작하기" 클릭 → `/bundle/[slug]/play` 이동
- [ ] "결과 보기" 클릭 → `/bundle/[slug]/result` 이동

### 로딩/에러

- [ ] 로딩 중 스켈레톤 표시
- [ ] 존재하지 않는 slug 진입 시 에러 표시

---

## 번들 플레이 (`/bundle/[slug]/play`)

### 렌더링

- [ ] 프로그레스 바가 표시된다
- [ ] 진행률 라벨 "1 / 5" 형식으로 표시
- [ ] 질문 번호 "Q1" 형식으로 표시
- [ ] 질문 텍스트가 표시된다
- [ ] 옵션 A, B 버튼이 표시된다
- [ ] "or" 구분자가 표시된다

### 투표 흐름

- [ ] 옵션 A 클릭 → 선택 상태 표시 → 다음 질문 자동 이동
- [ ] 옵션 B 클릭 → 선택 상태 표시 → 다음 질문 자동 이동
- [ ] 마지막 질문 답변 후 "결과 보기" 제출 버튼 표시
- [ ] 뒤로가기 버튼 클릭 → 이전 질문 이동
- [ ] 이전 질문의 선택이 유지됨

### 제출

- [ ] 모든 질문 답변 후 "결과 보기" 클릭 → 결과 페이지 이동
- [ ] 제출 중 "제출 중..." 텍스트 + 버튼 비활성화
- [ ] 미답변 질문 있으면 제출 버튼 비활성화

### 로딩

- [ ] 질문 로딩 중 스피너 표시

---

## 번들 결과 (`/bundle/[slug]/result`)

### 렌더링

- [ ] 결과 타이틀이 표시된다
- [ ] 카테고리 배지가 표시된다
- [ ] 대중성 등급 링이 표시된다
- [ ] 대중성 점수(%)가 표시된다
- [ ] 대중성 등급 타이틀이 표시된다
- [ ] 대중성 등급 설명이 표시된다
- [ ] "현재 N명 참여 기준" 힌트가 표시된다

### 답변 카드

- [ ] "내 답변 N개" 섹션 헤더가 표시된다
- [ ] 각 답변 카드에 질문 텍스트가 표시된다
- [ ] 다수파/소수파 배지가 표시된다
- [ ] 옵션별 퍼센트 바가 표시된다
- [ ] 내 선택에 하이라이트 표시

### CTA

- [ ] "다른친구랑 케미 보기" 버튼이 표시된다
- [ ] "그룹 케미 보기" 버튼이 표시된다

### 대중성 지수 설명

- [ ] 도움말 버튼 클릭 → 툴팁 표시
- [ ] 툴팁 외부 클릭 → 툴팁 닫힘

### 모달

- [ ] "다른친구랑 케미 보기" 클릭 → 1:1 비교 링크 생성 모달
- [ ] "그룹 케미 보기" 클릭 → 그룹 생성 모달
