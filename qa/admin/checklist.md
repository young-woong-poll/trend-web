# 관리자 페이지 (`/admin/*`) QA 체크리스트

> 대응 스펙: [specs/pages/admin.md](../../docs/specs/pages/admin.md)
> 최종 QA: -

## 핫픽 관리

### Critical

- [ ] 핫픽 생성이 정상 동작한다 (SINGLE 타입)
- [ ] 핫픽 수정이 정상 동작한다 (슬러그 외 모든 필드)
- [ ] 핫픽 삭제가 정상 동작한다 (확인 모달 후)

### Major

- [ ] 핫픽 목록에 썸네일, 제목, 슬러그, 상태, 생성일이 표시된다.
- [ ] 슬러그 중복 확인이 동작한다.
- [ ] 카테고리 복수 선택이 가능하다.
- [ ] 이미지 업로드 (S3 presigned URL)가 정상 동작한다.

---

## 카테고리 관리

### Critical

- [ ] 카테고리 생성/수정/삭제가 정상 동작한다.

### Major

- [ ] 인라인 편집 UI가 정상 동작한다.
- [ ] 슬러그 형식이 영숫자 + 언더스코어 + 하이픈으로 제한된다.
