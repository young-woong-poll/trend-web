# 그룹 케미 비교 E2E 테스트 체크리스트

## 그룹 결과 (`/compare/group/[token]`)

### 렌더링 (멤버 상태)

- [ ] 그룹 이름이 표시된다
- [ ] 번들 타이틀이 표시된다
- [ ] 그룹 싱크율(%)이 표시된다
- [ ] 참여 인원 수가 표시된다
- [ ] 질문 수가 표시된다
- [ ] 싱크율 태그 ("높음"/"보통"/"낮음")이 표시된다
- [ ] 설정 버튼이 표시된다 (멤버만)

### 미리보기 모드 (생성자, 혼자)

- [ ] "가상 멤버로 구성된 미리보기예요" 배너가 표시된다
- [ ] "초대 링크 복사하기" CTA가 표시된다

### 비멤버 상태

- [ ] "나도 참여하기" 버튼이 표시된다
- [ ] 설정 버튼이 미표시

### CTA (멤버)

- [ ] "1:1 케미 따로 보기" 버튼이 표시된다
- [ ] "새 그룹 만들기" (생성자) 또는 "내 그룹 만들기" 버튼이 표시된다

### 그룹 설정 모달

- [ ] 설정 버튼 클릭 → 모달 열림
- [ ] 그룹 이름 수정 가능

### 표시 이름 모달

- [ ] 참여 시 표시 이름 선택 모달 열림
- [ ] "현재 닉네임 사용" 옵션
- [ ] "다른 이름 사용" 옵션 → 커스텀 입력 필드
- [ ] 프로필 색상 선택 가능
- [ ] "참여하기" 버튼 클릭 → 참여 완료

### 로딩/에러

- [ ] 로딩 중 오빗 스피너 표시
- [ ] 존재하지 않는 토큰: "그룹 케미 결과를 찾을 수 없습니다"

---

## 그룹 생성 모달

### 렌더링

- [ ] "그룹 만들기" 타이틀
- [ ] 번들 정보 표시
- [ ] "그룹 이름" 라벨 + "1~20자" 힌트
- [ ] 그룹 이름 입력 필드 (placeholder: "예: 마케팅팀, 대학 친구들")
- [ ] "그룹 링크 만들기" 버튼

### 유효성 검사

- [ ] 빈 이름 → 에러 메시지
- [ ] 위험 문자 (< > " ' &) → 에러 메시지
- [ ] 20자 초과 → maxLength로 제한

### 동작

- [ ] 유효한 이름 입력 후 생성 → 그룹 결과 페이지로 이동
- [ ] 생성 중 버튼 비활성화 + "생성 중..." 텍스트
- [ ] 닫기 버튼 → 모달 닫힘
