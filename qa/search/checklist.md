# 검색 (`/search`) QA 체크리스트

> 대응 스펙: [specs/pages/search.md](../../docs/specs/pages/search.md)
> 최종 QA: -

## 2. 검색 진입점

### Critical

- [ ] PC(≥768px): MainHeader에 검색 입력 필드(pill shape)가 표시된다
- [ ] PC: 검색창 클릭 시 검색 모달(드롭다운)이 등장한다 (페이지 이동 없음)
- [ ] Mobile(<768px): MainHeader에 돋보기 아이콘만 표시된다
- [ ] Mobile: 돋보기 탭 시 `/search` 페이지로 이동한다

### Major

- [ ] PC: 모달 바깥 클릭 시 모달이 닫힌다
- [ ] PC: ESC 키 입력 시 모달이 닫힌다
- [ ] PC: 검색어 입력 즉시 모달 내에서 결과 미리보기가 표시된다

## 3. 검색 화면 구조

### Critical

- [ ] 초기 상태: 최근 검색어 목록이 표시된다
- [ ] 2글자 이상 입력 시 검색 결과 미리보기가 표시된다
- [ ] 미리보기 카드에 카테고리, 썸네일, 제목, 투표수, 댓글수, 공감수가 표시된다
- [ ] 결과 없음 시 빈 상태 메시지가 표시된다 ("검색 결과가 없어요")

### Major

- [ ] 초기 상태: 최근 검색어가 없으면 빈 화면이 표시된다
- [ ] 미리보기 카드에 투표 옵션(A/B 바)이 표시되지 않는다
- [ ] PC 검색 모달: 헤더 아래 드롭다운으로 등장한다
- [ ] PC 검색 모달: backdrop(반투명 오버레이)이 표시된다

## 4. 검색 UX 스펙

### Critical

- [ ] 최소 2글자 입력 시 미리보기가 트리거된다
- [ ] search-as-you-type 동작한다 (엔터 불필요)
- [ ] 검색어 삭제 ✕ 버튼 클릭 시 입력값이 초기화된다
- [ ] 검색 화면 진입 시 입력 필드에 자동 포커스된다
- [ ] 하이라이팅: 검색어 매칭 부분이 attention color로 표시된다

### Major

- [ ] 디바운스 300ms가 적용된다
- [ ] 무한 스크롤 페이지네이션이 동작한다
- [ ] 취소 버튼이 없다 (뒤로가기 ←와 ✕만 존재)

### Minor

- [ ] 최대 50자 입력 제한이 적용된다

## 4.3. 최근 검색어

### Critical

- [ ] 최근 검색어가 localStorage(`hotpick_recent_search`)에 저장된다
- [ ] 최근 검색어 개별 삭제(✕)가 동작한다
- [ ] 최근 검색어 전체 삭제가 동작한다

### Major

- [ ] 최근 검색어가 최대 10개까지 유지된다
- [ ] 동일 검색어 재검색 시 최상단으로 이동한다
- [ ] 검색 결과 진입 시 검색어가 저장된다 (빈 결과 제외)

## 8. 접근성

### Major

- [ ] 검색 입력 필드에 `role="searchbox"`, `aria-label="핫픽 검색"`이 있다
- [ ] 검색 결과 영역에 `role="region"`, `aria-label="검색 결과"`가 있다
- [ ] 최근 검색어 삭제 버튼에 `aria-label="검색어 '{keyword}' 삭제"`가 있다
- [ ] ESC 키보드로 검색 모달/화면이 닫힌다

### Minor

- [ ] 로딩 상태 시 결과 컨테이너에 `aria-busy="true"`가 설정된다

## 9. 라우팅

### Critical

- [ ] `/search` 경로로 검색 화면에 접근할 수 있다
- [ ] `/search?q=키워드` URL로 검색 결과가 표시된다 (URL 공유 가능)

### Major

- [ ] `/search?q=키워드&category=slug` URL로 카테고리 필터가 적용된다
- [ ] PC에서 `/search` 직접 URL 접근 시 페이지로 렌더링된다
