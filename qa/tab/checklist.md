# 탭 네비게이션 (`/`) QA 체크리스트

> 대응 스펙: [specs/pages/tab.md](../../docs/specs/pages/tab.md)
> 최종 QA: -

## 1. 탭 바 구조

### Critical

- [ ] 페이지 진입 시 NEW 탭이 기본 선택되어 있다
- [ ] 탭은 상호 배타적으로 동작한다 (하나만 활성화 가능)
- [ ] 필터탭(NEW/HOT/MY)과 카테고리탭이 하나의 탭 바에 표시된다

### Major

- [ ] 탭 바가 가로 스크롤 가능하다 (탭이 넘칠 때)
- [ ] 스크롤바가 숨겨져 있다

### Minor

- [ ] 탭 바가 `<nav role="tablist">` 요소로 렌더링된다

## 2. 필터탭

### Critical

- [ ] NEW 탭 클릭 시 최신순(`sort=latest`) 핫픽이 표시된다
- [ ] HOT 탭 클릭 시 인기순(`sort=hot`) 핫픽이 표시된다
- [ ] MY 탭 클릭 시 내가 투표한(`filter=voted`) 핫픽이 표시된다

### Major

- [ ] 각 필터탭에 아이콘이 텍스트 왼쪽에 표시된다 (NEW: ✦, HOT: 🔥, MY: ☑)
- [ ] 활성 탭의 아이콘은 `opacity: 1`, 비활성 탭의 아이콘은 `opacity: 0.6`이다

### Minor

- [ ] 아이콘 크기가 13x13px로 통일되어 있다
- [ ] 아이콘과 텍스트 사이 간격이 4px이다

## 3. 구분자

### Major

- [ ] 필터탭(MY)과 카테고리탭(첫 번째) 사이에 세로선 구분자가 표시된다

### Minor

- [ ] 카테고리가 0개이면 구분자가 표시되지 않는다

## 4. 카테고리탭

### Critical

- [ ] 카테고리탭 클릭 시 해당 카테고리의 인기순(`category={slug}&sort=popular`) 핫픽이 표시된다
- [ ] 카테고리 목록이 API(`GET /api/v1/hotpicks/categories`)에서 동적으로 로드된다
- [ ] API 응답의 "전체"(`slug: 'all'`) 카테고리는 탭에 표시되지 않는다

### Major

- [ ] API 실패 시 폴백 카테고리 목록(연애/결혼/관계/재테크/직장/라이프/트렌드)이 표시된다
- [ ] 카테고리탭에는 아이콘이 없고 텍스트만 표시된다

### Minor

- [ ] 카테고리탭의 `data-testid`가 `content-tab-category-{slug}` 형식이다

## 5. 탭 시각 스타일

### Major

- [ ] 활성 탭은 흰색 텍스트(`#ffffff`)와 bold(700) 폰트로 표시된다
- [ ] 활성 탭 하단에 gradient line(#ff00ff → #ff4500)이 표시된다
- [ ] 비활성 탭은 회색 텍스트(`#8a8a8a`)와 medium(500) 폰트로 표시된다

### Minor

- [ ] 비활성 탭 호버 시 텍스트 색상이 `#d1d1d1`로 변경된다

## 7. 탭 전환 동작

### Critical

- [ ] 탭 전환 시 해당 탭에 맞는 새로운 데이터가 로드된다
- [ ] 탭 전환 시 스크롤이 최상단으로 초기화된다

### Major

- [ ] 클릭한 탭이 화면 밖에 있을 때 탭 바가 자동 스크롤되어 해당 탭이 보인다
- [ ] 탭 전환 중 로딩 스켈레톤이 표시된다

## 8. 빈 상태 메시지

### Major

- [ ] NEW 탭에서 결과 없을 때 "새로운 핫픽이 없어요" 메시지가 표시된다
- [ ] HOT 탭에서 결과 없을 때 "아직 HOT 핫픽이 없어요" 메시지가 표시된다
- [ ] MY 탭에서 결과 없을 때 "투표한 핫픽이 없어요" 메시지가 표시된다

### Minor

- [ ] 카테고리탭에서 결과 없을 때 "'{카테고리명}' 핫픽이 없어요" 메시지가 표시된다

## 10. 헤더 고정

### Critical

- [ ] 스크롤 시 헤더와 탭 바가 화면 상단에 고정되어 있다 (fixed)
