# 마이페이지 E2E 테스트 체크리스트

## 마이페이지 (`/my`)

### 프로필 섹션

- [ ] 프로필 아바타 표시
- [ ] "닉네임 님" 표시
- [ ] "닉네임 변경" 버튼 표시
- [ ] "프로필 색상" 버튼 표시

### 계정 관리

- [ ] "로그아웃" 버튼 표시
- [ ] "회원 탈퇴" 버튼 표시

### 접근 제어

- [ ] 비로그인 상태 → 로그인 페이지로 리다이렉트

### 닉네임 변경 모달

- [ ] "닉네임 변경" 클릭 → 모달 열림
- [ ] 현재 닉네임 표시
- [ ] 새 닉네임 입력 가능

### 프로필 색상 모달

- [ ] "프로필 색상" 클릭 → 모달 열림
- [ ] 색상 선택 가능

### 로그아웃

- [ ] "로그아웃" 클릭 → 홈으로 이동

### 회원 탈퇴

- [ ] "회원 탈퇴" 클릭 → 확인 다이얼로그
