# 1:1 케미 비교 E2E 테스트 체크리스트

## 비교 랜딩 (`/compare/[token]`)

### 렌더링

- [ ] 번들 타이틀이 표시된다
- [ ] 히어로 타이틀이 표시된다 (생성자 닉네임 포함)
- [ ] 봉인 해제 섹션 (자물쇠 아이콘)이 표시된다
- [ ] 첫 질문 미리보기가 표시된다
- [ ] CTA 버튼이 표시된다

### 상태별 CTA

- [ ] 비로그인 상태: "대결 수락하기"
- [ ] 이미 참여된 링크: 별도 안내 + CTA 변경
- [ ] 생성자 대기 상태: 결과 페이지로 자동 이동
- [ ] 참여 가능 상태: "결과 확인하기"

### 네비게이션

- [ ] CTA 클릭 → 적절한 다음 단계로 이동

### 에러

- [ ] 존재하지 않는 토큰: "케미 테스트를 찾을 수 없습니다" + 홈 버튼

## 1:1 비교 결과 (`/compare/match/[token]`)

### 미리보기 모드 (생성자, 아직 상대방 미참여)

- [ ] "가상 상대와의 미리보기예요" 배너가 표시된다
- [ ] 가상 매치율이 40-60% 범위로 표시된다
- [ ] 초대 링크 복사 CTA가 표시된다

### 실제 결과 모드 (양쪽 참여 완료)

- [ ] 케미 카드가 표시된다
- [ ] 내 닉네임과 상대 닉네임이 표시된다
- [ ] 매치율(%)이 표시된다
- [ ] 답변 비교 카드가 표시된다 (일치/불일치)
- [ ] 대중성 비교 섹션이 표시된다

### CTA

- [ ] "다른 친구랑 케미 보기" 버튼이 표시된다
- [ ] "그룹 케미 보기" 버튼이 표시된다

### 그룹에서 진입 (`?from=group`)

- [ ] "그룹 결과로 돌아가기" 버튼이 표시된다
- [ ] 뒤로가기 버튼이 표시된다

### 로딩

- [ ] 로딩 오빗 애니메이션이 표시된다
- [ ] "둘의 케미를 분석하고..." 텍스트가 표시된다

## 1:1 비교 링크 생성 모달

### 렌더링

- [ ] "1:1 케미 테스트 공유" 타이틀
- [ ] 번들 정보 표시
- [ ] "가장 먼저 참여한 친구와 1:1 비교돼요" 설명
- [ ] 링크 생성 중 로딩 텍스트
- [ ] 링크 생성 완료 후 URL 표시
- [ ] "링크 복사하기" 버튼

### 동작

- [ ] 모달 열림 시 자동 링크 생성
- [ ] "링크 복사하기" 클릭 → 클립보드 복사
- [ ] 닫기 버튼 → 모달 닫힘
