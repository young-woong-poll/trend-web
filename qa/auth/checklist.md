# 로그인/인증 E2E 테스트 체크리스트

## 로그인 모달

### 기본 트리거

- [ ] 기본 메시지: "로그인하고 더 많은 기능을 이용해보세요"
- [ ] 댓글 트리거: "댓글을 남기려면 로그인이 필요해요"
- [ ] 좋아요 트리거: "좋아요는 로그인 후 이용할 수 있어요"
- [ ] 혜택 목록 3개 표시
- [ ] "카카오로 시작하기" 버튼 표시

### 비교 트리거 (compare)

- [ ] 🙇‍♂️🙏 이모지 표시
- [ ] "귀한 시간 내주셔서 감사합니다" 타이틀
- [ ] "카카오로 3초만에 시작하기" 버튼 표시

### 모달 동작

- [ ] 닫기 버튼 클릭 → 모달 닫힘
- [ ] 배경(dimmed) 클릭 → 모달 닫힘
- [ ] 모달 열림 시 body 스크롤 잠금
