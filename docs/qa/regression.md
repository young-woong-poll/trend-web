#### 노출

- [ ] 투표가 최신순으로 무한스크롤 표시된다.
- [ ] 무한 스크롤시 20개씩 노출된다.
- [ ] (무한스크롤 포함) 로딩시 스켈레톤 로딩이 표시된다.
- [ ] "이미지 or 텍스트" 타입에 맞게 화면이 노출된다.
- [ ] 옵션이 2~4개 일때 결과까지 잘 노출된다.
- [ ] 참여자수가 잘 노출되며 1000명 단위로 k, m 이 붙는다.
- [ ] 댓글 수가 잘 노출되고 클릭시 댓글창이 뜬다.
- [ ] deadline 이 설정된 경우에 D-day 가 표시되고, 오늘이 d-day 인 경우에는 시간이 초단위로 표시된다.
- [ ] 이미 deadline 이 지난 투표는 마감 표시가 되고 "결과만" 표시된다.
- [ ] 카테고리가 잘 표시된다. 2개 이상인 경우에도 모두 표시된다.
- [ ] 카테고리 클릭시 해당 카테고리 핫픽들만 잘 필터링된다.
- [ ] 동일한 카테고리 두번 클릭시 전체 카테고리로 변경된다.
- [ ] 질문이나 옵션 글자수가 너무 긴 경우 줄바꿈이 된다.
- [ ] 모바일에서도 잘 표시된다. (반응형)

#### 투표

- [ ] 투표시 애니메이션과 함께 결과가 표시된다. (지금 % 만 표시되고 있는데 투표 수도?)

#### 공유하기

- [ ] 공유하기 버튼을 클릭하면 상세페이지 (/hotpick/[slug]) URL 이 복사된다.
- [ ] "링크가 복사되었습니다" 토스트 메시지가 등장한다.

#### 댓글

- [ ] "댓글 전체 개수"가 잘 표시된다.
- [ ] 댓글이 최신순 / 인기순에 필터에 맞게 잘 정렬되어 나타난다.
- [ ] 댓글은 무한스크롤로 20개씩 노출된다.
- [ ] (무한스크롤 포함) 스켈레톤 로딩이 표시된다.
- [ ] 등록된 시간에 맞게 "0초전, 0분전, 0시간전, 0일전, 0주전, 0달전, 0년전" 으로 표시된다.
- [ ] 좋아요를 누를 수 있다.
- [ ] 좋아요는 Rate Limit 이 걸려있다. (0초에 0번)
- [ ] 좋아요 상태가 잘 표시된다. (uuid 기반)
- [ ] 글자수가 제한수 만큼만 입력되고 초과시 입력이 안된다.
  - 닉네임(20자) / 비밀번호 (4~10자) / 댓글 (200자)
- [ ] 미입력 필드가 있는 상태에서, 게시 버튼을 클릭시 에러표시가 잘 나온다.
- [ ] 댓글 게시가 잘되고, 게시 후에 최신순 탭으로 이동한다.
- [ ] 댓글 수정 & 삭제시 비밀번호 Validation 을 거친다. 잘못된 경우 에러메시지가 잘 나온다.
- [ ] 댓글 수정이 제약조건에 맞게 잘된다. 수정후 화면에 바로 업데이트 된다.
- [ ] 댓글 삭제가 잘된다. 삭제후 화면에 바로 업데이트 된다.
- [ ] 바텀시트는 dimmed 영역 클릭시 닫히며 스크롤이 방지되어야하고, 기존 스크롤 위치에 영향을 주면 안된다.

#### UUID

- [ ] 서비스 진입시 (메인 화면에서 뿐만아니라) 발급된 uuid 가 있으면 로컬스토리에서 가져온다. 없을 경우 uuid 를 발급해서 로컬스토리지에 저장한다.
- [ ] uuid 를 HTTP `x-tku-id` 헤더로 전송한다.
  - [ ] 메인에서 핫픽 가져올때
  - [ ] 투표할때
  - [ ] 좋아요 누를때
  - [ ] 댓글 좋아요 정보 가져올때
- [ ] uuid 기준으로 이미 투표한 핫픽은 결과가 보여진다.
- [ ] uuid 기준으로 이미 좋아요를 누른 댓글은 좋아요가 보여진다.

#### 상세페이지 (hotpick/[slug])

- [ ] SINGLE 타입은 SingleDetailView, BUNDLE 타입은 HotpickView 가 렌더링된다.
- [ ] 존재하지 않는 alias 진입 시 404 페이지가 노출된다.
- [ ] 투표 전에 결과 & 댓글 미노출 (댓글 블러 + "투표 후 댓글을 확인할 수 있습니다" 오버레이)
- [ ] 이미 투표한 적 있는 투표라면 진입 시 결과가 노출되어야 함
- [ ] 마감된 투표는 옵션 비활성화 + 결과만 표시
- [ ] 투표 시 애니메이션과 함께 결과 바가 표시되고, 내가 선택한 옵션에 체크 표시
- [ ] 투표 후 공유 CTA("투표 공유하기") 버튼이 활성화되고, 클릭 시 URL 복사 + 토스트
- [ ] 인라인 댓글: 5개씩 로드, "댓글 더보기" 버튼으로 추가 로드
- [ ] 인라인 댓글: 인기순/최신순 정렬, 댓글 작성/수정/삭제 동작
- [ ] 추천 섹션: 동일 카테고리 Single 최대 2개 표시, 없으면 섹션 미노출
- [ ] "더 많은 투표 보기" 클릭 시 메인("/")으로 이동
- [ ] OG 메타태그가 정상 생성된다 (카카오톡 등 프리뷰 확인)

#### 에러 or 엣지케이스

- [ ] 불러오는 과정에서 에러가 발생한 경우 → "핫픽을 불러오는데 실패했습니다." 문구가 노출
- [ ] 카테고리 별로 핫픽이 하나도 없는 경우 → "아직 진행중인 핫픽이 없어요" 문구가 노출
