H3 로딩 UI 5개 비교

다크 톤 / Primary Gradient / 호흡 1.0~1.8s 사이. 마음에 드는 옵션을 알려주세요.

A. Pulse Dot + Halo (현재)

그라데이션 원 1개가 호흡, 뒤에 radial halo 동조. BundleResult gateVisual 톤. 차분/우아 · 임팩트 약함.

B. 3-Dot Wave

점 3개 좌→우 호흡, 0.15s stagger. "로딩 중" 즉시 인지. 범용 패턴 — 깔끔하고 안전.

C. Bar Wave (음악 톤)

세로 막대 5개가 위아래로 호흡. 활기/생기 느낌. H3 같은 가벼운 콘텐츠 톤에 잘 맞음.

D. Orbit Dots (HotPick 시그니처)

중앙 그라데이션 + 4개 노드가 궤도 회전. BundleResult / LandingHero 비주얼 패턴 그대로. HotPick 톤 매칭도 최고.

E. Ripple (잔물결)

중심 dot + 외곽 ring 3개가 차례로 확장-fade. 모던/세련. "투표 → 친구로 퍼져나간다" 메타포와도 어울림.

결의 추천 우선순위
  • D. Orbit Dots — HotPick 자체 시그니처(BundleResult, LandingHero)와 시각 어휘 일치. 통일감 ★★★
  • E. Ripple — H3 서비스 본질("내 답이 친구들로 퍼짐") 메타포. 시그니처는 아니지만 의미적 fit ★★★
  • B. 3-Dot Wave — 가장 보편적, "로딩" 인지 ★★★. 다만 HotPick 시그니처는 약함
  • C. Bar Wave — 톤 좋지만 다른 영역 사례 없음
  • A. 현재 안 — 우아하지만 "로딩" 신호 약함
