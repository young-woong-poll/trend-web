# HotPick 브랜딩 리뉴얼 전략

> **작성일**: 2026-03-30
> **상태**: 승인됨
> **배경**: 번들 퍼스트 전략에 맞춰 "투표 서비스" → "생각 비교 도구"로 브랜딩 전환

---

## 1. 브랜드 아이덴티티 재정의

### 핵심 전환

```
이전: "투표 서비스" — 핵심 동사 "투표하다"
이후: "생각 비교 도구" — 핵심 동사 "비교하다"
```

### 브랜드 요소

| 요소            | 이전                                                             | 이후                                           |
| --------------- | ---------------------------------------------------------------- | ---------------------------------------------- |
| **메인 슬로건** | 애매하면 핫픽                                                    | **생각을 비교하다, 핫픽**                      |
| **서브카피**    | 투표하고, 대중의 생각을 확인하세요                               | **대중의 생각부터 연인의 가치관까지**          |
| **페르소나**    | 트렌드에 민감하고, 논쟁을 즐기며, 돌직구를 던지는 재치 있는 친구 | **궁금증을 숫자로 풀어주는 재치 있는 친구**    |
| **톤앤매너**    | 활기찬 나이트클럽 느낌                                           | **호기심을 자극하는 톤. 가볍지만 신뢰감 있는** |
| **서비스 이름** | 핫픽 (HotPick)                                                   | 핫픽 (유지)                                    |
| **비주얼**      | 다크 테마 + 마젠타→오렌지 그라디언트                             | 유지 (변경 없음)                               |

### 브랜드 구조

```
상위 가치: "우리의 생각, 숫자로 확인하다"
    │
    ├── 싱글: 대중과 나의 생각 비교 (1 vs 다수)
    │   강점: 즉시성, 대중 의견 확인, 리텐션
    │
    └── 번들: 나와 너의 가치관 비교 (1 vs 1, 소그룹)
        강점: 관계 비교, 바이럴, 공유
```

랜딩/공유에서는 번들 비교 중심, 피드에 들어오면 싱글도 자연스럽게 노출.

## 2. SEO/OG 메타 변경

| 위치              | 이전                                                   | 이후                                                           |
| ----------------- | ------------------------------------------------------ | -------------------------------------------------------------- |
| **사이트 타이틀** | 핫픽                                                   | **핫픽 - 생각을 비교하다**                                     |
| **메인 설명**     | 애매하면? 핫픽 🔥 투표하고 사람들의 생각을 확인하세요! | **생각을 비교하다, 핫픽 🔥 대중의 생각부터 연인의 가치관까지** |
| **OG 타이틀**     | 애매하면? 핫픽                                         | **핫픽 - 생각을 비교하다**                                     |
| **OG 설명**       | 애매한 고민, 사람들의 생각을 확인하세요!               | **대중의 생각부터 연인의 가치관까지, 숫자로 비교하세요**       |
| **타이틀 템플릿** | %s \| HotPick                                          | %s \| HotPick (유지)                                           |

### 페이지별 메타

| 페이지             | 이전                                           | 이후                                                                   |
| ------------------ | ---------------------------------------------- | ---------------------------------------------------------------------- |
| **싱글 상세**      | {제목} — {A} vs {B} - 지금 바로 투표하세요!    | **{제목} — {A} vs {B} - 대중의 생각을 확인하세요**                     |
| **싱글 결과**      | 나는 어떤 유형일까? {A} vs {B} 결과 확인하기 → | **{A} vs {B} - 대중의 답은? 결과 확인하기 →**                          |
| **번들 인트로**    | (신규)                                         | **{번들 제목} - 우리 생각 얼마나 통할까?**                             |
| **번들 비교 결과** | (신규)                                         | **{이름} vs {이름} - 케미 {N}% \| HotPick**                            |
| **제안 페이지**    | 새로운 핫픽 투표 주제를 제안해주세요!          | **새로운 비교 주제를 제안해주세요! 여러분의 아이디어가 핫픽이 됩니다** |

## 3. SEO 키워드 전환

```
이전: 핫픽, 트렌드 투표, 대중 투표, 이지선다, 밸런스 게임, A vs B,
     대중 의견, 실시간 투표, 취향 테스트, 연애 투표, 직장인 투표, 논란

이후: 핫픽, 가치관 비교, 커플 테스트, 연애 가치관 테스트,
     케미 테스트, 생각 비교, 대중 의견, 커플 궁합,
     가치관 테스트, 밸런스 게임, 연인 비교, HotPick
```

Pickhana가 "예측/트렌딩" 키워드를 쓰는 것과 완전히 다른 검색 영역 선점.
