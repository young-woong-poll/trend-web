# 마이페이지 구조 개편 — My 탭 활동 통합 + 마이페이지 설정 전용

> 작성일: 2026-04-08
> 상태: 설계 완료, 구현 대기

## 목적

"내 것"이 마이페이지와 메인 My 탭에 흩어져 있는 문제를 해결한다. 모든 활동은 메인 My 탭에서, 설정은 마이페이지에서.

## 변경 요약

| 영역             | 현재                                    | 변경 후                                |
| ---------------- | --------------------------------------- | -------------------------------------- |
| 메인 My 탭       | 내가 투표한 싱글 핫픽 리스트만          | [투표] [비교] [댓글] [좋아요] 하위 4탭 |
| 마이페이지 (/my) | 프로필 + 댓글/좋아요 탭 + 로그아웃/탈퇴 | 프로필 + 로그아웃/탈퇴만 (설정 전용)   |

---

## 1. 메인 My 탭 구조

```
메인 탭: [NEW] [TOP] [MY] [카테고리들...]
                 ↓
My 하위 탭: [투표] [비교] [댓글] [좋아요]
```

- My 탭 진입 시 기본 선택: 로그인 유저는 **비교** (바이럴 핵심), 비로그인은 **투표**
- 투표: 기존 My 탭 콘텐츠 그대로 (내가 투표한 싱글 핫픽 무한 스크롤)
- 비교: 번들 아코디언 (신규, 아래 상세)
- 댓글: `MyCommentList` 컴포넌트 이동 (마이페이지에서)
- 좋아요: `LikedHotpickList` 컴포넌트 이동 (마이페이지에서)

### 비로그인 처리

4탭 모두 비로그인에게도 노출. 탭 전환은 자유롭게 가능.

| 탭     | 비로그인                     | 로그인        |
| ------ | ---------------------------- | ------------- |
| 투표   | 콘텐츠 바로 표시 (기존 동작) | 콘텐츠 표시   |
| 비교   | 로그인 유도 화면             | 번들 아코디언 |
| 댓글   | 로그인 유도 화면             | 댓글 리스트   |
| 좋아요 | 로그인 유도 화면             | 좋아요 리스트 |

로그인 유도 화면: 탭별 맞춤 문구 + [로그인하기] 버튼

- 비교: "로그인하면 비교 기록을 볼 수 있어요"
- 댓글: "로그인하면 내 댓글을 볼 수 있어요"
- 좋아요: "로그인하면 좋아요한 핫픽을 볼 수 있어요"

### 용어 선택

"싱글"/"번들"은 개발 용어이므로 유저에게는:

- 싱글 → **투표** (내가 투표한 것)
- 번들 → **비교** (친구랑 비교한 것)

## 2. 비교 탭 — 번들 아코디언

### 레이아웃

```
[연애 가치관 테스트]  ▼  ← 최근 활동순 1위, 자동 펼침
├── 내 결과  트렌드 여우 62%          [결과 보기]
├── 1:1  vs ??? (대기 중)            [링크 복사]    ← 대기가 위
├── 1:1  vs ??? (대기 중)            [링크 복사]
├── 그룹  대학동기 (3명, 대기)        [링크 복사]
├── 1:1  vs 수진 (완료)              [결과 보기]    ← 완료는 아래
├── 그룹  마케팅팀 (5명)             [결과 보기]
└── [+ 새 비교 만들기]

[결혼 가치관 테스트]  ▶  2건
[소비 가치관 테스트]  ▶  1건
```

### 정렬 규칙

**번들 정렬**: 최근 활동순 (비교 링크의 최신 상태 변경 시간 기준)

**번들 내 비교 링크 정렬**: 대기 → 완료 순 + 각 그룹 내에서 최신순

- 바이럴 관점: "아직 안 들어온 링크"가 눈에 먼저 띄어야 재공유 행동 유도

### 아코디언 동작

- 최근 활동 번들 1개만 자동 펼침
- 다른 번들 탭 시 이전 것 접힘 (한 번에 하나만 열림)
- 접힌 상태에서 비교 링크 총 건수 표시

### 각 항목 액션

| 상태      | 표시               | 액션                                 |
| --------- | ------------------ | ------------------------------------ |
| 내 결과   | 캐릭터 + 점수      | 결과 보기 → `/bundle/{slug}/result`  |
| 1:1 완료  | vs 닉네임          | 결과 보기 → `/compare/match/{token}` |
| 1:1 대기  | vs ???             | 링크 복사 (클립보드)                 |
| 그룹 완료 | 그룹명 (N명)       | 결과 보기 → `/compare/group/{token}` |
| 그룹 대기 | 그룹명 (N명, 대기) | 링크 복사 (클립보드)                 |

### 하단 CTA

각 번들 아코디언 하단에 "새 비교 만들기" 버튼 → 탭 시 1:1/그룹 선택

### 빈 상태

"아직 참여한 테스트가 없어요" + 메인으로 유도

## 4. 필요한 API

### 4-1. 번들 목록 (기존 미구현 API)

`GET /api/v1/bundles?filter=completed`

bundle-api-spec.md 14번에 이미 정의됨. 내가 완료한 번들 목록 반환.

### 4-2. 내 비교 링크 목록 (신규)

`GET /api/v1/bundles/{slug}/my-compare-links`

```typescript
Array<{
  token: string;
  type: 'ONE_TO_ONE' | 'GROUP';
  status: 'WAITING' | 'COMPLETED';
  createdAt: string;
  // 1:1 전용
  participantNickname: string | null;
  // 그룹 전용
  groupName: string | null;
  memberCount: number;
}>;
```

- 페이지네이션 불필요 (한 유저가 한 번들에 수백 개 링크를 만들 일 없음)
- 전체 목록 한 번에 반환
- FE에서 상태별 정렬 (대기 → 완료, 최신순)

### API 문서

신규 API는 별도 문서로 작성 예정 (bundle-api-spec.md가 아닌 새 파일).

## 5. 컴포넌트 변경 범위

### 이동 (마이페이지 → 메인 My 탭)

| 컴포넌트           | 현재 위치       | 변경                            |
| ------------------ | --------------- | ------------------------------- |
| `MyCommentList`    | MyPageView 내부 | My 탭 댓글 하위 탭에서 렌더링   |
| `LikedHotpickList` | MyPageView 내부 | My 탭 좋아요 하위 탭에서 렌더링 |

컴포넌트 코드 자체는 변경 불필요. 렌더링 위치만 이동.

### 신규

| 컴포넌트          | 설명                                            |
| ----------------- | ----------------------------------------------- |
| `MySubTabs`       | [투표] [비교] [댓글] [좋아요] 하위 탭 UI        |
| `MyBundleList`    | 비교 탭 — 번들 아코디언 리스트                  |
| `BundleAccordion` | 개별 번들 아코디언 (펼침/접힘 + 비교 링크 목록) |

### 수정

| 컴포넌트         | 변경 내용                                 |
| ---------------- | ----------------------------------------- |
| `MainViewClient` | My 탭 선택 시 하위 탭 렌더링              |
| `MyPageView`     | 댓글/좋아요 탭 + 리스트 제거, 설정만 남김 |

### 훅

| 훅                        | 설명                                                 |
| ------------------------- | ---------------------------------------------------- |
| `useMyCompareLinks(slug)` | 신규 — `GET /api/v1/bundles/{slug}/my-compare-links` |
| `useMyComments`           | 기존 유지 (위치만 이동)                              |
| `useLikedHotpicks`        | 기존 유지 (위치만 이동)                              |
