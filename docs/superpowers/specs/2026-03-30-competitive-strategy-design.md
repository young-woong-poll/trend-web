# HotPick 경쟁 전략 & 번들 퍼스트 실행 계획

> **작성일**: 2026-03-30
> **상태**: 승인됨
> **배경**: 유사 서비스 Pickhana(pickhana.com) 발견 → 차별화 전략 수립

## 1. 경쟁 분석 요약

### Pickhana vs HotPick

| 항목           | Pickhana                          | HotPick                             |
| -------------- | --------------------------------- | ----------------------------------- |
| 포지셔닝       | 예측 플랫폼 (적중률 게임)         | 고민 해결 도구 (대중 의견 확인)     |
| 콘텐츠 유형    | 밸런스/퀴즈/논쟁 (3종)            | 싱글(이지선다) + 번들(비교 시스템)  |
| 카테고리       | 넓고 얕음 (스포츠, 정치, 경제 등) | 좁고 깊음 (인간관계, 연애, 직장 등) |
| 참여 동기      | 적중률 쌓기, 명예의전당           | 대중 의견 궁금증 + 관계 비교        |
| 게이미피케이션 | 적중률, 랭킹, 예측마스터          | 케미 등급, 비교 카드                |
| 바이럴 구조    | 개인 공유 (약함)                  | 1:1/그룹 비교 초대 (강함)           |

### 핵심 위협

- 투표 형식의 유사성 → 유저가 구분하지 못할 위험
- Pickhana의 선점 효과 (유저 기반, 투표 수 축적)
- 투표 수 = 신뢰도 = 서비스 가치 → 네트워크 효과에서 후발주자 불리

## 2. 전략 결정: "번들 퍼스트"

### 포지셔닝 전환

```
기존: "투표 서비스" (Pickhana와 정면 경쟁)
전환: "관계 비교 도구" (완전히 다른 카테고리)
```

- (기존) "애매하면 핫픽" → 투표 서비스로 인식됨
- (신규) **"우리 생각 얼마나 통할까?"** → 관계 비교 도구로 인식됨

### 경쟁 구도 재정의

진짜 경쟁자는 Pickhana가 아니라 **MBTI 궁합 테스트류**이며, HotPick은 그것을 "실제 고민 주제"로 업그레이드한 버전이다.

|             | Pickhana          | MBTI/궁합 테스트 | **HotPick**          |
| ----------- | ----------------- | ---------------- | -------------------- |
| 핵심 가치   | 예측 적중 쾌감    | 성격 유형 분류   | **실제 가치관 비교** |
| 비교 대상   | 대중 vs 나        | 나 혼자          | **나 vs 너 + 대중**  |
| 콘텐츠 수명 | 이슈 소멸 시 종료 | 반복하면 질림    | **관계마다 새로움**  |
| 바이럴 동기 | "나 맞췄다" 자랑  | "나 INFJ래" 공유 | **"우리 케미 60%"**  |

### 전략 선택 이유

1. **차별화가 가장 선명** — Pickhana와 비교 자체가 안 되는 다른 제품이 됨
2. **투표 수 문제를 우회** — 번들 비교는 "나와 친구의 답 비교"가 핵심이라 대중 투표 수가 적어도 가치 있음
3. **자체 성장 엔진** — K-factor 0.12~0.30으로 마케팅 예산 없이도 유저가 유저를 데려옴
4. **싱글은 리텐션 역할** — 번들로 들어온 유저가 싱글도 투표하면서 투표 수 자연 축적

## 3. 실행 계획 — 타이트 일정

### 리소스 현황

- **인력**: 웅일(기획+FE) + BE 동료 1명, 전원 직장 병행
- **가용 시간**: 평일 저녁 + 주말 + 휴가 활용
- **예산**: 월 50만원 이하 (Phase 2까지는 0원 목표)

### Phase 1: 번들 MVP 개발 (4/1 ~ 4/20, 3주)

> 목표: "연애 가치관 테스트" 번들 1개가 완전히 동작하는 MVP

| 주차 | 기간      | FE (웅일)                      | BE (동료)                     |
| ---- | --------- | ------------------------------ | ----------------------------- |
| 1주  | 4/1~4/6   | 번들 인트로 + 순차 질문 UI     | 번들 CRUD API + 답변 세션 API |
| 2주  | 4/7~4/13  | 결과 페이지 + 비교 초대 링크   | 비교 초대/결과 API            |
| 3주  | 4/14~4/20 | 비교 결과 카드 + 카카오톡 공유 | 통합 테스트 + 배포            |

**병행 작업:**

- "연애 가치관 테스트" 5문항 확정 (50:50 갈리는 질문)
- 싱글 콘텐츠 20~30개 추가 축적 (콘텐츠 자동화)

**MVP 필수 기능:**

- [ ] 번들 인트로 → 순차 질문(5개) → 내 결과 확인
- [ ] 비교 초대 링크 생성 + 카카오톡 공유
- [ ] 초대받은 사람이 같은 번들 풀기
- [ ] 1:1 비교 결과 카드 (케미 등급 포함)
- [ ] 비교 카드 이미지 저장/공유

**MVP에서 빼는 것 (Phase 3 이후):**

- 그룹 비교 (3인+)
- 위클리 HOT 자동 큐레이션
- 푸시 알림
- 비교 이력 저장

### Phase 2: 시딩 (4/21 ~ 5/4, 2주)

> 목표: 첫 500명 유저 확보, 2차 공유 발생 확인

**Week 1 (4/21~4/27): 지인 네트워크 시딩**

| 일정      | 행동                                           | 목표            |
| --------- | ---------------------------------------------- | --------------- |
| 4/21 (월) | 웅일 + 동료, 각자 번들 풀고 연인/친구에게 공유 | 1차 시딩 10명   |
| 4/22~23   | 단톡방 5~10개에 비교 결과 카드 + "같이 해보자" | 1차 시딩 50명   |
| 4/24~27   | 2차 공유 모니터링, 피드백 수집, 즉시 버그 수정 | 2차 확산 100명+ |

**Week 2 (4/28~5/4): 커뮤니티 시딩**

커뮤니티 시딩 핵심 원칙: **"링크 말고 결과물"**

```
❌ "제가 만든 투표 사이트인데 평가해주세요" → 광고 (거부감)
✅ "남친이랑 결혼 가치관 테스트 해봤는데 혼수에서 갈라짐 ㅋㅋ" → 콘텐츠 (공감)
```

| 커뮤니티   | 시딩 방법                         | 타이밍 |
| ---------- | --------------------------------- | ------ |
| 에브리타임 | 비교 카드 캡쳐 + 연애 후기 글     | 4/28~  |
| X (트위터) | 비교 카드 이미지 + 짧은 감상      | 4/28~  |
| 블라인드   | (직장인 번들 준비 후 Phase 3에서) | 추후   |

### Phase 3: 검증 + 확장 (5/5~)

> 목표: 바이럴 검증 → 2번째 번들 출시 → 광고 부스팅

**바이럴 검증 후 순차 실행:**

1. "결혼 가치관 테스트" 번들 출시
2. "직장인 생존 테스트" 번들 출시
3. 인스타 광고 시작 (월 20~30만원, 비교 카드를 소재로)
4. 숏폼 본격화 (검증된 포맷으로)

## 4. 마케팅 전략 상세

### 채널별 전략

#### 카카오톡/지인 (최우선)

번들 비교는 지인 공유에 최적화된 포맷. 광고가 아니라 "같이 해보자"이기 때문에 거부감 제로.

```
웅일이 번들 풀기 → 친구에게 "이거 해봐" → 비교 결과 → 재밌으면 2차 공유
```

#### 커뮤니티 (2순위)

이전 시딩 실패 교훈: 외부 URL 직접 공유 = 광고로 인식됨.
전환: 비교 결과 카드 자체가 콘텐츠가 되게 하고, 댓글에서 "이거 어디서 해?" 질문이 나오게 유도.

#### 숏폼/SNS (Go/No-Go 이후 주력 성장 엔진)

AI 이미지 + TTS 숏폼은 알고리즘에서 밀림. 번들 비교 기능 출시 후 **리얼 비교 리액션** 포맷으로 전환.

**킬러 포맷: 커플 비교 리액션 (얼굴 O)**

```
훅 (0~3초): "3년 사귄 여자친구랑 연애 가치관 테스트 해봤는데..."
과정 (3~20초): 둘이 나란히 폰 보면서 결과 확인
반전 (20~30초): "케미 40%... 혼수에서 완전 갈라짐 ㅋㅋ"
CTA: 프로필 링크 or 댓글 고정
```

**확장 포맷:**
| 포맷 | 설명 | 난이도 |
|------|------|--------|
| 커플 리액션 | 본인+연인 또는 지인 커플 섭외 | 중 |
| 거리 인터뷰 | 홍대/강남에서 커플 즉석 테스트 | 높음 (고수익) |
| 1인 리뷰 | "이거 해봤는데 충격적 결과" | 낮음 |
| 결과 모음 | "케미 90% 커플 vs 20% 커플 비교" | 낮음 |

- 주 2~3개 릴스/틱톡 업로드 (주말 촬영, 평일 저녁 편집)
- 처음엔 1인 리뷰 + 커플 리액션으로 시작 → 반응 좋은 포맷에 집중

### Go/No-Go 이후 시딩 확장 구조

지인 공유는 1회성 "점화"이고, 이후 3개 채널을 동시에 돌리는 구조:

```
지인 시딩 (1회, 점화)
    │
    ▼
┌─────────────────────────────────────────────┐
│  채널 1: 숏폼 (주력 성장 엔진)               │
│  채널 2: 커뮤니티 (보조 유입)                 │
│  채널 3: SEO (장기 누적)                      │
└─────────────────────────────────────────────┘
    │
    ▼ 바이럴 검증되면
인스타 광고 부스팅 (월 20~30만)
```

### 예산 배분

| 시기                | 예산         | 용도                                 |
| ------------------- | ------------ | ------------------------------------ |
| Phase 1~2 (4/1~5/4) | 0원          | 번들 바이럴 + 지인 시딩으로 검증     |
| Phase 3 (5/5~)      | 월 20~30만원 | 바이럴 검증된 후, 인스타 광고 부스팅 |

## 5. 성공/실패 판단 기준

### Phase 2 종료 시점 (5/4) 판단

| 지표                 | 목표      | 미달 시 대응                           |
| -------------------- | --------- | -------------------------------------- |
| 번들 완료율          | 70% 이상  | UX 개선 (질문 수 줄이기, 진행 바 등)   |
| 비교 초대율          | 40% 이상  | CTA 위치/문구 개선, 공유 동기 강화     |
| 초대 → 참여 전환율   | 35% 이상  | 초대 메시지 개선, 인트로 페이지 최적화 |
| 지인 시딩 → 2차 공유 | 10건 이상 | 비교 카드 디자인/공유성 개선           |
| 누적 유저            | 500명     | 시딩 채널 확대 or 콘텐츠 주제 변경     |

**수치 미달 시**: 제품 개선 먼저, 마케팅 확대 및 예산 투입 보류.

## 6. 핵심 원칙

1. **돈보다 제품** — 바이럴 안 되는 제품에 광고비 쓰면 돈만 날림. 번들 비교가 자연 공유되는지 먼저 검증
2. **링크 말고 결과물** — 커뮤니티에 URL 던지지 말고, 비교 카드가 콘텐츠가 되게 하기
3. **좁고 깊게** — 연애 카테고리 하나에서 확실히 터뜨린 후 확장. 처음부터 넓히면 아무것도 안 됨
