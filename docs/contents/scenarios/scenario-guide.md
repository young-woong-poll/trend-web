# 4컷 만화 시나리오 생성 가이드

> Claude Code Agent가 hotpick 데이터를 기반으로 인스타 릴스/유튜브 쇼츠용 4컷 만화 시나리오를 생성하기 위한 가이드

### Quick Start (Agent용 요약)

1. hotpick 데이터(title, story, options, categories)를 읽는다
2. §3.4 패턴 결정 플로우로 시나리오 유형을 선택한다
3. §3.1 기-승-전-결 구조로 4컷을 작성한다
4. §9 체크리스트 12항목을 자가 검증한다
5. `pnpm db:validate-scenarios -- --file {파일}` 로 자동 검증한다
6. `docs/contents/scenarios/` 에 JSON 파일로 저장하고 git 커밋한다

---

## 1. 목표

| 항목 | 내용                                                   |
| ---- | ------------------------------------------------------ |
| 입력 | hotpick 1개 (title, story, options)                    |
| 출력 | 4컷 이상의 만화 시나리오 JSON                          |
| 용도 | 인스타 릴스(15~30초), 유튜브 쇼츠(30~60초) 만화 콘텐츠 |
| 핵심 | 사연의 갈등을 극적으로 연출하여 투표 참여를 유도       |

## 2. 시나리오 데이터 구조

### 2.1 전체 구조

```json
{
  "hotpick_id": 15,
  "hotpick_title": "연인 핸드폰 비밀번호, 공유해야 할까요?",
  "hotpick_story": "여자친구가 비밀번호 공유하자고 했는데...",
  "hotpick_options": ["당연히 공유", "프라이버시 존중"],
  "character": [
    {
      "name": "여자친구",
      "gender": "여",
      "appearance": "긴 생머리, 캐주얼한 니트, 밝은 표정",
      "personality": "밝고 직설적인 성격"
    }
  ],
  "panels": [
    {
      "panel": 1,
      "location": "카페",
      "dialogue": {
        "여자친구": "우리 비밀번호 공유하자~"
      },
      "composition": "카페 테이블에 마주 앉은 커플. 2인 미디엄 샷."
    }
  ]
}
```

**메타데이터 필드** (검증/참조용, DB에는 hotpick_id만 저장):

- `hotpick_title` — 원본 hotpick 제목 (참조용)
- `hotpick_story` — 원본 사연 (참조용)
- `hotpick_options` — 원본 선택지 배열 (검증에 사용)
- `hotpick_type` — `TEXT` 또는 `IMAGE` (IMAGE면 마지막 컷 연출 달라짐)

### 2.2 패널(panel) 필드 상세

| 필드        | 타입   | 필수 | 설명                                      |
| ----------- | ------ | ---- | ----------------------------------------- |
| panel       | number | O    | 컷 번호 (1부터 시작)                      |
| location    | string | O    | 장소 (카페, 회사, 집, 지하철 등)          |
| dialogue    | object | O    | 등장인물별 대사. key=캐릭터명, value=대사 |
| composition | string | O    | 구도 설명 (카메라 앵글, 인물 배치, 효과)  |

### 2.3 대사(dialogue) 작성 규칙

```json
{
  "여자친구": "(의심스러운 눈빛으로) 뭐야 숨기는거 있어?",
  "남자친구(속마음)": "(진짜 없는데... 감시당하는 느낌이지)",
  "효과음": "카톡! 카톡!",
  "나레이션": "당신이라면?"
}
```

- **일반 대사**: `"캐릭터명": "(감정/동작) 대사 내용"`
- **속마음**: `"캐릭터명(속마음)": "(생각 내용)"` — 말풍선 대신 생각풍선으로 표현
- **속마음 2개**: `"캐릭터명(속마음A)"`, `"캐릭터명(속마음B)"` — 키 중복 방지
- **효과음**: `"효과음": "소리"` — 배경 효과음
- **나레이션**: `"나레이션": "텍스트"` — 화면 위 자막
- **카톡/채팅 다중 메시지**: `"캐릭터명(카톡1)"`, `"캐릭터명(카톡2)"` — 연속 채팅 표현

> **핵심 규칙**: JSON 객체에 같은 키를 2번 쓸 수 없다. 같은 캐릭터의 대사/속마음/카톡이 2개 이상이면 반드시 접미사(A/B, 1/2)로 구분한다.

### 2.4 구도(composition) 작성 규칙

구도 설명에 반드시 포함할 요소:

1. **카메라 앵글**: 풀 샷 / 미디엄 샷 / 클로즈업 / 버드아이뷰
2. **인물 배치**: 몇 명이 어디에 어떻게 위치하는지
3. **연출 효과** (선택): 물음표, 땀방울, 분노 마크, 상상 풍선 등
4. **배경 디테일** (선택): 시간대, 조명, 분위기

## 3. 4컷 구성 공식

### 3.1 기본 구조 (기-승-전-결)

| 컷  | 역할       | 핵심                                  | 예시                          |
| --- | ---------- | ------------------------------------- | ----------------------------- |
| 1컷 | 기(설정)   | 일상적 장면에서 시작, 평화로운 분위기 | 커플이 카페에서 대화 중       |
| 2컷 | 승(발단)   | 갈등/사건 발생, 분위기 전환           | 여자친구가 비밀번호 공유 요청 |
| 3컷 | 전(절정)   | 감정 폭발 또는 딜레마 심화            | 남자친구의 곤란함, 내면 갈등  |
| 4컷 | 결(선택지) | "당신이라면?" + 투표 선택지 제시      | 화면 분할로 선택지 시각화     |

> **중요**: 1컷에서 갈등 발생까지 너무 오래 걸리지 않도록 한다.
> 설정이 길면 1컷에서 바로 사건을 암시하거나, 1컷 자체가 갈등 시작이 되어야 한다.
> (예: 지하철에서 지친 표정 → 이미 "뭔가 있다" 느낌)

### 3.2 마지막 컷(선택지 컷) 규칙

마지막 컷은 **항상** 다음 형태:

```json
{
  "panel": 4,
  "location": "배경 없음 (연출 컷)",
  "dialogue": {
    "나레이션": "당신이라면?"
  },
  "composition": "화면 분할. [선택지 개수]분할로 각 선택지를 시각적으로 표현. 하단에 선택지 텍스트."
}
```

- **2개 선택지**: 좌우 분할
- **3개 선택지**: 3분할
- **4개 선택지**: 4분할 (2x2 그리드)

### 3.3 확장 구성 (5~6컷)

갈등이 복잡하거나 배경 설명이 필요한 경우 5~6컷으로 확장:

| 컷  | 역할             |
| --- | ---------------- |
| 1컷 | 설정 (일상)      |
| 2컷 | 발단 (사건)      |
| 3컷 | 갈등 심화        |
| 4컷 | 절정 (감정 폭발) |
| 5컷 | 여운 / 고민      |
| 6컷 | 선택지 제시      |

### 3.4 패턴 결정 플로우

hotpick 데이터를 보고 아래 순서로 시나리오 패턴을 결정한다.

```
hotpick 입력
  ├─ categories에 love/marriage 포함?
  │   ├─ YES → story에 커플 등장? → 커플 갈등형 (2인)
  │   └─ YES → story에 커플 없음 → 1인 고민형
  ├─ categories에 work 포함?
  │   └─ YES → 직장인 딜레마형 (1인 + 간접 등장)
  ├─ categories에 relationship 포함?
  │   └─ YES → 인간관계 갈등형 (2인)
  ├─ categories에 finance/life 포함?
  │   └─ YES → 현실 고민형 (1인 또는 대비 캐릭터 추가)
  └─ categories에 trend 포함?
      ├─ type == IMAGE? → 취향 대결형 (그룹, 코믹)
      └─ type == TEXT? → 가치관형 (1~2인)
```

**1인 캐릭터 시나리오 팁:**
1인만 등장하면 갈등이 내면에만 머물러 약해진다.
→ **대비 캐릭터(동기, 친구)를 1명 추가**하여 외적 갈등으로 만들면 극적 효과 상승.
(예: 출퇴근 고민 → 회사 근처 이사한 동기가 자랑하는 장면 추가)

### 3.5 엣지 케이스 처리

| 케이스                   | 처리 방법                                                         |
| ------------------------ | ----------------------------------------------------------------- |
| `story`가 null/빈 문자열 | `title`과 `options`만으로 시나리오 구성. 1컷에서 바로 상황 진입.  |
| 선택지 4개 이상          | 마지막 컷을 2x2 그리드 분할. 각 선택지에 작은 아이콘+텍스트.      |
| IMAGE 타입               | 마지막 컷에 optionImages 활용. 실제 이미지 좌우 분할 + VS 마크.   |
| 주제가 추상적 (가치관)   | 구체적 상황으로 변환. "AI 불안" → 회사에서 ChatGPT 도입하는 장면. |
| 음식/취향 대결           | 코믹 톤. 친구 그룹 논쟁 패턴. 과장된 표현 OK.                     |

## 4. 카테고리별 시나리오 패턴

### 4.1 연애 (love) — 커플 갈등형

- **등장인물**: 커플 2명
- **대표 장소**: 카페, 집, 차 안
- **갈등 구조**: 한쪽의 요구 → 상대의 곤란 → 내면 갈등
- **핵심 포인트**: 양쪽 다 공감할 수 있는 상황

```
예: 비밀번호 공유 → 여자친구의 요구 vs 남자친구의 프라이버시
예: 전 애인 사진 → 발견한 사람의 배신감 vs 남긴 사람의 무심함
```

### 4.2 직장 (work) — 직장인 딜레마형

- **등장인물**: 직장인 1명 + 상사/동료(간접 등장)
- **대표 장소**: 사무실, 집(퇴근 후), 지하철
- **갈등 구조**: 회사의 요구 ↔ 개인의 바람
- **핵심 포인트**: "나도 겪어봤어" 공감

```
예: 퇴근 후 카톡 → 워라밸 vs 사회생활
예: 좋은 팀장 vs 낮은 연봉 → 사람 vs 돈
```

### 4.3 재테크/생활 (finance, life) — 현실 고민형

- **등장인물**: 직장인/사회초년생 1명
- **대표 장소**: 집, 지하철, 부동산
- **갈등 구조**: A를 택하면 B를 포기해야 하는 트레이드오프
- **핵심 포인트**: 구체적 숫자로 현실감 부여

```
예: 출퇴근 1시간반 vs 월세 60만원 → 시간 vs 돈
예: 월급 300으로 저축 → 현실적 가능성 고민
```

### 4.4 관계 (relationship) — 인간관계 갈등형

- **등장인물**: 친구/가족/지인 2명
- **대표 장소**: 카톡 채팅, 모임, 집
- **갈등 구조**: 관계 유지 vs 자기 보호
- **핵심 포인트**: 거절의 어려움, 눈치

```
예: 오래된 친구 돈 빌려달라 → 우정 vs 현실
예: 결혼식 축의금 → 예의 vs 경제적 부담
```

### 4.5 트렌드 (trend) — 취향/가치관형

- **등장인물**: 친구 그룹 또는 1인
- **대표 장소**: 다양 (주제에 따라)
- **갈등 구조**: "보통은 이렇지 않아?" vs "아닌데?"
- **핵심 포인트**: 가벼운 논쟁, 유머

```
예: 짜장면 vs 짬뽕 → 만년 갈등
예: 양념 vs 후라이드 → 친구들 사이 논쟁
```

## 5. 대사 작성 핵심 원칙

### 5.1 자연스러운 구어체

```
❌ "나는 이 상황이 불편하게 느껴져"
✅ "야 이거 좀 그렇지 않아?"

❌ "당신의 의견이 궁금합니다"
✅ "어떡하지... 나만 이상한 건가?"
```

### 5.2 감정 표현은 괄호로

```
✅ "(당황해하며) 아니야 아니야!"
✅ "(소곤소곤) 야 저 사람 좀 봐"
✅ "(분노하며 주먹을 쥐고) 진짜?!"
```

### 5.3 속마음은 별도 키로 — 핵심 연출 도구

속마음은 만화의 핵심 유머/공감 장치다. **갈등 컷(2~3컷)에서 적극 활용**한다.

```json
{
  "남자친구": "(웃으며) 괜찮아~",
  "남자친구(속마음)": "(전혀 괜찮지 않은데...)"
}
```

속마음 활용 패턴:

- **겉과 속이 다를 때**: 말은 괜찮다 하면서 속으로는 불만
- **선택 갈등**: 양쪽 선택지를 속마음으로 번갈아 고려
- **사회적 압박**: 겉으론 동의하지만 속으로는 반대

### 5.4 대사 길이

- 한 캐릭터당 **1~2문장** (최대 30자)
- 속마음은 **1문장** (최대 20자)
- 나레이션은 **5~10자** ("당신이라면?", "어떡하지?")

## 6. 구도 작성 핵심 원칙

### 6.1 카메라 샷 가이드

| 샷 타입      | 용도                 | 예시                                |
| ------------ | -------------------- | ----------------------------------- |
| 풀 샷        | 장면 설정, 인물 관계 | "카페 전경, 창가에 앉은 커플"       |
| 미디엄 샷    | 대화 장면, 상호작용  | "테이블 위 커피와 두 사람의 상반신" |
| 클로즈업     | 감정 강조, 반응      | "여자친구의 의심스러운 눈빛"        |
| 폰 화면 삽입 | 카톡/SNS 장면        | "폰 화면에 카톡 알림 + 인물 반응"   |

### 6.2 마지막 컷 분할 연출

```
2분할: "화면 분할. 왼쪽: [A 선택지 시각화]. 오른쪽: [B 선택지 시각화]."
3분할: "3분할 연출. ①[A] ②[B] ③[C]."
```

각 선택지를 **아이콘/상징물**로 시각화:

- 돈 관련 → 지갑, 통장, 돼지저금통
- 시간 관련 → 시계, 알람
- 관계 관련 → 하트, 끊어진 실
- 직장 관련 → 명함, 노트북

**3개 이상 선택지 시각화 팁:**

- 각 선택지를 **하나의 대표 장면(미니 일러스트)**으로 표현
- 번호(①②③)를 붙여 구분
- 추상적 선택지("먼저 제안한 쪽이 낸다")는 해당 상황을 연상시키는 구체적 장면으로 변환
  - 예: "먼저 제안한 쪽" → 카톡에서 "밥 먹을래?"라고 보내는 화면

## 7. 연출 이펙트 가이드

| 이펙트    | 용도        | 구도 표기 예시                  |
| --------- | ----------- | ------------------------------- |
| 물음표    | 의문, 혼란  | "머리 위에 물음표 이펙트"       |
| 느낌표    | 놀람, 충격  | "머리 위에 느낌표"              |
| 땀방울    | 당황, 곤란  | "이마에 식은땀"                 |
| 분노 마크 | 화남        | "관자놀이에 분노 마크"          |
| 상상 풍선 | 상상, 회상  | "구름 모양 상상 풍선 안에 장면" |
| 천사/악마 | 내면 갈등   | "양쪽 어깨에 천사와 악마"       |
| 배경 흐림 | 감정 집중   | "배경 흐림 처리, 인물만 선명"   |
| 화면 분할 | 선택지/대비 | "화면 좌우 분할"                |

## 8. 안티패턴 (이렇게 하지 마세요)

### 8.1 JSON 중복 키

한 패널의 dialogue에 **같은 캐릭터명 키를 2번 쓰면 안 됨**. JSON 스펙 위반.

```json
// ❌ 잘못된 예: 같은 키 중복
{
  "직장인(속마음)": "읽씹하면 내일 분위기...",
  "직장인(속마음)": "답장하면 또 꼬리물기..."
}

// ✅ 올바른 예: 키를 구분
{
  "직장인(속마음A)": "읽씹하면 내일 분위기...",
  "직장인(속마음B)": "답장하면 또 꼬리물기..."
}
```

### 8.2 편향된 시나리오

3컷에서 한쪽 선택지의 결과만 보여주면 시청자가 그쪽으로 쏠린다.

```
❌ 소개팅 밥값 → 3컷에서 남자가 내고 여자가 "감사해요~" → "남자가 낸다"로 편향
✅ 소개팅 밥값 → 3컷에서 양쪽 다 눈치 보며 고민 → 양쪽 공감 가능
```

### 8.3 너무 긴 대사

만화는 말풍선에 들어가야 한다. 3줄 이상이면 너무 길다.

```
❌ "나 사실 3년 전부터 이 문제에 대해 생각하고 있었는데 결국 결론을 못 내렸어"
✅ "3년째 고민인데... 답이 없어"
```

### 8.4 설정에 시간 낭비

1~2컷을 전부 설정에 쓰면 갈등 없이 절반이 지나간다. 1컷에서 바로 상황 진입.

```
❌ 1컷: 아침에 일어남 → 2컷: 회사 도착 → 3컷: 드디어 갈등 발생
✅ 1컷: 이미 갈등 상황에 있음 (카톡 알림 수신)
```

### 8.5 IMAGE 타입에서 이미지 무시

IMAGE 타입 hotpick은 옵션별 이미지가 있다. 마지막 컷에서 이미지를 활용해야 한다.

```
❌ IMAGE 타입인데 마지막 컷이 텍스트만 있는 선택지
✅ IMAGE 타입이면 마지막 컷에 옵션 이미지를 좌우 분할로 배치 + VS 마크
```

## 9. 시나리오 작성 체크리스트

시나리오 작성 후 아래 항목을 모두 확인:

| #   | 체크 항목                               | 기준                                     |
| --- | --------------------------------------- | ---------------------------------------- |
| 1   | 최소 4컷 이상인가?                      | 기-승-전-결 구조 확보                    |
| 2   | 마지막 컷이 선택지 제시인가?            | 나레이션 + 선택지 시각화                 |
| 3   | 모든 선택지가 마지막 컷에 포함되었는가? | hotpick의 options 전부 반영              |
| 4   | 대사가 자연스러운 구어체인가?           | 20~40대 한국 청년 말투                   |
| 5   | 갈등이 2컷 이내에 드러나는가?           | 너무 느린 전개 방지                      |
| 6   | 한쪽으로 편향되지 않았는가?             | 양쪽 선택지 모두 공감 가능해야           |
| 7   | 캐릭터 설정이 사연에 맞는가?            | 성별, 관계, 상황이 story와 일치          |
| 8   | 구도에 카메라 샷이 명시되었는가?        | 풀샷/미디엄/클로즈업 중 택1              |
| 9   | 감정 표현이 괄호로 되어 있는가?         | "(당황해하며)" 형식                      |
| 10  | 장소가 구체적인가?                      | "밖" 대신 "회사 앞 편의점"               |
| 11  | dialogue에 중복 키가 없는가?            | 같은 캐릭터 속마음 2개면 A/B 접미사 사용 |
| 12  | IMAGE 타입이면 마지막 컷에 이미지 활용? | 옵션 이미지 좌우 분할 + VS 마크          |

## 10. 실행 방법

### 10.1 Agent 호출 프롬프트 (시나리오 생성)

```
다음 hotpick에 대한 4컷 만화 시나리오를 생성해줘.

[hotpick 데이터]
- title: {title}
- story: {story}
- options: {options}
- categories: {categories}

[참고 가이드]
- docs/contents/scenarios/scenario-guide.md

[참고 예시]
- docs/contents/scenarios/test-scenarios.json

[출력 형식]
JSON으로 출력. test-scenarios.json의 구조를 따를 것.

[규칙]
1. 최소 4컷, 최대 6컷
2. 마지막 컷은 반드시 선택지 제시 컷
3. 모든 options를 마지막 컷에 반영
4. 대사는 20~40대 한국 청년 구어체
5. 한쪽으로 편향되지 않도록 양쪽 모두 공감 가능하게
```

### 10.2 Agent 호출 프롬프트 (배치 생성)

```
docs/contents/contents-mix.json에서 시나리오가 없는 hotpick들에 대해
4컷 만화 시나리오를 배치 생성해줘.

[참고 가이드]
- docs/contents/scenarios/scenario-guide.md
- docs/contents/scenarios/test-scenarios.json

[작업 절차]
1. contents-mix.json 로드
2. docs/contents/scenarios/ 디렉토리의 기존 시나리오 확인
3. 시나리오가 없는 hotpick부터 순서대로 생성
4. 각 시나리오를 scenarios/{hotpick_id}-{slug}.json으로 저장
5. 10개씩 배치로 생성 후 중간 점검

[출력 형식]
개별 JSON 파일로 저장
```

### 10.3 검증 후 git으로 버전관리

```bash
# 1. 시나리오 검증 (체크리스트 자동 검사)
pnpm db:validate-scenarios                                              # 전체 검증
pnpm db:validate-scenarios -- --file docs/contents/scenarios/14-xxx.json  # 개별 파일
pnpm db:validate-scenarios -- --dir docs/contents/scenarios/            # 디렉토리 전체

# 2. 검증 통과 후 git 커밋 (시나리오는 JSON 파일로 git 버전관리)
git add docs/contents/scenarios/14-xxx.json
git commit -m "feat: #14 시나리오 추가 - 친구 돈 빌려달라"
```

**Agent 워크플로우**: 생성 → 검증(validate) → git 커밋

## 11. 품질 평가 기준

| 평가 항목       | 가중치 | 기준                                           |
| --------------- | ------ | ---------------------------------------------- |
| 갈등 구현       | 30%    | 사연의 핵심 갈등이 시나리오에 잘 드러나는가    |
| 공감도          | 25%    | 20~40대가 "나도 겪어봤어"라고 느낄 수 있는가   |
| 대사 자연스러움 | 20%    | 실제 대화처럼 자연스러운가, 과장되지 않았는가  |
| 선택지 균형     | 15%    | 한쪽으로 편향되지 않고 양쪽 모두 공감 가능한가 |
| 시각 연출       | 10%    | 구도/이펙트가 만화로 표현하기 적합한가         |

### 평가 등급

- **A (90+)**: 바로 사용 가능
- **B (70~89)**: 소폭 수정 후 사용
- **C (50~69)**: 구조/대사 대폭 수정 필요
- **D (50 미만)**: 재작성 필요

## 12. 릴스 바이럴 최적화 (선택 필드)

바이럴을 목표로 할 때 시나리오 JSON에 `reels_meta` 필드를 추가한다.

```json
{
  "hotpick_id": 1,
  "reels_meta": {
    "hook_panel": {
      "dialogue": { "여자친구": "(굳은 표정으로) ...이 사진 뭐야?" },
      "composition": "여자친구 얼굴 클로즈업. 폰 화면 빛 반사. 화면 가득."
    },
    "hook_caption": "남자친구 폰에서 이걸 발견했을 때",
    "cta": {
      "comment_prompt": "지워야 한다 🗑️ vs 상관없다 🤷 댓글로 투표",
      "save_prompt": "공감되면 저장해두고 남자친구한테 보여줘",
      "tag_prompt": "이런 상황 겪은 사람 태그 ↓"
    },
    "bgm_mood": "평화 → 정적 → 긴장 현악",
    "series": "연애 논란 ep.2",
    "viral_trigger": "분노 + 공감"
  },
  "panels": [...]
}
```

### 훅(hook) 작성 원칙

기본 1컷은 "일상에서 시작"이지만, 릴스용은 **갈등 한가운데서 시작**해야 한다.

```
❌ 릴스 기본 1컷: "(편하게) 오빠 폰 좀 볼게~"
✅ hook_panel:    "(굳은 표정) ...이 사진 뭐야?" → 3초 안에 궁금증 유발
```

### 댓글 CTA 공식

```
[선택지A] [이모지A]  vs  [선택지B] [이모지B]  댓글로 투표
```

> 상세 릴스 전략: `docs/contents/reels-viral-strategy.md` 참조
