# 릴스 영상 제작 템플릿

> 시나리오 JSON을 실제 릴스 영상으로 변환하는 편집 가이드

---

## 1. 영상 스펙

| 항목      | 값                            |
| --------- | ----------------------------- |
| 비율      | 9:16 (세로형)                 |
| 해상도    | 1080 × 1350                   |
| 총 길이   | 20~35초                       |
| FPS       | 30fps                         |
| 자막 폰트 | 나눔 고딕 Bold / 노토 산스 KR |

---

## 2. 영상 구조 (타임라인)

```
[0~3초]   훅(Hook)        — hook_panel 사용, 상단 자막 오버레이
[3~5초]   전환 효과       — 페이지 넘기는 이펙트 or 스와이프
[5~20초]  본편 (4컷)      — 각 컷당 3~5초
[20~25초] 선택지 컷       — 마지막 panel (분할 연출)
[25~30초] CTA 오버레이    — cta.comment_prompt 텍스트 + 이모지
[28~35초] 루프 처리       — 훅 장면 1~2초 재생 후 자연스럽게 시작 연결
```

---

## 3. 컷별 편집 가이드

### 3.1 훅 컷 (0~3초) — `hook_panel` 기준

```
✅ 화면 가득 채우는 클로즈업
✅ 상단 1/3 지점에 훅 자막 (hook_caption)
✅ BGM: bgm_mood의 첫 단계
✅ 자막은 컷 시작 0.3초 후 페이드인
❌ 로고, 인트로, 계정 소개 없음 (첫 3초 낭비 금지)
```

**자막 스타일:**

```
폰트: 나눔 고딕 Bold 48-56px
색상: 흰색 + 검정 아웃라인 or 반투명 검정 배경 띠
위치: 상단 (세이프존 내)
애니메이션: 아래에서 팝인 or 타이프라이터 효과
```

### 3.2 만화 컷 전환 (각 컷 3~5초)

**전환 방법 2가지:**

| 방법          | 효과                         | 어울리는 톤 |
| ------------- | ---------------------------- | ----------- |
| 페이지 넘기기 | 오른쪽에서 왼쪽으로 슬라이드 | 만화책 느낌 |
| 줌 인/아웃    | 이전 컷 줌아웃 → 새 컷 줌인  | 영화적 느낌 |

**대사 표시 방법:**

- 말풍선을 화면에 오버레이 (만화 스타일)
- 또는 하단 자막 바 형식 (심플 스타일)
- 속마음: 구름 모양 말풍선 or 이탤릭체 회색 자막

### 3.3 선택지 컷 (마지막 panel)

**2분할:**

```
화면 정중앙에 수직선
왼쪽 50%: 선택지 A 이미지 + 텍스트 (위에서 슬라이드 인)
오른쪽 50%: 선택지 B 이미지 + 텍스트 (아래에서 슬라이드 인)
중앙: VS 텍스트 or 물음표 이모지
```

**3분할:**

```
화면 3등분 수직
①②③ 순서로 0.3초 간격으로 팝인
각 칸 상단: 번호, 하단: 선택지 텍스트
```

### 3.4 CTA 오버레이 (마지막 3~5초)

```
cta.comment_prompt 텍스트 → 화면 하단 1/4
배경: 반투명 검정 띠
이모지 크게 표시
화살표 ↓ 애니메이션으로 "댓글로" 유도
```

## 4. 실제 변환 예시 — #4 퇴근 카톡

### 원본 JSON

```json
{
  "hook_panel": {
    "dialogue": { "직장인": "팀장님이... 퇴근하고 3시간이나 지났는데??" },
    "composition": "침대에 누운 직장인. 폰 화면만 밝게."
  },
  "bgm_mood": "신나는 퇴근 분위기 → 카톡 알림음 → 무거운 침묵",
  "cta": { "comment_prompt": "A 확인만 👀  B 바로 답장 📱  C 다음날 ⏰  댓글에 달아줘" }
}
```

### 영상 편집 지시서 변환

```
[0.0~0.3초] 화면 완전 암전
[0.3~3초]   훅 컷: 어두운 침실, 폰 화면 빛, 직장인 얼굴 클로즈업
             상단 자막: "퇴근하고 쉬고 있는데 팀장님 카톡 왔을 때"
             BGM: 신나는 퇴근 음악이 갑자기 '카톡!' 알림음으로 중단
[3~4초]     페이지 넘기기 전환
[4~8초]     1컷: 샤워 후 소파 드러눕는 장면 (BGM: 평화로운)
[8~12초]    2컷: 폰 화면 + 얼굴 스플릿 (BGM: 무거운 침묵)
[12~17초]   3컷: 침대 고민 (천사/악마 이펙트)
[17~22초]   4컷: 3분할 선택지 컷 (①②③ 순서 팝인)
[22~27초]   CTA 오버레이: "A 확인만 👀  B 바로 답장 📱  C 다음날 ⏰"
             하단 "댓글에 달아줘" 텍스트 + ↓ 화살표 애니메이션
[27~30초]   루프: 훅 컷 1.5초 재생 → 자연 루프 연결
```

## 5. 캡션 공식

```
[훅 문장 — 공감 유발]

[선택지 투표 안내]
A: [선택지1] [이모지]
B: [선택지2] [이모지]

👇 댓글로 투표해줘

[태그/저장 유도 1줄]

#[주제] #직장인공감 #연애공감 #hotpick
```

**예시 — #4 퇴근 카톡:**

```
퇴근하고 쉬고 있는데 팀장님 카톡 왔을 때... 이거 진짜임?

A: 확인만 한다 👀
B: 바로 답장한다 📱
C: 다음날 출근해서 한다 ⏰

👇 댓글로 투표해줘

이런 팀장 있는 직장인 친구 태그 ↓

#퇴근카톡 #직장인공감 #워라밸 #hotpick #직장인
```

## 7. 업로드 타이밍

| 요일           | 시간대                  | 이유           |
| -------------- | ----------------------- | -------------- |
| 화/수/목       | 오후 7~9시              | 퇴근 후 피크   |
| 주말           | 오전 10시~오후 1시      | 여유 있게 소비 |
| 피해야 할 시간 | 새벽 1~6시, 월요일 오전 | 노출 낮음      |

## 8. 성과 모니터링

업로드 후 48시간 내 확인해야 할 지표:

| 지표   | 목표 기준         | 비고            |
| ------ | ----------------- | --------------- |
| 완주율 | 60% 이상          | 낮으면 훅 수정  |
| 저장률 | 5% 이상           | 낮으면 CTA 수정 |
| 댓글수 | 좋아요의 3% 이상  | 낮으면 CTA 강화 |
| 공유수 | 저장수의 50% 이상 | 태그 유도 강화  |
