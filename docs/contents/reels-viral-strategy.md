# HotPick 릴스 바이럴 전략

> 현재 시나리오의 트렌드 적합도 분석 + 바이럴을 위한 구체적 가공 아이디어

---

## 1. 현재 시나리오의 트렌드 적합도 평가

### 강점 (이미 잘 맞는 것들)

| 요소                       | 현재 시나리오                | 트렌드 부합도                                    |
| -------------------------- | ---------------------------- | ------------------------------------------------ |
| **인터랙티브 요소**        | 마지막 컷에서 투표 유도      | ✅ 높음 — 투표형 콘텐츠는 2026 알고리즘 우선순위 |
| **공감 + 논쟁 구조**       | 양쪽 모두 공감 가능한 딜레마 | ✅ 높음 — 댓글 자연 유도                         |
| **20-40대 타겟 공감 주제** | 연애·직장·재테크 상황        | ✅ 높음 — 정확한 타겟                            |
| **짧은 스토리**            | 4컷 기-승-전-결              | ✅ 높음 — 20-40초 내외 최적 길이                 |
| **속마음 연출**            | 속마음 말풍선                | ✅ 높음 — Z세대 공감 포맷                        |

### 약점 (개선이 필요한 것들)

| 요소            | 현재 문제                                      | 영향                                          |
| --------------- | ---------------------------------------------- | --------------------------------------------- |
| **훅(Hook)**    | 1컷이 "일상적 장면에서 시작" → 처음 3초가 약함 | 🔴 치명적 — 스크롤 멈춤 실패                  |
| **댓글 CTA**    | "당신이라면?" 텍스트만 있음                    | 🟡 중간 — 댓글 행동 유도 미흡                 |
| **논란 강도**   | 상황이 너무 중립적인 경우 있음                 | 🟡 중간 — 분노/공감 트리거 약함               |
| **음악/사운드** | 시나리오에 BGM 지정 없음                       | 🟡 중간 — 트렌딩 오디오 42% 인게이지먼트 차이 |
| **루프 구조**   | 끝에서 처음으로 이어지지 않음                  | 🟠 보통 — 재시청률 손실                       |

## 2. 바이럴 릴스의 핵심 공식 (2026 기준)

```
처음 3초 (훅) → 전개 15-25초 → 마지막 3초 (CTA)
     ↓                ↓                  ↓
 스크롤 멈춤       감정 투자           행동 유발
 (분노/공감)      (기-승-전)        (댓글/저장/태그)
```

알고리즘이 우선시하는 신호 (중요도 순):

1. **완주율** — 끝까지 본 비율
2. **저장** — "나중에 다시 볼게" 행동
3. **공유/DM** — 친구에게 보내기
4. **댓글** — 논쟁 유발 시 폭발
5. **좋아요** — 가장 낮은 가중치

## 3. 시나리오별 바이럴 가공 아이디어

### 3.1 훅 강화: "클리프행어 오프닝"

현재 1컷은 평화로운 일상에서 시작하여 3초 안에 관심을 못 잡는다.

**개선 방법 — 결과 컷을 먼저 보여주는 역순 구조:**

```
기존:     [일상] → [발단] → [갈등] → [선택지]
개선:  [갈등 한가운데] → (회상) [일상] → [발단] → [선택지]
```

**예시 — #1 전 애인 사진:**

```
❌ 현재: "오빠 폰으로 사진 좀 볼게~" (평화롭게 시작)
✅ 개선: 화면이 시작하자마자 여자친구의 굳은 표정 + "...이 사진 뭐야?" 클로즈업
         자막: "폰에서 이걸 발견했을 때" → 회상으로 전환
```

**시나리오에 추가할 선택적 `hook_panel` 필드:**

```json
"hook_panel": {
  "description": "첫 1-3초 훅 컷. 결과 또는 갈등의 절정을 먼저 보여줌",
  "dialogue": { "여자친구": "(굳은 표정으로) ...이 사진 뭐야?" },
  "composition": "여자친구 얼굴 클로즈업. 충격 표정. 화면 전체 채움."
}
```

---

### 3.2 댓글 CTA 강화: "A vs B 댓글 투표"

현재 마지막 컷은 "당신이라면?"만 있어 구체적 행동 지시가 없다.

**개선 — 마지막 컷 나레이션에 이모지 투표 추가:**

```
현재: "당신이라면?"
개선: "당신의 선택은? 👇
       A: [선택지1] → 🙋 댓글
       B: [선택지2] → 🤷 댓글"
```

**카테고리별 CTA 템플릿:**

| 카테고리  | CTA 문구                                         |
| --------- | ------------------------------------------------ |
| 연애      | "내 얘기라고 느낀 사람 🙋 댓글에 네 선택 달아줘" |
| 직장      | "공감되면 저장해두고 직장 동료한테 보여줘 😅"    |
| 재테크    | "친구한테 태그해서 어떻게 생각하는지 물어봐"     |
| 음식/취향 | "틀린 쪽 이모지 👍👎 댓글 달아 (논쟁 시작 🔥)"   |

**시나리오에 추가할 `cta` 필드:**

```json
"cta": {
  "comment_prompt": "A면 🙋 B면 🤷 댓글로 알려줘",
  "save_prompt": "나중에 친구한테 보여줄 것 같으면 저장",
  "tag_prompt": "이런 상황 겪은 사람 태그 ↓"
}
```

### 3.3 논란 강도 조정: "분노 트리거" 버전

같은 시나리오를 톤에 따라 2가지로 변형:

| 버전              | 특징                     | 댓글 유형            |
| ----------------- | ------------------------ | -------------------- |
| **공감형** (현재) | "나도 이런 적 있어"      | 경험 공유 댓글       |
| **분노형** (추가) | "이거 실화야?" 수준 과장 | 논쟁 댓글, 친구 태그 |

**예시 — #4 퇴근 카톡 분노형 1컷:**

```
공감형: "(수건으로 머리 닦으며) 아~ 퇴근하니까 살 것 같다~"
분노형: "(폰을 보고 얼어붙으며) 팀장님이... 퇴근 3시간 후에 카톡을??"
         자막 오버레이: "이거 진짜 선 넘은 거 아님?"
```

---

### 3.4 루프 구조: 재시청률 2배

끝 컷에서 첫 컷으로 자연스럽게 이어지는 구조.

**방법:**

- 마지막 나레이션을 첫 컷 상황으로 다시 연결
- "어떻게 할지 아직 모르겠어?" → 1컷 장면 짧게 반복 → 투표 선택지

**예시 루프 시퀀스:**

```
[훅: 갈등 장면] → [기: 상황 설명] → [승: 발단] → [전: 딜레마]
      ↑                                                    ↓
      └─────── [결: "당신이라면?" + 갈등 장면 1초 반복] ←──┘
```

### 3.5 음악/사운드 가이드

시나리오에 `bgm_mood` 필드 추가 권장:

```json
"bgm_mood": "긴장감 고조 → 드럼롤 → 정적",
"sound_effects": ["카톡 알림음", "심장박동", "정적"]
```

**카테고리별 BGM 전략:**

| 카테고리    | 권장 BGM 무드              | 효과        |
| ----------- | -------------------------- | ----------- |
| 연애 갈등   | 긴장감 현악 or 감성 피아노 | 감정 이입   |
| 직장 딜레마 | 무거운 드럼 비트           | 공감 + 분노 |
| 재테크/생활 | 가벼운 뮤직박스            | 친근함      |
| 음식/취향   | 신나는 팝                  | 코믹함      |
| 논란 오프닝 | 정적 → 갑자기 강한 비트    | 스크롤 멈춤 |

트렌딩 오디오 사용 시 인게이지먼트 **42% 상승** (2026 Instagram 내부 데이터).

## 4. 시리즈 기획: 팔로우 유도 구조

단발 콘텐츠보다 시리즈가 팔로워 전환율 3-5배 높음.

### 제안 시리즈 구성

```
📱 HotPick 만화 시리즈
   ├── [연애 논란] ep.1 비밀번호 공유
   ├── [연애 논란] ep.2 전 애인 사진
   ├── [직장 현실] ep.1 퇴근 카톡
   ├── [직장 현실] ep.2 야근 수당
   ├── [돈 얘기] ep.1 소개팅 밥값
   └── [돈 얘기] ep.2 축의금
```

**시리즈 캡션 공식:**

```
[연애 논란 ep.2] 전 애인 사진 🔥

이거 진짜 지워야 할까?

A: 지워야 한다 🗑️
B: 상관없다 🤷

👇 댓글에 네 답 달아줘

ep.1 봤어? (링크 프로필에)
팔로우하면 다음 논란 알림 받아
```

## 5. 포맷별 릴스 변형 방안

같은 시나리오를 여러 포맷으로 재활용:

### 5.1 만화 컷 슬라이드형 (현재 기획)

- 컷당 3-5초씩 전환
- 페이지 넘기는 효과로 만화 느낌
- 총 15-25초

### 5.2 "나만 이래?" POV형

- 1인칭 시점으로 재구성
- 화면에 텍스트 오버레이만 사용 (간단 제작 가능)
- 예: "퇴근하고 샤워하는데 팀장님 카톡 옴. 어떻게 해?" 단순 텍스트

### 5.3 인터랙티브형 (고난도)

- 마지막에 화면을 좌우로 기울이면 선택지가 나오는 연출
- "이 화면 기울여봐 → 네 답이 뭔지 나와" 방식

### 5.4 댓글 투표 결과 공개형 (팔로우 유지)

- 1차 릴스: 시나리오 + 투표
- 2차 릴스: "지난 투표 결과 나왔어 👀 예상했어?"
- 연속 시청 유도

## 7. 우선순위 액션 플랜

### 즉시 적용 (시나리오 수정으로 해결)

1. **기존 시나리오에 `hook_panel` 추가** — 훅 강화 (1-2시간)
2. **마지막 컷 나레이션에 댓글 CTA 문구 추가** — 행동 유도 (30분)

### 단기 (신규 시나리오 작성 시 반영)

3. **`reels_meta` 필드 포함** — 제작팀에 정보 제공
4. **`bgm_mood` 지정** — 편집 가이드

### 중기 (콘텐츠 전략)

5. **카테고리별 시리즈 기획** — 팔로우 유지율 향상
6. **댓글 결과 공개 후속편** — 재방문 유도

## 8. 경쟁 포맷 vs HotPick 비교

| 포맷                    | 사례                     | HotPick 차이점                           |
| ----------------------- | ------------------------ | ---------------------------------------- |
| 연애 상황극 (배우 출연) | 틱톡 상황극 계정         | 만화라 제작 비용 낮음 + 반복 재활용 가능 |
| 텍스트 카드 투표        | "이거 맞아 vs 틀려" 논쟁 | 시각적 스토리가 있어 감정 투자 높음      |
| 인스타툰                | 개인 일상 만화           | 투표 참여 구조로 인터랙션 강제 유도      |
| 설문조사 스토리         | 단순 양자 선택           | 사연 + 갈등이 있어 맥락 제공             |

**HotPick의 핵심 경쟁력**: 사연 기반 만화(공감) + 투표(참여) + 논쟁(확산) 3박자가 하나의 포맷에 있음.

## 9. 파일럿 제작 로드맵 (지금 당장 할 것)

### Phase 1 — 검증 (1~2주)

바이럴 잠재력 1위 시나리오 1개로 먼저 테스트:

```
대상: #8 소개팅 밥값 (virality_rank: 1)
포맷: 만화 컷 슬라이드형 (28초)
참고: docs/contents/reels-viral-strategy.md 섹션 10 (완전한 스크립트)
목표: 완주율 60% 이상, 댓글 좋아요의 3% 이상 확인
```

**제작 순서:**

1. 시나리오 JSON → 만화 컷 4장 제작 (일러스트레이터)
2. `hook_panel` 첫 컷 제작 (정적 + 클로즈업)
3. `reels-production-template.md` 타임라인으로 편집
4. 캡션: `reels_meta.cta.comment_prompt` 활용
5. 해시태그: `#소개팅 #연애고민 #밥값 #hotpick #공감만화`

### Phase 2 — 최적화 (2~4주)

1차 성과 데이터를 보고 포맷 조정:

| 완주율 결과 | 액션                              |
| ----------- | --------------------------------- |
| 60% 미만    | 훅 컷 변경, 영상 길이 단축        |
| 60~75%      | 현 포맷 유지, CTA만 강화          |
| 75% 이상    | 2위 시나리오도 같은 포맷으로 제작 |

### Phase 3 — 시리즈 확장 (1개월~)

2개 이상 성과 확인 후 시리즈 체계화:

```
연애 논란: ep.1(비밀번호) → ep.2(전 애인 사진) → ep.3(소개팅 밥값) → ep.4(동거)
직장 현실: ep.1(퇴근 카톡) → ep.2(출퇴근 vs 월세) → ep.3(AI 불안)
인간관계: ep.1(돈 빌려달라) → ...
돈 얘기: ep.1(축의금) → ...
```

**시리즈 효과**: 첫 영상 본 사람 → 다음 에피소드 시청 → 팔로우

| 🥇 1 | #8 소개팅 밥값           | 5      | 4      | 5      | 5    | 4    | **23/25** |
| 🥈 2 | #4 퇴근 카톡             | 4      | 5      | 5      | 4    | 5    | **23/25** |
| 🥉 3 | #1 전 애인 사진          | 4      | 5      | 4      | 5    | 3    | **21/25** |

| 5    | #15 비밀번호 공유        | 3      | 4      | 3      | 4    | 3    | **17/25** |
| 6    | #7 출퇴근 vs 월세        | 2      | 5      | 4      | 3    | 3    | **17/25** |

### 랭킹 해설
