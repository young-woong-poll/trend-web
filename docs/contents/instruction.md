# HotPick 콘텐츠 가이드라인

## 1. 콘텐츠 철학

### 1.1 핵심 포지셔닝

HotPick은 **"보편적 상황에 대한 대중 의견 확인"** 플랫폼이다.

| 구분        | 커뮤니티 (블라인드, 에타 등)          | HotPick                                                 |
| ----------- | ------------------------------------- | ------------------------------------------------------- |
| 유저 심리   | "나 이런 상황인데 어떡해?"            | "이런 상황이면 사람들은 보통 어떻게 생각해?"            |
| 핵심 가치   | 조언을 구하러 간다                    | 내 생각이 다수인지 확인하러 온다                        |
| 결과물      | 댓글 3~4개 (대중 의견인지 알 수 없음) | "73% vs 27%, 참여자 2,400명" (정량적 다수 의견)         |
| 쾌감 포인트 | 공감 댓글                             | "역시 나랑 같은 생각이 많네" / "어 의외로 반대가 많네?" |

> 커뮤니티가 절대 줄 수 없는 가치 = **정량적 다수 의견 확인**

### 1.2 콘텐츠 믹스 전략 (B 기반 + A 얹기)

| 유형           | 비중 | 역할               | 예시                                                       |
| -------------- | ---- | ------------------ | ---------------------------------------------------------- |
| **고민형 (B)** | ~70% | 리텐션 확보        | "연인이 전 애인 사진 안 지우면?", "축의금 5만원 vs 10만원" |
| **논란형 (A)** | ~30% | 신규 유입 (바이럴) | 시의성 이슈, 월드컵, 사회적 화제                           |

**작동 구조:**

1. 논란형 콘텐츠가 커뮤니티/SNS에서 신규 유저를 끌어옴
2. 신규 유저가 피드에서 "너도 이런 고민 있지?" 같은 고민형 콘텐츠를 발견
3. 자연스럽게 추가 투표 참여 → 리텐션으로 전환

## 2. 좋은 싱글 핫픽의 기준: 3초 룰

**주제를 읽고 3초 안에 한쪽을 고를 수 있어야 한다.**

### 2.1 4가지 필수 조건

#### 조건 1: 즉시 이해 — 배경 설명 없이 상황이 그려질 것

배경 설명 없이 한 줄로 상황이 그려지고, 누구나 즉시 한쪽을 고를 수 있는 주제여야 한다. 장황한 설명이 필요한 고민은 HotPick에 맞지 않는다.

| 판정 | 예시                                                                         | 이유                          |
| ---- | ---------------------------------------------------------------------------- | ----------------------------- |
| O    | "연인이 전 애인 사진 안 지우면?"                                             | 누구나 바로 상황이 떠오름     |
| X    | "3년 사귄 여자친구가 전 남친이랑 같은 동네 사는데 전 애인 사진을 안 지우면?" | 배경이 특수함 → 커뮤니티 영역 |

**원칙:** 배경이 특수해질수록 커뮤니티 영역으로 넘어간다.

#### 조건 2: 대등한 선택지 — 정답이 뻔하면 안 됨

진짜 의견이 갈리는 주제여야 탭하고 싶어진다.

| 판정 | 예시                                         | 이유                         |
| ---- | -------------------------------------------- | ---------------------------- |
| O    | "축의금 5만원 vs 10만원"                     | 진짜 갈리는 주제             |
| X    | "부모님 말 잘 들어야 한다 vs 안 들어도 된다" | 정답이 뻔함 → 투표 동기 없음 |

#### 조건 3: 결과 궁금증 — "사람들은 보통 어떻게 생각할까?"

- 투표의 핵심 동기는 **결과에 대한 호기심**
- 80:20으로 예상되는 주제보다, **50:50에 가까울 것 같은 주제**가 훨씬 매력적

#### 조건 4: 보편성 — "이거 내 얘기잖아"

- 개인화 없이도 공감을 유발하는 **생애주기별 공통 고민**을 활용
- 타겟 연령대(20~40대 남성) 누구든 스크롤하다 자기 고민을 만나게 배치

## 3. 콘텐츠 기피 기준

아래 주제는 바이럴 가능성이 있어도 **브랜드 리스크**가 크므로 제외한다. 초기에 이 선을 확실히 그어야 향후 UGC 오픈 시에도 기준이 된다.

| 기피 영역      | 이유                                  |
| -------------- | ------------------------------------- |
| 정치           | 진영 갈등 유발, 브랜드 이미지 훼손    |
| 종교           | 민감한 신앙 영역, 혐오 표현 전이 위험 |
| 특정 집단 혐오 | 성별/지역/세대 등 혐오로 확산 가능    |

## 4. 콘텐츠 탈락 기준 (킬 필터)

3초 룰을 통과해도 아래에 해당하면 탈락시킨다.

### 4.1 한쪽으로 쏠리는 질문

대다수가 같은 답을 고를 게 뻔한 질문은 투표 동기가 없다.

| 탈락                                 | 이유                      |
| ------------------------------------ | ------------------------- |
| "육아휴직, 아빠도 꼭 써야 할까?"     | "당연히 써야 한다"로 쏠림 |
| "식당 직원에게 반말하는 사람?"       | "안 된다"로 쏠림          |
| "결혼 적정 나이가 있다고 생각해요?"  | "없다, 준비되면"으로 쏠림 |
| "퇴근 후 공부, 현실적으로 가능할까?" | 뻔한 자기계발 질문        |

### 4.2 너무 사소한 질문

투표까지 할 만큼의 무게감이 없으면 스크롤을 멈추지 않는다.

| 탈락                      | 이유               |
| ------------------------- | ------------------ |
| "결혼식 뷔페 몇 번 리필?" | 고민이 아니라 취향 |
| "택시 문 세게 닫는 사람?" | 투표 동기 약함     |
| "약속 장소 누가 정하나?"  | 사소함             |

### 4.3 이미 비슷한 질문이 있음

같은 카테고리에서 구조가 겹치면 하나만 남긴다.

| 탈락                  | 이유                                  |
| --------------------- | ------------------------------------- |
| "장례식 부의금 얼마?" | 축의금 질문과 구조 동일 (금액 맞추기) |
| "장례식장에서 화투?"  | 요즘 안 하는 문화                     |

### 4.4 수치/스펙 비교형 질문

개인 편차가 크고, "대중 의견 확인"보다 "내 수준 비교"가 되어 공감보다 위축을 유발한다.

| 탈락                                | 이유                         |
| ----------------------------------- | ---------------------------- |
| "사회초년생 연봉인상 금액?"         | 개인 편차 큼, 비교 심리 유발 |
| "연봉 얼마부터 잘 번다고 느껴져요?" | 같은 맥락                    |
| "이직할 때 연봉 최소 몇 % 올라야?"  | 같은 맥락                    |

### 4.5 투표보다 자기 성찰에 가까운 질문

투표 결과를 봐도 "그래서?" 가 되는 질문. 행동 결정이 아니라 내면 탐색 영역.

| 탈락                                 | 이유                  |
| ------------------------------------ | --------------------- |
| "10년 후의 나, 상상이 되나요?"       | 결과를 봐도 의미 없음 |
| "외모 관리에 돈 쓰는 거 사치인가요?" | "자기 관리다"로 쏠림  |

## 5. 좋은 질문으로 다듬는 기준

탈락 대상이 아니라도, 다음 기준으로 질문을 더 날카롭게 다듬는다.

### 5.1 상황에 긴장감 추가하기

평범한 질문에 미묘한 갈등 상황을 얹으면 투표 욕구가 올라간다.

| Before                             | After                                                       |
| ---------------------------------- | ----------------------------------------------------------- |
| "친구한테 돈 빌려달라고 하면?"     | "몇년만에 연락 온 친구가 너무 힘들다고 돈 빌려달라고 하면?" |
| "내 집 마련, 30대 안에 해야 할까?" | "2026년 무주택자, 내 집 마련해야할까?"                      |

### 5.2 타겟 맥락 끼우기

20~40대 직장인이 바로 자기 상황으로 느끼도록 장면을 좁힌다.

| Before                                      | After                                       |
| ------------------------------------------- | ------------------------------------------- |
| "엘리베이터에서 모르는 사람한테 인사?"      | "회사 엘리베이터에서 모르는 사람한테 인사?" |
| "부모님이랑 여행, 1년에 한 번은 가야 할까?" | "부모님 환갑 & 칠순 여행, 가야 할까?"       |

### 5.3 선택지를 구체적으로

추상적인 선택지보다 구체적인 수치/상황이 고르기 쉽다.

| Before                               | After                                                         |
| ------------------------------------ | ------------------------------------------------------------- |
| "더치페이 1원 단위까지 나눠야 할까?" | "더치페이, 어느 단위까지? — 십원까지 / 백원 단위 / 천원 단위" |
| "인스타에 일상 올리는 거?"           | "인스타 스토리 매일 올리는 거?"                               |

### 5.4 "둘 다" / "상황에 따라" 선택지 지양

모든 갈등을 무마하는 도피처 선택지가 있으면 그쪽으로 몰린다. 유저를 양자택일로 몰아넣어야 투표가 재밌다.

| 지양                 | 이유                                      |
| -------------------- | ----------------------------------------- |
| "둘 다 의지 문제"    | 도피처 — 삭제하면 헬스장 vs 홈트가 살아남 |
| "상황에 따라 다르다" | 모든 질문에 해당돼서 의미 없음            |

## 6. 콘텐츠 자가 체크리스트

새로운 싱글 핫픽을 기획할 때 아래 항목을 모두 통과하는지 확인한다.

| #   | 체크 항목                         | 기준                                    |
| --- | --------------------------------- | --------------------------------------- |
| 1   | 3초 안에 한쪽을 고를 수 있는가?   | 주제를 읽고 즉시 선택 가능              |
| 2   | 한 줄로 상황이 그려지는가?        | 배경 설명 없이 보편적 상황 전달         |
| 3   | 선택지가 대등한가?                | 예상 비율이 50:50에 가까운지            |
| 4   | 결과가 궁금한가?                  | "사람들은 어떻게 생각할까?" 호기심 유발 |
| 5   | 기피 주제에 해당하지 않는가?      | 정치/종교/특정 집단 혐오 아닌지         |
| 6   | 커뮤니티가 아닌 HotPick 영역인가? | "보편적 대중 의견 확인"에 부합하는지    |
| 7   | 한쪽으로 쏠리지 않는가?           | 도덕적 정답이 뻔한 질문 아닌지          |
| 8   | 사소하지 않은가?                  | 투표까지 할 만큼의 무게감이 있는지      |
| 9   | 비슷한 질문이 이미 없는가?        | 같은 구조의 중복 질문 아닌지            |
| 10  | 수치 비교가 아닌가?               | 공감이 아니라 위축을 유발하진 않는지    |
| 11  | "둘 다" 도피처가 없는가?          | 양자택일로 몰아넣는 구조인지            |
