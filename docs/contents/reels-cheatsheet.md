# HotPick 릴스 제작 치트시트

> 시나리오 → 바이럴 릴스 변환 1페이지 요약

---

## 제작 순서 (5단계)

```
1. 시나리오 선택    →  virality_rank 1위부터
2. 훅 컷 제작      →  hook_panel의 클로즈업 장면
3. 본편 4컷 제작   →  panels[] 순서대로
4. CTA 추가        →  cta.comment_prompt 텍스트
5. 캡션 작성       →  아래 공식 사용
```

---

## 영상 구조 (28~30초)

| 구간   | 길이    | 내용                      | JSON 필드               |
| ------ | ------- | ------------------------- | ----------------------- |
| 훅     | 0~3초   | 갈등 클로즈업 + 상단 자막 | `reels_meta.hook_panel` |
| 본편   | 3~20초  | 4컷 (컷당 3~5초)          | `panels[]`              |
| 선택지 | 20~25초 | 분할 연출                 | `panels[-1]`            |
| CTA    | 25~28초 | 댓글 투표 유도            | `reels_meta.cta`        |
| 루프   | 28~30초 | 훅 1.5초 반복             | —                       |

---

## 훅 공식

```
❌ 나쁜 훅: "안녕하세요~" / 일상 장면으로 시작
✅ 좋은 훅: 갈등이 이미 터진 순간 클로즈업
           + 상단 자막: "[상황] 했을 때"

예: "소개팅 계산할 때 이 정적 아는 사람?"
예: "퇴근하고 쉬는데 팀장님 카톡 왔을 때"
예: "3년 만에 연락온 친구 카톡 봤을 때"
```

---

## CTA 공식

```
[선택지A] [이모지A]  vs  [선택지B] [이모지B]

👇 댓글로 투표해줘

[저장/태그 유도 1줄]
```

---

## 캡션 공식

```
[훅 문장 — 공감 유발]

A [선택지1] [이모지]
B [선택지2] [이모지]
(C [선택지3] [이모지])

👇 댓글로 투표해줘

[태그 유도]

#주제태그 #직장인공감 #연애공감 #hotpick #공감만화 #인스타툰
```

## 성과 기준

| 지표        | 목표 | 낮으면             |
| ----------- | ---- | ------------------ |
| 완주율      | 60%+ | 훅 교체, 길이 단축 |
| 저장률      | 5%+  | CTA 문구 변경      |
| 댓글/좋아요 | 3%+  | 논쟁 강도 높이기   |
| 공유/저장   | 50%+ | 태그 유도 강화     |

---

## 시리즈 구성

```
연애 논란: ep.1 비밀번호 → ep.2 전 애인 사진 → ep.3 소개팅 밥값 → ep.4 동거
직장 현실: ep.1 퇴근 카톡 → ep.2 출퇴근vs월세 → ep.3 AI 불안
인간관계: ep.1 친구 돈 빌려달라
돈 얘기:  ep.1 축의금
```
