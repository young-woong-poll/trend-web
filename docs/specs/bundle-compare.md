# 번들 가치관 비교 기능 기획서

> **작성일**: 2026-03-27
> **상태**: 설계 완료 (초안)
> **작성 목적**: 번들 Hotpick에 "가치관 비교" 기능을 결합하여, 바이럴 + 리텐션을 극대화하는 신규 피처 설계

---

## 1. 컨셉

### 1.1 한 줄 정의

> **"요즘 가장 핫한 논쟁으로 우리의 가치관을 비교해보자"**

한 주제에 관련하여 가치관이 드러나는 Hotpick 5~10개를 묶어 하나의 Bundle로 만들고, 친구·연인·동료에게 공유하면 서로의 답변을 비교할 수 있는 기능.

### 1.2 핵심 가치

| 기존 싱글 Hotpick   | 번들 가치관 비교                      |
| ------------------- | ------------------------------------- |
| "나는 어떤 편일까?" | "우리는 얼마나 통할까?"               |
| 1문항, 즉시 결과    | 5~10문항, 종합 결과                   |
| 혼자 투표           | 비교 링크로 함께 참여                 |
| 바이럴 루프 약함    | 초대 → 참여 → 비교 → 재공유 강력 루프 |

## 2. 전제 조건

- **카카오 OAuth 로그인** 필수 (번들 풀기, 비교 기능 모두)
- 회원가입 시 **고유 닉네임 필수**, 성별/생년월일 선택
- 번들 인트로/비교 링크 랜딩은 비로그인으로 열람 가능하나, 참여 시 로그인 유도

## 3. 번들 구성

### 3.1 번들 정의

- 하나의 주제(테마)에 대한 가치관이 드러나는 Hotpick 묶음
- **질문 수**: 최소 5개 ~ 최대 10개
- **번들 전용 Hotpick**: 싱글 Hotpick과 독립적인 투표 엔티티

### 3.2 투표 데이터 통합 정책

번들 전용 Hotpick은 **싱글 피드에도 동시 노출**되며, 투표 데이터를 합산한다.

- 번들에서 투표한 유저 → 싱글 피드에서 "투표 완료" 상태 표시
- 싱글에서 투표한 유저 → 번들에서도 해당 질문 "투표 완료" 처리
- 대중성 지수는 싱글+번들 합산 모수 기준으로 계산
- **중복 투표 방지**: 한쪽에서 투표하면 다른 쪽에서 재투표 불가
- **싱글에서 먼저 투표한 경우**: 번들 풀기 시 해당 질문은 이미 선택한 답변이 자동 반영되며, 유저에게 "이미 투표한 질문이에요" 안내 표시. 번들의 연속적 풀기 경험을 해치지 않도록 건너뛰지 않고 결과 확인 형태로 표시.

이를 통해 초기 모수 부족 문제를 해소하고, 유저는 "대중은 어떻게 생각하지?" 확인 가능.

### 3.3 번들 생성 주체

- **1차**: 어드민이 직접 큐레이션 (기존 Hotpick에서 선별 or 신규 생성)
- **추후**: 자동 큐레이션 (위클리 HOT 등) 및 UGC 형태 확장 고려

### 3.4 번들 큐레이션 유형

| 유형           | 설명                                    | 갱신 주기    | 예시                                        |
| -------------- | --------------------------------------- | ------------ | ------------------------------------------- |
| **테마 번들**  | 특정 주제로 묶은 고정 콘텐츠            | 상시         | "결혼 가치관", "직장인 생존", "연애 스타일" |
| **시즌 번들**  | 계절·시기에 맞는 테마 큐레이션          | 월 1~2회     | "2026 여름휴가 밸런스 게임"                 |
| **위클리 HOT** | 해당 주 최다 투표 Hotpick 자동 큐레이션 | 매주         | "이번 주 HOT 7"                             |
| **이슈 번들**  | 시의성 있는 이슈 모음                   | 이슈 발생 시 | "AI 시대 논쟁 TOP 5"                        |

### 3.5 테마 번들 예시

#### 결혼 가치관 테스트 (5문항)

1. 혼수 비용, 각자 알아서 vs 반반
2. 맞벌이 vs 한쪽이 집에
3. 신혼집 매매 vs 전세
4. 시댁·처가 명절 매년 vs 격년
5. 아이 교육 사교육 vs 자율

#### 직장인 생존 테스트 (5문항)

1. 연봉 500 올려주는 이직 vs 편한 현 직장
2. 칼퇴 vs 야근하고 성과급
3. 좋은 상사 + 별로인 일 vs 별로인 상사 + 좋아하는 일
4. 대기업 안정 vs 스타트업 스톡옵션
5. 퇴근 후 업무 카톡 답장 vs 무시

#### 연애 스타일 테스트 (5문항)

1. 썸 탈 때 먼저 연락 vs 기다리기
2. 연인 전 애인 사진 지워야 함 vs 상관없음
3. 기념일 챙기는 편 vs 별로
4. 연인 이성 친구 만남 OK vs NO
5. 싸우면 바로 풀기 vs 혼자 정리하고 대화

## 4. 사용자 플로우

### 4.1 번들 풀기 (공통)

```
[메인 피드]
  │ 번들 카드 탭
  ▼
[번들 인트로 페이지]  ← 비로그인도 열람 가능
  │ 테마 소개 + "시작하기" CTA
  │ (미로그인 시 카카오 로그인 유도)
  ▼
[질문 1/N] → [질문 2/N] → ... → [질문 N/N]
  │ 프로그레스 바 표시
  │ 각 질문 = 번들 전용 Hotpick (2지선다)
  ▼
[내 결과 확인]
  │ 종합 결과 카드 + 각 질문별 내 선택 요약
  │ 대중성 지수 + 대중성 캐릭터
  ├──▶ "1:1 비교하기" CTA
  └──▶ "그룹 비교하기" CTA
```

### 4.2 비교 링크 종류

| 타입          | 설명            | 특징                                |
| ------------- | --------------- | ----------------------------------- |
| **1:1 비교**  | 특정 1명과 비교 | 1명만 참여 가능                     |
| **그룹 비교** | 여러 명과 비교  | 그룹 이름 + 최대 인원 설정 (2~20명) |

비교 링크는 **번들을 모두 풀었을 때만** 생성 가능.

### 4.3 1:1 비교 흐름

```
[내 결과 페이지] → "1:1 비교하기"
  │
  ▼
[1:1 비교 링크 생성]
  │ 공유 방법: 카카오톡 / 링크 복사
  │ 공유 메시지: "{닉네임}님이 가치관 대결을 신청했어요!"
  ▼
[상대방이 링크 클릭]
  │
  ├─ 이미 번들 완료 → 바로 비교 결과 페이지
  │
  └─ 아직 미완료
      │ 안내: "{닉네임}님과의 비교 결과가 기다리고 있어요!"
      ▼
      [번들 풀기] → [완료] → [비교 결과 페이지]
```

### 4.4 그룹 비교 흐름

```
[내 결과 페이지] → "그룹 비교하기"
  │
  ▼
[그룹 생성]
  │ 그룹 이름 입력 (예: "마케팅팀")
  │ 최대 인원 설정 (2~20명)
  │ → 그룹 링크 생성
  ▼
[단톡방 등에 링크 공유]
  │
  ▼
[멤버들이 링크 클릭]
  │ 안내: "{닉네임}님의 '{그룹이름}' 그룹에 참여하세요!"
  ├─ 이미 완료 → 그룹 합류 → 비교 결과
  └─ 미완료 → 안내 + 번들 풀기 → 완료 후 그룹 합류
```

- 같은 비교 링크로 들어온 사람들이 하나의 **그룹**으로 묶임
- 그룹 내 멤버끼리 **크로스 1:1 비교** 가능
- 그룹 전체 **통계/인사이트** 제공
- 생성자가 원하는 시점에 **그룹 마감** 가능 (더 이상 합류 불가)
- 같은 번들에 **여러 그룹 생성** 가능 (예: "회사 동료" 그룹, "대학 친구" 그룹)

### 4.5 이미 둘 다 풀었으면 바로 비교

비교 링크 없이도, 해당 번들을 이미 둘 다 완료한 상태이고 같은 비교 그룹에 속해 있다면 바로 비교 결과를 확인할 수 있다.

### 4.6 비교 관리

```
[마이페이지 또는 번들 결과 페이지]
  │
  ▼
[내가 푼 번들 목록]
  │
  ├─ 결혼 가치관 ──┬─ 1:1: vs 수진 (케미 A)
  │                ├─ 1:1: vs 영희 (케미 B)
  │                ├─ 그룹: "마케팅팀" (4/5명 참여)
  │                └─ 그룹: "대학 동기" (7/10명 참여, 마감)
  │
  └─ 직장인 생존 ──┬─ 1:1: vs 철수 (케미 S)
                   └─ 그룹: "개발팀" (3/8명 참여)
```

## 5. 비교 결과 시스템

### 5.1 케미 등급 체계

| 일치율  | 등급 | 타이틀        | 한줄평                                           |
| ------- | ---- | ------------- | ------------------------------------------------ |
| 90~100% | S    | 🔥 소울메이트 | "전생에 한 몸이었나? 생각이 이렇게 같을 수가"    |
| 70~89%  | A    | 💜 찰떡궁합   | "대부분 통하는데, 가끔 깜짝 놀랄 포인트가!"      |
| 50~69%  | B    | ⚡ 밀당 케미  | "반은 같고 반은 다르고, 이게 진짜 케미 아닐까?"  |
| 30~49%  | C    | 🌀 반전 매력  | "다른 점이 더 많아서 오히려 재밌는 사이"         |
| 0~29%   | D    | 👽 평행우주   | "같은 세상 살고 있는 거 맞아? 그래도 그게 매력!" |

> 모든 등급이 긍정적 톤을 유지한다. 낮은 일치율도 "재미 포인트"로 전환.

### 5.2 번들 테마별 맞춤 해석

번들 생성 시 어드민이 등급별 맞춤 문구를 설정한다. 같은 S등급이라도 테마마다 다른 재미를 준다.

| 테마        | S등급                           | D등급                                 |
| ----------- | ------------------------------- | ------------------------------------- |
| 결혼 가치관 | "이 정도면 혼인신고 바로 가능"  | "결혼 전 진지한 대화가 필요할지도..." |
| 직장인 생존 | "같은 팀 하면 시너지 폭발할 듯" | "회의 때 싸울 확률 99%"               |
| 연애 스타일 | "이상형이 서로인 거 아닌가요?"  | "밀당의 신이 탄생했습니다"            |

### 5.3 1:1 비교 결과 구성 (재미 위주)

#### 케미 카드 (상단)

- 케미 등급 + 타이틀 + 테마별 맞춤 한줄평
- 일치율 % 크게 표시
- 등급별 포인트 색상 차별화

#### 가장 충격적인 차이

다른 답을 고른 질문 중, 대중 투표에서 비율이 가장 극단적으로 갈린 질문을 "충격 포인트"로 강조.

```
😱 가장 충격적인 차이

"시댁 명절 매년 vs 격년"

민수: 매년 (대중 27%)
수진: 격년 (대중 73%)

"민수님, 이건 좀 양보하셔야..."
```

상대방이 다수파인데 나는 소수파인 경우 더 재밌는 코멘트 생성.

#### 대중성 포지션 비교

각자의 대중성 지수(다수파와 같은 답 비율)를 비교하여 캐릭터 부여.

```
대중성 지수 = (다수파와 같은 답 개수 / 전체 질문 수) × 100
```

| 대중성 | 캐릭터         | 설명                          |
| ------ | -------------- | ----------------------------- |
| 90%+   | 👑 여론 장악자 | "대중의 마음을 꿰뚫어 봄"     |
| 70~89% | 🐻 트렌드 리더 | "시대를 읽는 눈이 있음"       |
| 50~69% | ⚖️ 밸런서      | "어느 쪽이든 이해하는 균형파" |
| 30~49% | 🦊 소신파      | "남들과 다른 길을 가는 타입"  |
| ~29%   | 🦄 유니콘      | "세상에 없는 독보적 가치관"   |

#### "같은 편인 순간 / 갈린 순간" 스토리텔링

단순 나열이 아니라, 같은 답들의 공통점을 한 문장으로 요약.

```
🤝 우리가 같은 편인 순간 (3/5)

"혼수는 각자, 맞벌이는 당연, 신혼집은 전세부터!"
→ 현실적인 결혼 준비를 지향하는 두 사람. 큰 그림에선 통한다!

🔥 우리가 갈린 순간 (2/5)

· 명절: 민수 "매년" vs 수진 "격년"
· 육아: 민수 "어린이집" vs 수진 "직접"
→ 가족·육아 관련해서 대화가 필요한 포인트!
```

어드민이 번들 생성 시 질문 조합별 해석 문구를 설정.

### 5.4 그룹 비교 결과 구성 (인사이트 위주)

#### 그룹 통계

- **그룹 싱크율**: 그룹 전체 평균 일치율
- **만장일치 질문**: 전원이 같은 답을 고른 질문 (🏆 만장일치 뱃지)
- **논쟁 포인트**: 가장 의견이 갈린 질문 (🔥 논쟁 포인트 뱃지)
- **질문별 답변 분포**: 가로 막대 차트로 비율 시각화

#### 가치관 지도 (클러스터링 점도표)

- 2D 공간에 멤버들의 포지션을 점으로 표시
- 축: 번들 테마에 따라 의미 있는 축 설정 (예: 현실주의↔이상주의, 보수↔진보)
- 그룹 평균 영역을 점선 원으로 표시
- 주류에 가까운 사람과 멀리 떨어진 아웃라이어가 시각적으로 구분됨

#### 케미 네트워크

- 멤버 간 1:1 궁합을 관계도로 시각화
- 선 두께 = 케미 등급 (두꺼울수록 높은 궁합)
- 등급별 색상 차별화 (S: 골드, A: 퍼플, B: 오렌지, C: 블루, D: 그린)

#### 그룹 어워드 (칭호 자동 부여)

| 칭호           | 기준                              | 한줄평                                      |
| -------------- | --------------------------------- | ------------------------------------------- |
| 🏆 그룹 대장   | 그룹 평균과 가장 일치율 높은 사람 | "이 그룹의 가치관을 대표합니다"             |
| 🦊 그룹 이단아 | 그룹 평균과 가장 먼 사람          | "혼자만 다른 세계에 사는 중"                |
| 💜 소울 커넥션 | 그룹 내 최고 1:1 궁합 조합        | "통하는 게 느껴지나요?"                     |
| 👽 극과 극     | 그룹 내 최저 1:1 궁합 조합        | "토론하면 밤새겠다"                         |
| ⚡ 논쟁 메이커 | 가장 많이 소수파에 속한 사람      | "매번 반대편에 서는 당신, 혹시 일부러?"     |
| 👑 대중의 왕   | 대중성 지수가 가장 높은 사람      | "세상이 어떻게 돌아가는지 정확히 아는 사람" |

#### 멤버별 1:1 비교 리스트

- 각 멤버와의 케미 등급 + 일치율 표시
- 탭하면 1:1 상세 비교로 이동

#### 그룹 간 내 포지션 비교

같은 번들을 여러 그룹에서 비교했을 때, 그룹마다 내 대중성 캐릭터가 달라질 수 있음.

```
"마케팅팀"에서 나는: 🐻 트렌드 리더 → 그룹 평균과 비슷
"대학 동기"에서 나는: 🦊 소신파 → 이 그룹에선 꽤 독특한 답변

"같은 가치관이라도 누구와 비교하느냐에 따라 나의 포지션이 달라져요!"
```

### 5.5 결과 공유

- **링크 공유**: 비교 결과 웹 페이지 링크 (카카오톡, 링크 복사)
- **이미지 저장**: 비교 결과를 카드 이미지로 생성하여 다운로드/공유 (인스타 스토리, 카카오톡 등)

#### 이미지 카드 사이즈

| 용도          | 비율 | 사이즈      |
| ------------- | ---- | ----------- |
| 카카오톡 공유 | 1:1  | 800 x 800   |
| 인스타 스토리 | 9:16 | 1080 x 1920 |
| 인스타 피드   | 4:5  | 1080 x 1350 |
| 트위터/X      | 16:9 | 1200 x 675  |

#### 디자인 톤

- 기존 HotPick 다크 테마 (#121212 배경)
- 케미 등급별 포인트 색상 차별화
  - S등급: 골드 그라디언트
  - A등급: 마젠타-퍼플 그라디언트
  - B등급: 오렌지-마젠타 그라디언트
  - C등급: 블루-시안 그라디언트
  - D등급: 그린-시안 그라디언트
- 워터마크: 하단에 `hotpick.kr` + 슬로건

## 6. 바이럴 루프

### 6.1 비교 기능 바이럴 루프

```
A가 번들 풀기 → "비교하자!" → B에게 초대 → B가 풀기 → 비교 결과 공유
                                                              │
                                        ┌─────────────────────┤
                                        ▼                     ▼
                                  C가 보고 "나도!"       D가 보고 "나도!"
                                  → A에게 비교 요청      → B에게 비교 요청
                                  → C도 공유              → D도 공유
```

### 6.2 핵심 바이럴 요소

- **참여 의무감**: "친구가 기다리고 있음" → 안 하면 찝찝
- **대결 뉘앙스**: "{닉네임}님이 가치관 대결을 신청했어요!" → 승부욕 자극
- **비교 욕구**: "내가 더 대중적일까?" → 궁금해서 참여
- **2차 공유**: 비교 카드 자체가 새로운 콘텐츠 → 또 공유

## 7. 데이터 모델

### 7.1 엔티티 관계

```
[User] (카카오 OAuth)
  │ userId, kakaoId
  │ nickname (고유, 필수)
  │ gender? (선택)
  │ birthDate? (선택)
  │ createdAt

[Bundle]
  │ bundleId, slug, title, subtitle, description
  │ category
  │ questionCount (5~10)
  │ status: ACTIVE | CLOSED
  │ gradeMessages: { S, A, B, C, D } × 테마별 맞춤 문구
  │ createdAt, expiredAt
  │
  ├─── 1:N ───▶ [BundleElection] (번들 전용 Hotpick)
  │               │ electionId, title, voteType
  │               │ options: { A, B }
  │               │ order (질문 순서)
  │               │ linkedSingleId? (싱글 Hotpick 연동 ID)
  │               │
  │               └─── 1:N ───▶ [Vote] (싱글과 투표 데이터 공유)
  │                               │ userId, selectedOption
  │                               │ source: BUNDLE | SINGLE
  │
  ├─── 1:N ───▶ [BundleSession] (유저의 번들 완료 기록)
  │               │ sessionId, userId, nickname
  │               │ answers: [{ electionId, selected }]
  │               │ completedAt
  │               │ popularityScore (대중성 지수)
  │               │ popularityGrade (👑🐻⚖️🦊🦄)
  │
  └─── 1:N ───▶ [CompareLink] (비교 링크)
                  │ linkId, token (URL용 UUID)
                  │ creatorUserId, creatorSessionId
                  │ type: ONE_TO_ONE | GROUP
                  │ groupName? (그룹일 때)
                  │ maxMembers? (그룹일 때)
                  │ status: ACTIVE | CLOSED
                  │ createdAt, expiredAt (7일)
                  │
                  └─── 1:N ───▶ [CompareMember]
                                  │ userId, sessionId, nickname
                                  │ joinedAt
```

### 7.2 비교 결과 계산

비교 결과는 서버에서 **실시간 계산**하며, 별도 테이블에 저장하지 않는다.

- **일치율**: `(같은 답 개수 / 전체 질문 수) × 100`
- **대중성 지수**: `(다수파와 같은 답 개수 / 전체 질문 수) × 100`
- **케미 등급**: 일치율 기반 S/A/B/C/D 매핑
- **클러스터 좌표**: 답변 패턴 기반 2D 좌표 계산 (MDS 또는 PCA)

## 10. 단계별 구현 제안

### Phase 1: 번들 기본 (BE API 필수)

- 번들 CRUD (어드민)
- 번들 인트로 / 질문 풀기 / 결과 페이지
- 번들-싱글 투표 데이터 통합
- 대중성 지수 계산

### Phase 2: 1:1 비교 (핵심)

- 1:1 비교 링크 생성/공유
- 비교 링크 랜딩 (미완료 시 풀기 유도 + 안내 메시지)
- 1:1 비교 결과 (케미 등급, 충격 포인트, 대중성 비교, 스토리텔링)
- 비교 결과 이미지 생성/공유

### Phase 3: 그룹 비교

- 그룹 링크 생성 (이름 + 인원 설정)
- 그룹 비교 결과 (통계, 답변 분포, 어워드)
- 가치관 지도 (클러스터링 점도표)
- 케미 네트워크 시각화
- 그룹 마감 기능
- 그룹 간 내 포지션 비교

### Phase 4: 고도화

- 내 번들/비교 관리 페이지
- 푸시 알림 ("비교 결과가 도착했어요!")
- 위클리 HOT 자동 큐레이션
- 시즌/이슈 번들 운영 도구
