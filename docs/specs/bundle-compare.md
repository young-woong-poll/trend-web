# 번들 핫픽 — 친구 비교 기능 기획서

> **작성일**: 2026-03-08
> **상태**: 아이디어 구체화 (초안)
> **작성 목적**: 번들 핫픽에 "친구 비교" 기능을 결합하여, 바이럴 + 리텐션을 동시에 극대화하는 신규 피처 설계

---

## 1. 배경 및 문제 인식

### 1.1 현재 번들 핫픽의 한계

- BE API 미구현 상태로 기능 자체가 비활성
- 기존 번들 설계: 5개 투표 → 유형 결과 카드 → SNS 공유 (1인 체험 구조)
- **문제**: 혼자 하고 공유만 하는 구조는 공유받은 사람의 참여 동기가 약함
  - "나도 해볼까?" → 해봤자 혼자 결과만 나옴 → 바이럴 루프 단절

### 1.2 기회 포착

- MBTI 궁합, 연애 밸런스 게임 등 **"비교"** 콘텐츠가 바이럴 강세
- "혼자 하는 테스트"보다 **"둘이 비교하는 테스트"**가 공유율 3~5배 높음 (참고: 쿠키런 궁합 테스트, 16personalities 공유 패턴)
- HotPick의 핵심 가치("대중의 답을 숫자로")에 **"너와 나의 답 비교"**를 추가하면 차별점이 더 선명해짐

## 2. 컨셉 정의

### 2.1 한 줄 정의

> **"요즘 가장 핫한 논쟁으로 우리의 생각을 비교해보자"**

시즌별로 큐레이션된 테마 번들(5~10개)을 풀고, 친구·연인·동료에게 공유하면 서로의 답을 비교할 수 있는 기능.

### 2.2 핵심 가치

| 기존 번들 (1인용)     | 신규 번들 비교 (2인+)                 |
| --------------------- | ------------------------------------- |
| "나는 어떤 유형일까?" | "우리는 얼마나 통할까?"               |
| 결과 카드 → 혼자 공유 | 비교 카드 → 함께 공유                 |
| 1회성 체험            | 관계 기반 반복 체험                   |
| 바이럴 루프 약함      | 초대 → 참여 → 비교 → 재공유 강력 루프 |

### 2.3 네이밍 후보

- **핫픽 매치** (HotPick Match) — "우리 생각 매치해볼래?"
- **핫픽 VS** (HotPick VS) — "너 vs 나, 누가 더 대중적?"
- **핫픽 싱크** (HotPick Sync) — "우리 얼마나 싱크율 높을까?"
- **핫픽 케미** (HotPick Chemistry) — "우리 케미 몇 %?"

> 추천: **핫픽 매치** — 직관적이고, "매치"라는 단어가 궁합/비교/대결을 모두 포괄

## 3. 사용자 시나리오

### 3.1 시나리오 A: 연인 — "결혼 가치관 비교"

```
1. 민수가 "결혼 가치관 테스트" 번들을 발견
2. 5개 질문에 답변 (혼수 각자 vs 반반 / 맞벌이 vs 외벌이 / ...)
3. 내 결과 확인: "현실주의 결혼관" + 대중성 지수 62%
4. "연인에게 공유하기" → 카카오톡으로 초대 링크 전송
5. 여자친구 수진이가 링크 클릭 → 같은 5개 질문에 답변
6. 비교 결과 카드 생성:
   - 일치율: 3/5 (60%)
   - 같은 답: 혼수 각자, 맞벌이, 신혼집 전세
   - 다른 답: 시댁 명절(민수: 매년 / 수진: 격년), 육아(민수: 어린이집 / 수진: 직접)
   - "당신들의 결혼 케미: 60% 🔥"
7. 비교 카드를 캡처해서 인스타 스토리에 올림
8. 친구들이 보고 "나도 해볼래!" → 바이럴
```

### 3.2 시나리오 B: 직장 동료 — "직장인 가치관 비교"

```
1. 팀 회식에서 "직장인 밸런스 게임" 번들 발견
2. 동료 4명이 각자 풀기
3. 그룹 비교 카드: "이 팀의 싱크율 45% — 의외로 생각이 다른 팀!"
4. 가장 의견이 갈린 질문 하이라이트 → 회식 대화 소재
```

### 3.3 시나리오 C: 친구 그룹 — "요즘 핫한 논쟁 비교"

```
1. 이번 주 가장 투표수 많았던 핫픽 7개를 자동 큐레이션한 "이번 주 HOT 7" 번들
2. 단톡방에 공유 → 친구들이 각자 풀기
3. 그룹 내 비교: "5명 중 3명이 같은 답!"
4. 가장 소수파인 사람 하이라이트 → "너만 그렇게 생각해 ㅋㅋ"
```

## 4. 번들 큐레이션 전략

### 4.1 큐레이션 유형

| 유형           | 설명                                      | 갱신 주기    | 예시                                                             |
| -------------- | ----------------------------------------- | ------------ | ---------------------------------------------------------------- |
| **시즌 번들**  | 계절·시기에 맞는 테마 큐레이션            | 월 1~2회     | "2026 여름휴가 밸런스 게임", "연말 회식 논쟁 TOP 5"              |
| **테마 번들**  | 특정 주제로 묶은 고정 콘텐츠              | 상시         | "결혼 가치관 테스트", "직장인 생존 테스트", "연애 스타일 테스트" |
| **위클리 HOT** | 해당 주 가장 투표 많은 핫픽 자동 큐레이션 | 매주         | "이번 주 HOT 7"                                                  |
| **이슈 번들**  | 시의성 있는 이슈 모음                     | 이슈 발생 시 | "2026 총선 쟁점 5가지", "AI 시대 논쟁 TOP 5"                     |

### 4.2 번들 구성 기준

- **질문 수**: 5개 (기본) ~ 10개 (스페셜)
  - 5개: 가볍게 비교 (1~2분 소요)
  - 7개: 표준 (2~3분 소요)
  - 10개: 딥한 비교 (3~5분 소요)
- **질문 선정 기준**:
  - 테마 내에서 답이 진짜 갈리는 질문 우선 (50:50에 가까울수록 좋음)
  - 비교했을 때 대화가 생기는 질문 (정답이 없는 가치관 질문)
  - 3초 룰 적용 (싱글 핫픽과 동일)

### 4.3 테마 번들 예시

#### 결혼 가치관 테스트 (5문항)

1. 혼수 비용, 각자 알아서 vs 반반
2. 맞벌이 vs 한쪽이 집에
3. 신혼집 매매 vs 전세
4. 시댁·처가 명절 매년 vs 격년
5. 아이 교육 사교육 vs 자율

#### 직장인 생존 테스트 (5문항)

1. 연봉 500 올려주는 이직 vs 편한 현 직장
2. 칼퇴 vs 야근하고 성과급
3. 좋은 상사 + 별로인 일 vs 별로인 상사 + 좋아하는 일
4. 대기업 안정 vs 스타트업 스톡옵션
5. 퇴근 후 업무 카톡 답장 vs 무시

#### 연애 스타일 테스트 (5문항)

1. 썸 탈 때 먼저 연락 vs 기다리기
2. 연인 전 애인 사진 지워야 함 vs 상관없음
3. 기념일 챙기는 편 vs 별로
4. 연인 이성 친구 만남 OK vs NO
5. 싸우면 바로 풀기 vs 혼자 정리하고 대화

#### 소비 습관 테스트 (5문항)

1. 월급 받으면 저축 먼저 vs 쓰고 남기기
2. 비싼 거 하나 vs 저렴한 거 여러 개
3. 배달 vs 직접 요리
4. 여행 계획형 vs 즉흥형
5. 구독 서비스 많이 쓰는 편 vs 최소화

## 5. 비교 시스템 설계

### 5.1 비교 흐름

```
[A가 번들 풀기]
      │
      ▼
[A의 결과 확인] ──▶ [비교 초대 링크 생성]
                           │
                           ▼
                    [B에게 링크 공유]
                           │
                           ▼
                    [B가 같은 번들 풀기]
                           │
                           ▼
                    [비교 결과 카드 생성]
                           │
                    ┌──────┴──────┐
                    ▼             ▼
              [A가 확인]    [B가 확인]
                    │             │
                    └──────┬──────┘
                           ▼
                    [비교 카드 공유]
```

### 5.2 초대 링크 구조

```
https://hotpick.kr/hotpick/{bundle-slug}/compare?inviter={inviterToken}
```

- `inviterToken`: 초대자의 답변 세션을 식별하는 토큰 (UUID)
- 링크를 받은 사람은 동일 번들을 풀고, 완료 시 자동으로 비교 결과 페이지로 이동
- 로그인 불필요 — TKUID 기반으로 동작

### 5.3 비교 결과 데이터

```typescript
interface CompareResult {
  bundleSlug: string;
  bundleTitle: string;
  totalQuestions: number;

  inviter: {
    nickname?: string; // 선택 입력
    answers: Answer[];
    resultType: ResultType;
  };

  invitee: {
    nickname?: string;
    answers: Answer[];
    resultType: ResultType;
  };

  comparison: {
    matchCount: number; // 같은 답 개수
    matchRate: number; // 일치율 (%)
    matchedQuestions: number[]; // 같은 답 질문 인덱스
    divergedQuestions: number[]; // 다른 답 질문 인덱스
    mostControversial: number; // 가장 의견이 갈린 질문 (대중 투표 기준)
  };

  chemistry: {
    grade: 'S' | 'A' | 'B' | 'C' | 'D';
    title: string; // "소울메이트급 싱크!", "의외의 조합" 등
    description: string;
  };
}
```

### 5.4 케미 등급 체계

| 일치율  | 등급 | 타이틀        | 설명                                             |
| ------- | ---- | ------------- | ------------------------------------------------ |
| 90~100% | S    | 🔥 소울메이트 | "생각이 이렇게 같을 수가? 전생에 한 몸이었나"    |
| 70~89%  | A    | 💜 찰떡궁합   | "대부분 통하는데, 가끔 깜짝 놀랄 포인트가!"      |
| 50~69%  | B    | ⚡ 밀당 케미  | "반은 같고 반은 다르고, 이게 진짜 케미 아닐까?"  |
| 30~49%  | C    | 🌀 반전 매력  | "다른 점이 더 많아서 오히려 재밌는 사이"         |
| 0~29%   | D    | 👽 평행우주   | "같은 세상 살고 있는 거 맞아? 그래도 그게 매력!" |

> 모든 등급이 긍정적 톤을 유지한다. 낮은 일치율도 "재미 포인트"로 전환.

### 5.5 그룹 비교 (3인 이상)

- 초대 링크를 여러 명에게 공유 가능
- 그룹 비교 결과:
  - 전체 평균 일치율
  - 가장 의견이 일치한 질문 / 가장 갈린 질문
  - "이 그룹의 소수파" 하이라이트 (재미 요소)
  - 1:1 매칭 케미 그래프 (3~5명일 때)
- 그룹 인원 제한: 최대 10명 (UX 복잡도 관리)

## 7. 사용자 여정 (UX 플로우)

### 7.1 번들 진입 → 비교 초대까지

```
[메인 피드]
    │ 번들 카드 발견 (싱글 7~10개에 1개 비율)
    ▼
[번들 인트로 페이지]
    │ 테마 소개 + "시작하기" CTA
    ▼
[질문 1/5] → [질문 2/5] → ... → [질문 5/5]
    │ 스와이프 또는 탭으로 순차 진행
    │ 프로그레스 바 표시
    ▼
[내 결과 확인]
    │ 유형 카드 + 대중성 지수
    ├──▶ "내 결과 공유하기" (기존 기능)
    └──▶ "친구와 비교하기" CTA (신규 ⭐)
            │
            ▼
      [닉네임 입력 (선택)]
            │ "비교 카드에 표시될 이름이에요"
            ▼
      [초대 링크 생성 + 공유 방법 선택]
            │ 카카오톡 / 링크 복사 / 인스타 DM
            ▼
      [대기 화면 또는 피드로 복귀]
```

### 7.2 초대받은 사람의 여정

```
[카카오톡에서 링크 클릭]
    │
    ▼
[번들 인트로 페이지]
    │ "{민수}님이 비교를 기다리고 있어요!"
    │ 테마 소개 + "나도 풀어보기" CTA
    ▼
[질문 1/5] → ... → [질문 5/5]
    │ 동일 질문 순서로 진행
    ▼
[비교 결과 페이지] ⭐
    │ 1:1 비교 카드 + 케미 등급
    │ 같은 답 / 다른 답 하이라이트
    ├──▶ "비교 카드 저장하기" (이미지 다운로드)
    ├──▶ "인스타 스토리에 올리기"
    └──▶ "다른 친구도 초대하기"
```

### 7.3 푸시 알림 / 리마인더

- 초대받은 사람이 아직 안 풀었을 때: 초대자에게 "아직 대기 중" 상태 표시
- (로그인 시스템 도입 후) 푸시 알림: "{수진}님이 비교 결과를 확인했어요!"

## 8. 바이럴 루프 분석

### 8.1 기존 번들 바이럴 루프

```
A가 번들 풀기 → 결과 공유 → B가 보기 → "나도 해볼까?" → B가 풀기 → B 결과 공유 → ...
```

**문제**: B가 공유를 받아도 "혼자 하는 테스트"라서 참여 동기가 약함.

### 8.2 비교 기능 바이럴 루프

```
A가 번들 풀기 → "비교하자!" → B에게 초대 → B가 풀기 → 비교 결과 공유
                                                              │
                                        ┌─────────────────────┤
                                        ▼                     ▼
                                  C가 보고 "나도!"       D가 보고 "나도!"
                                  → A에게 비교 요청      → B에게 비교 요청
                                  → C도 공유              → D도 공유
```

**핵심 차이**:

- **참여 의무감**: "친구가 기다리고 있음" → 안 하면 찝찝
- **비교 욕구**: "내가 더 대중적일까?" → 궁금해서 참여
- **2차 공유**: 비교 카드 자체가 새로운 콘텐츠 → 또 공유
- **N차 확산**: 비교 카드를 본 제3자가 "나도 해보고 싶다" → 새로운 비교 루프

### 8.3 예상 바이럴 계수

| 지표               | 기존 번들 (추정) | 비교 기능 (목표)     |
| ------------------ | ---------------- | -------------------- |
| 완료 후 공유율     | 15~20%           | 40~60%               |
| 공유 → 참여 전환율 | 10~15%           | 30~50% (초대 의무감) |
| K-factor           | 0.02~0.03        | 0.12~0.30            |

## 9. 대중성 지수 & 비교 지표

### 9.1 대중성 지수 (기존)

각 질문에서 **다수파(50% 이상 득표)와 같은 답**을 고른 비율.

```
대중성 지수 = (다수파와 같은 답 개수 / 전체 질문 수) × 100
```

예: 5문항 중 3개가 다수파와 같음 → 대중성 지수 60%

### 9.2 비교 지표

| 지표              | 계산                                | 표시                                       |
| ----------------- | ----------------------------------- | ------------------------------------------ |
| **일치율**        | (같은 답 개수 / 전체 질문 수) × 100 | "케미 지수: 60%"                           |
| **대중성 비교**   | 각자의 대중성 지수 비교             | "민수 62% vs 수진 44% — 민수가 더 대중적!" |
| **소수파 포인트** | 다수파와 다른 답 고른 횟수          | "수진의 반골 지수: 3/5 🤘"                 |

## 10. 기술 고려사항

### 10.1 기존 시스템과의 관계

- 번들 핫픽 BE API가 아직 미구현 → **번들 API 구현이 선행 과제**
- 비교 기능은 번들 위에 얹히는 추가 레이어
- 싱글 핫픽의 투표 데이터와는 독립적으로 집계 (기존 원칙 유지)

### 10.2 필요한 신규 API (예상)

| Method | Endpoint                                                           | 설명                |
| ------ | ------------------------------------------------------------------ | ------------------- |
| POST   | `/api/v1/bundles/{slug}/sessions`                                  | 번들 답변 세션 생성 |
| PUT    | `/api/v1/bundles/{slug}/sessions/{sessionId}/answers`              | 답변 제출           |
| GET    | `/api/v1/bundles/{slug}/sessions/{sessionId}/result`               | 내 결과 조회        |
| POST   | `/api/v1/bundles/{slug}/sessions/{sessionId}/invite`               | 비교 초대 링크 생성 |
| GET    | `/api/v1/bundles/{slug}/compare?inviter={token}&invitee={token}`   | 1:1 비교 결과       |
| GET    | `/api/v1/bundles/{slug}/compare-group?session={token1,token2,...}` | 그룹 비교 결과      |

### 10.3 데이터 저장

- 답변 세션은 서버에 저장 (TKUID + sessionId)
- 비교 초대 토큰은 만료 기한 설정 (7일)
- 번들 자체는 재투표 가능 (기존 설계 유지) → 새 세션 생성

### 10.4 페이지 구성 (예상)

| 페이지      | 경로                                                      | 설명               |
| ----------- | --------------------------------------------------------- | ------------------ |
| 번들 인트로 | `/hotpick/{slug}`                                         | 번들 소개 + 시작   |
| 번들 질문   | `/hotpick/{slug}/play`                                    | 순차 질문 진행     |
| 내 결과     | `/hotpick/{slug}/result?session={id}`                     | 유형 + 대중성 지수 |
| 비교 결과   | `/hotpick/{slug}/compare?inviter={token}&invitee={token}` | 1:1 비교 카드      |
| 그룹 비교   | `/hotpick/{slug}/compare-group?sessions={tokens}`         | 그룹 비교          |

## 11. 우선순위 & 단계별 구현 제안

### Phase 1: 번들 핫픽 기본 (BE API 구현 필요)

- 번들 생성/관리 Admin API
- 번들 순차 투표 플로우
- 유형 결과 카드
- 결과 공유 (카카오톡, 이미지 저장)

### Phase 2: 1:1 비교 기능 ⭐ 핵심

- 비교 초대 링크 생성/공유
- 초대받은 사람의 투표 플로우
- 1:1 비교 결과 카드 생성
- 비교 카드 이미지 다운로드/공유
- 닉네임 입력 (선택)

### Phase 3: 그룹 비교 + 위클리 HOT

- 3인 이상 그룹 비교
- 매주 자동 큐레이션 "이번 주 HOT" 번들
- 그룹 내 소수파 하이라이트

### Phase 4: 고도화

- 비교 이력 저장 (로그인 시스템 도입 후)
- 푸시 알림 ("친구가 비교를 완료했어요!")
- 시즌별 번들 아카이브

## 12. 킬러 번들 후보 (론칭용)

론칭 시 바이럴을 터뜨릴 **첫 번째 번들** 선정이 중요.

### 후보 1: "연애 가치관 테스트" (추천 ⭐)

- **타겟**: 20~30대 연인, 썸 타는 사이
- **바이럴 포인트**: "우리 연애 케미 몇 %?" → 커플 사이에서 자연스러운 공유
- **시딩 카피**: "연인이랑 해봤는데 케미 40%... 이거 괜찮은 건가요? ㅋㅋ"

### 후보 2: "결혼 가치관 테스트"

- **타겟**: 30대 초반, 결혼 준비 중인 커플
- **바이럴 포인트**: 실질적인 가치관 차이 확인 → "결혼 전에 꼭 해봐야 하는 테스트"
- **시딩 카피**: "결혼 준비하면서 이거 해봤는데, 혼수 문제에서 갈라졌다 ㅋㅋ"

### 후보 3: "직장인 생존 테스트"

- **타겟**: 20~30대 직장인
- **바이럴 포인트**: 동료랑 비교 → 팀 내에서 자연 확산
- **시딩 카피**: "팀원이랑 해봤는데 칼퇴 문제에서 3:1로 갈렸다 ㅋㅋ"

> **론칭 전략**: 후보 1(연애)로 론칭 → 바이럴 검증 후 → 후보 2, 3 순차 오픈
