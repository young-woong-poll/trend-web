# Main 페이지 기획서

> 경로: `/`

---

## 1. 페이지 목적

진행 중인 트렌드 목록을 탐색하고, 관심 있는 트렌드를 선택하여 투표를 시작하는 진입점 페이지.

**핵심 가치:**

- "오늘 뭐가 핫하지?" 호기심 해소
- 다양한 트렌드 한눈에 탐색
- 쉽고 빠른 투표 진입

## 3. UI 컴포넌트 상세

### 3.1 MainHeader

| 요소   | 설명                            |
| ------ | ------------------------------- |
| 로고   | HotPick 로고 이미지             |
| 슬로건 | "오늘 대한민국은 이걸로 싸운다" |

**스타일:**

- 로고: 중앙 정렬 또는 좌측 배치
- 슬로건: 로고 하단, 서브 텍스트 스타일
- 배경: 다크 모드 블랙 (#121212)

---

### 3.2 PollCard (트렌드 카드)

각 트렌드를 대표하는 카드 컴포넌트.

#### 3.2.1 카드 구성 요소

| 요소               | 설명                           | 위치           |
| ------------------ | ------------------------------ | -------------- |
| 썸네일 이미지      | 2개 이미지 좌우 분할           | 카드 상단/배경 |
| NEW 배지           | 24시간 이내 생성된 트렌드 표시 | 좌측 상단      |
| 제목 (title)       | 트렌드 메인 제목               | 중앙 또는 하단 |
| 서브타이틀 (label) | 카테고리 또는 부가 설명        | 제목 하단      |
| 참여자 수          | 누적 참여자 카운트             | 하단 좌측      |
| 참여 버튼          | 투표 페이지 이동 유도          | 하단 우측      |

#### 3.2.2 썸네일 이미지

2개의 이미지를 좌우 분할하여 "대립" 느낌 연출.

```
┌─────────────┬─────────────┐
│             │             │
│   이미지 1   │   이미지 2   │
│  (선택지 A)  │  (선택지 B)  │
│             │             │
└─────────────┴─────────────┘
```

**이미지 처리:**

- 크기: 고정 비율 (예: 240x162px)
- 유효하지 않은 URL: placeholder 이미지로 대체
- 로딩 중: 스켈레톤 UI 표시

#### 3.2.3 NEW 배지

| 조건             | 표시                |
| ---------------- | ------------------- |
| 24시간 이내 생성 | 라임 그린 배지 표시 |
| 24시간 이후      | 배지 없음           |

**스타일:**

- 색상: 라임 그린 (#DFFF00)
- 위치: 카드 좌측 상단
- 텍스트: "NEW"

#### 3.2.4 참여자 수

| 형식           | 예시           |
| -------------- | -------------- |
| 1,000 미만     | "참여자 999"   |
| 1,000 이상     | "참여자 1.2K"  |
| 10,000 이상    | "참여자 12.3K" |
| 1,000,000 이상 | "참여자 1.2M"  |

#### 3.2.5 참여 버튼

| 상태 | 표시                     |
| ---- | ------------------------ |
| 기본 | "참여 →"                 |
| 호버 | 강조 색상 + 살짝 확대    |
| 클릭 | 로딩 애니메이션 (3개 점) |

### 3.3 PollCardSkeleton

카드 로딩 중 표시되는 스켈레톤 UI.

| 요소       | 스켈레톤                    |
| ---------- | --------------------------- |
| 썸네일     | 회색 박스 + 펄스 애니메이션 |

| 서브타이틀 | 가로 바 (60% 너비)          |
| 하단       | 가로 바 (40% 너비)          |

## 4. 트렌드 노출 순서

### 4.1 정렬 규칙

| 순서  | 유형                      | 설명                             |
| ----- | ------------------------- | -------------------------------- |
| 1순위 | 고정 트렌드 (fixedTrends) | 관리자가 상단 고정 설정한 트렌드 |
| 2순위 | 일반 트렌드 (trends)      | 생성일 기준 최신순               |

### 4.2 페이지네이션

| 항목      | 값                                 |
| --------- | ---------------------------------- |
| 초기 로드 | 20개                               |
| 추가 로드 | 20개씩                             |
| 방식      | 무한스크롤 (Intersection Observer) |

## 5. 사용자 플로우

### 5.1 기본 플로우

```
1. 메인 페이지 진입
   ↓
2. 트렌드 목록 확인
   ↓
3. 관심 있는 트렌드 카드 클릭
   ↓
4. Vote 페이지로 이동 (/vote/{alias})
```

### 5.2 무한스크롤 플로우

```
1. 초기 20개 트렌드 로드
   ↓
2. 하단으로 스크롤
   ↓
3. Intersection Observer 트리거
   ↓
4. 추가 20개 트렌드 로드
   ↓
5. 더 이상 트렌드 없으면 종료
```

## 10. 핵심 UX 원칙

1. **빠른 탐색**: 스크롤만으로 다양한 트렌드 확인
2. **시각적 대비**: 2개 이미지 분할로 "대결" 느낌 강조
3. **시의성 강조**: NEW 배지로 최신 콘텐츠 어필
4. **사회적 증거**: 참여자 수로 인기도 표시
5. **매끄러운 로딩**: 무한스크롤로 끊김 없는 탐색
