# Main 페이지 기획서

> 경로: `/`

---

## 1. 페이지 목적

진행 중인 트렌드와 Single를 탐색하고, 관심 있는 콘텐츠를 선택하여 투표를 시작하는 진입점 페이지.

**핵심 가치:**

- "오늘 뭐가 핫하지?" 호기심 해소
- 다양한 트렌드와 Single 한눈에 탐색
- 쉽고 빠른 투표 진입
- 탭으로 콘텐츠 유형별 맞춤 탐색

## 3. UI 컴포넌트 상세

### 3.0 MainTabNavigation (탭 네비게이션)

트렌드와 Single를 전환하는 상단 탭.

```
┌────────────────────────────────────┐
│  [ 트렌드 ]    [ ⚡Single ]        │
│  ─────────                         │  ← 활성 탭 하단 인디케이터
└────────────────────────────────────┘
```

| 요소       | 설명                                              |
| ---------- | ------------------------------------------------- |
| 트렌드 탭  | 기본 활성 탭, 기존 PollCard 목록 표시             |
| Single 탭  | ⚡ 아이콘 + "Single" 텍스트, SingleCard 목록 표시 |
| 인디케이터 | 활성 탭 하단에 2px 그라데이션 라인                |

**스타일:**

| 속성            | 활성 탭                                         | 비활성 탭                            |
| --------------- | ----------------------------------------------- | ------------------------------------ |
| 텍스트 색상     | white (#FFF)                                    | text-tertiary (#8A8A8A)              |
| 폰트            | text-base (16px) / font-bold (700)              | text-base (16px) / font-medium (500) |
| 하단 인디케이터 | 2px solid, primary-gradient (#ff00ff → #ff4500) | 없음                                 |
| 배경            | bg-primary (#121212)                            | bg-primary (#121212)                 |
| 높이            | 44px                                            | 44px                                 |

**인터랙션:**

| 동작          | 설명                                        |
| ------------- | ------------------------------------------- |
| 탭 클릭       | 해당 탭 콘텐츠로 즉시 전환                  |
| 좌우 스와이프 | 모바일에서 탭 간 전환 (0.3s ease)           |
| 인디케이터    | 탭 전환 시 슬라이드 애니메이션              |
| URL 동기화    | `/?tab=trend` (기본, 생략) / `/?tab=single` |

**Single 탭 상세 사항은 `06-single-page.md` 참조.**

### 3.2 PollCard (트렌드 탭 전용)

트렌드 탭에서 각 트렌드를 대표하는 카드 컴포넌트.

#### 3.2.1 카드 구성 요소

| 요소               | 설명                           | 위치           |
| ------------------ | ------------------------------ | -------------- |
| 썸네일 이미지      | 2개 이미지 좌우 분할           | 카드 상단/배경 |
| NEW 배지           | 24시간 이내 생성된 트렌드 표시 | 좌측 상단      |
| 제목 (title)       | 트렌드 메인 제목               | 중앙 또는 하단 |
| 서브타이틀 (label) | 카테고리 또는 부가 설명        | 제목 하단      |
| 참여자 수          | 누적 참여자 카운트             | 하단 좌측      |
| 참여 버튼          | 투표 페이지 이동 유도          | 하단 우측      |

#### 3.2.2 썸네일 이미지

2개의 이미지를 좌우 분할하여 "대립" 느낌 연출.

```
┌─────────────┬─────────────┐
│             │             │
│   이미지 1   │   이미지 2   │
│  (선택지 A)  │  (선택지 B)  │
│             │             │
└─────────────┴─────────────┘
```

**이미지 처리:**

- 크기: 고정 비율 (예: 240x162px)
- 유효하지 않은 URL: placeholder 이미지로 대체
- 로딩 중: 스켈레톤 UI 표시

#### 3.2.3 NEW 배지

| 조건             | 표시                |
| ---------------- | ------------------- |
| 24시간 이내 생성 | 라임 그린 배지 표시 |
| 24시간 이후      | 배지 없음           |

**스타일:**

- 색상: 라임 그린 (#DFFF00)
- 위치: 카드 좌측 상단
- 텍스트: "NEW"

#### 3.2.4 참여자 수

| 형식           | 예시           |
| -------------- | -------------- |
| 1,000 미만     | "참여자 999"   |
| 1,000 이상     | "참여자 1.2K"  |
| 10,000 이상    | "참여자 12.3K" |
| 1,000,000 이상 | "참여자 1.2M"  |

#### 3.2.5 참여 버튼

| 상태 | 표시                     |
| ---- | ------------------------ |
| 기본 | "참여 →"                 |
| 호버 | 강조 색상 + 살짝 확대    |
| 클릭 | 로딩 애니메이션 (3개 점) |

## 4. 콘텐츠 노출 순서

### 4.1 트렌드 탭 정렬 규칙

| 순서  | 유형                      | 설명                             |
| ----- | ------------------------- | -------------------------------- |

### 4.2 Single 탭 정렬 규칙

| 순서 | 기본 정렬          | 설명                    |
| ---- | ------------------ | ----------------------- |
| 기본 | 최신순 (createdAt) | 최근 생성된 Single 우선 |

> Single 탭의 정렬/필터 상세 사항은 `06-single-page.md` 섹션 10 참조.

### 4.3 페이지네이션

| 항목       | 트렌드 탭                          | Single 탭                          |

| 추가 로드  | 20개씩                             | 20개씩                             |

## 5. 사용자 플로우

### 5.1 트렌드 플로우 (기본)

```
1. 메인 페이지 진입 (트렌드 탭 기본 활성)
   ↓
2. 트렌드 목록 확인
   ↓
3. 관심 있는 트렌드 카드 클릭
   ↓
4. Vote 페이지로 이동 (/vote/{alias})
```

### 5.2 Single 플로우

```
1. 메인 페이지 상단 탭에서 "⚡Single" 탭 선택
   ↓
2. Single 목록 확인
   ↓
3. 관심 있는 Single 카드 클릭
   ↓
4. Single 전용 페이지로 이동 (/single/{alias})
```

### 5.3 무한스크롤 플로우 (양 탭 공통)

```
1. 초기 20개 콘텐츠 로드
   ↓
2. 하단으로 스크롤
   ↓
3. Intersection Observer 트리거
   ↓
4. 추가 20개 콘텐츠 로드
   ↓
5. 더 이상 콘텐츠 없으면 종료
```

## 10. 핵심 UX 원칙

1. **빠른 탐색**: 스크롤만으로 다양한 콘텐츠 확인
2. **시각적 대비**: 2개 이미지 분할로 "대결" 느낌 강조 (트렌드)
3. **시의성 강조**: NEW 배지로 최신 콘텐츠 어필
4. **사회적 증거**: 참여자 수로 인기도 표시
5. **매끄러운 로딩**: 무한스크롤로 끊김 없는 탐색
6. **탭으로 명확한 선택**: 트렌드(5개 묶음, 깊이 있는 참여)와 Single(단일, 빠른 참여)를 분리하여 사용자 의도에 맞는 경험 제공
