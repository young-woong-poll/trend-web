### 2-1. UUID localStorage 키 변경

| 항목            | 현재               | 변경 후               |
| --------------- | ------------------ | --------------------- |
| localStorage 키 | `tkuid`            | `hp_tkuid`            |
| 유틸 함수       | `getTKUID()`       | 동일 (내부 키만 변경) |
| 구현 파일       | `src/lib/tkuid.ts` | 동일                  |

**작업 내용:**

### 2-6. UUID를 API 요청 헤더에 포함

**결정:** 기존 댓글 좋아요 패턴과 동일하게 `x-tku-id` 헤더로 전송

**근거:**

- `useCommentLike.ts`에서 이미 `headers: { 'x-tku-id': tkuId }` 패턴 사용 중
- `services/api/comment.ts`, `services/api/display.ts`에서도 동일 패턴
- 쿼리 파라미터 대비 헤더 방식이 RESTful하고, URL 노출을 방지

| API                        | 현재      | 변경 후                      |
| -------------------------- | --------- | ---------------------------- |
| `GET /api/v1/display/main` | 헤더 없음 | `x-tku-id: {uuid}` 헤더 추가 |
| 싱글 투표 API              | —         | `x-tku-id: {uuid}` 헤더 추가 |

**작업 내용:**

- `useInfiniteMainDisplay` 훅에서 `x-tku-id` 헤더 자동 포함
- 싱글 투표 API 호출 시에도 동일 헤더 포함
- BE 요청서에 헤더 기반 UUID 수신 요구사항 추가

**우선순위:** 높음

## 3. 미구현 (신규 개발 필요)

### 3-1. [핵심] 싱글 핫픽 인라인 투표 — 상세페이지 완전 대체

**결정:** 현재 상세페이지 방식을 완전히 대체한다.

**스펙 요구사항:**

> 싱글 핫픽은 상세페이지 없이 메인피드 카드 안에서 투표 → 결과 확인이 완료된다.

**현재 구현:**

> SingleCard 클릭 → `/hotpick/{alias}` 상세페이지 이동 → VoteCard에서 투표

**필요 작업:**

| #   | 작업                         | 설명                                                            |
| --- | ---------------------------- | --------------------------------------------------------------- |
| 1   | SingleCard 컴포넌트 리디자인 | 카드 내에 A/B 선택 버튼 추가 (투표 전 상태)                     |
| 2   | 인라인 투표 결과 UI          | 같은 카드 안에서 퍼센티지 바로 전환 (투표 후 상태)              |
| 3   | 투표 API 연동                | 카드에서 직접 투표 API 호출 (`x-tku-id` 헤더) + 낙관적 업데이트 |
| 4   | 상태 전환 애니메이션         | Framer Motion으로 버튼 → 퍼센티지 바 모핑 (700ms)               |
| 5   | 기투표 상태 처리             | 서버 `voted` 응답 기반으로 카드 초기 상태 결정                  |
| 6   | 상세페이지 라우트 정리       | 싱글 타입의 `/hotpick/{alias}` 라우트 제거 또는 리다이렉트      |

**영향 범위:**

- `SingleCard.tsx` — 완전 리작성
- `SingleView.tsx` — 투표 상태 관리 추가
- `useDisplay.ts` — `x-tku-id` 헤더 추가
- 신규 훅: `useSingleVote.ts` (인라인 투표 처리)
- `src/app/hotpick/[hotpickAlias]/page.tsx` — 싱글 타입 리다이렉트 처리

**BE 요청:** 싱글 투표 전용 API 또는 기존 API 확장 (→ 요청서에 반영)

**우선순위:** 최고

## 5. 권장 구현 순서

### Phase 1: 인프라 + 핵심 기능 (인라인 투표)

1. `framer-motion` 패키지 설치
2. `hp_tkuid` 키 마이그레이션
3. BE 요청: 싱글 투표 API + 피드 기투표 응답
4. SingleCard 리디자인 (투표 전/후 상태, Framer Motion 애니메이션)
5. 인라인 투표 로직 + 낙관적 업데이트
6. 상세페이지 라우트 정리 (싱글 → 리다이렉트)

### Phase 2: 공유 & 해시 스크롤

1. BE 요청: `anchor` 파라미터 + 응답 확장
2. 토스트 알림 컴포넌트
3. 카드에 공유 버튼 + 해시 링크 복사
4. 해시 감지 + Anchor API 연동
5. 스크롤 이동 + Framer Motion 하이라이트
6. 양방향 무한 스크롤
