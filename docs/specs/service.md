# HotPick 서비스 정의

> 최종 업데이트: 2026-03-14

## 서비스 정의

**서비스명:** 핫픽 (HotPick)

**한 줄 요약:** 애매한 고민을 대중 투표로 해결하는 실용 도구형 플랫폼

**슬로건:** "애매하면 핫픽"

**핵심 가치:** 탭 한 번, 1초 투표 / 수천 명의 정량적 대중 의견 / 3초 안에 고를 수 있는 직관적 콘텐츠

**타겟:** 트렌드에 민감한 20-40대 한국 청년, 모바일 우선

---

## 콘텐츠 타입

### 싱글 핫픽 (Single) — 리텐션 엔진

- 메인 피드에서 바로 투표 가능한 개별 이지선다 (2~4개 선택지)
- 투표 즉시 퍼센티지 바 결과 확인, 재투표 불가
- IMAGE (옵션별 이미지) 또는 TEXT (질문 옆 대표 이미지)

### 번들 핫픽 (Bundle) — 바이럴 엔진 ⚠️ 미구현

- 테마로 묶인 5개 이상 투표 세트, 완료 시 결과 카드 제공
- 결과 카드를 SNS에 공유 -> 새 유저 유입하는 바이럴 루프
- 현재 아이디어 단계, 상세 기획 및 BE 미구현

---

## 용어 사전

| 용어            | 정의                                                                            |
| --------------- | ------------------------------------------------------------------------------- |
| HotPick (핫픽)  | 콘텐츠 단위. SINGLE 또는 BUNDLE 타입                                            |
| Election (선거) | 서버 도메인에서의 투표 단위. 하나의 질문 + 선택지 세트                          |
| Election Item   | 투표 선택지. 2~4개                                                              |
| Slug            | 핫픽의 URL용 고유 식별자 (예: chicken-2024)                                     |
| VoteType        | FE에서 추론하는 표시 방식. IMAGE / TEXT                                         |
| TKUID           | 익명 사용자 식별용 UUID. localStorage `hp_tkuid`에 저장, `x-tku-id` 헤더로 전송 |
| TopComment      | 가장 좋아요가 많은 댓글. 피드 카드 하단 미리보기                                |

| 스타일링   | SCSS Modules                      |
