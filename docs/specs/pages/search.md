## 1. 개요

핫픽 서비스에 **검색 기능**을 추가한다. BE에서 Meilisearch + 데이터 임베딩을 통해 뉘앙스 검색(시맨틱 서치)까지 지원하며, FE에서는 빠르고 직관적인 검색 UX를 제공한다.

### 1.1 목적

- 사용자가 관심 있는 핫픽을 빠르게 찾을 수 있도록 한다
- 카테고리 브라우징 외에 **목적 기반 탐색** 경로를 제공한다
- 정확한 키워드 매칭뿐 아니라 **의미(뉘앙스) 기반 검색**을 지원한다

### 1.2 기술 스택

- **BE**: Meilisearch (오타 허용, 패싯 필터, 하이라이팅, <50ms 응답)
- **FE**: React Query + debounced input → search-as-you-type

## 2. 검색 진입점 (Entry Point)

### 2.1 반응형 검색 UI

참고: Polymarket, Kalshi와 동일한 반응형 UX

#### PC (tablet 이상, ≥768px)

`MainHeader`에 **검색 입력 필드(pill shape)** 표시

```
┌──────────────────────────────────────────────────┐
│ [Logo]    [🔍 핫픽 검색...              ]  태그라인 │
└──────────────────────────────────────────────────┘
```

- 검색창 클릭 시 → **검색 모달(드롭다운)** 등장 (페이지 이동 없음)
- 모달 바깥 클릭 또는 ESC로 닫기
- 검색어 입력 즉시 모달 내에서 결과 미리보기 표시

#### Mobile (<768px)

`MainHeader`에 **돋보기 아이콘만** 표시

```
┌─────────────────────────────────────┐
│ [Logo]  태그라인...        [🔍]     │
└─────────────────────────────────────┘
```

- 돋보기 탭 → **검색 전용 페이지(`/search`)로 이동**
- 풀스크린 검색 화면

│  결과 없음 시:                       │
│     🔍 검색 결과가 없어요            │

## 4. 검색 UX 스펙

### 4.1 검색 입력

| 항목          | 스펙                                               |
| ------------- | -------------------------------------------------- |
| 디바운스      | 300ms                                              |

| 검색어 삭제   | 입력 필드 우측 ✕ 버튼                              |
| 제출 방식     | search-as-you-type (엔터 불필요, 타이핑 즉시 검색) |
| ~~취소 버튼~~ | **제거** — 뒤로가기(←)와 ✕만 사용                  |

### 4.2 검색 결과 미리보기

| 항목         | 스펙                                                       |
| ------------ | ---------------------------------------------------------- |
| 트리거       | **2글자 이상** 입력 시                                     |
| 카드 UI      | **간소화 미리보기** (옵션 바 없음)                         |
| 표시 항목    | 썸네일, 카테고리, 제목(하이라이팅), 투표수, 댓글수, 공감수 |

### 4.5 Meilisearch 활용 기능

| 기능                           | FE 영향                                                  |
| ------------------------------ | -------------------------------------------------------- |
| **오타 허용** (Typo Tolerance) | 별도 처리 불필요, BE에서 자동                            |
| **뉘앙스 검색** (Semantic)     | 별도 처리 불필요, BE 임베딩으로 자동                     |
| **하이라이팅**                 | `_formatted` 필드의 `<em>` 태그를 attention color 렌더링 |
| **패싯 필터**                  | 카테고리 필터 chip에 각 카테고리별 결과 수 표시 가능     |
| **동의어**                     | BE 설정, FE 영향 없음                                    |

## 5. API 스펙 (BE 요청사항)

### 5.1 검색 API

```
GET /api/search?q={query}&category={slug}&sort={sort}&page={page}&size={size}
```

**Request Parameters:**

| 파라미터 | 타입   | 필수 | 설명                                                 |
| -------- | ------ | ---- | ---------------------------------------------------- |
| q        | string | O    | 검색어 (2~50자)                                      |
| category | string | X    | 카테고리 slug 필터                                   |
| sort     | enum   | X    | `relevance` / `newest` / `popular` (기본: relevance) |
| page     | number | X    | 페이지 번호 (기본: 0)                                |
| size     | number | X    | 페이지 크기 (기본: 20)                               |

**Response:**

## 6. 화면 상태 흐름

### Mobile (<768px)

```
[메인 피드] → 🔍 아이콘 탭 → [검색 페이지 /search]
                                    │
                                    ├── 최근 검색어 탭 → [미리보기 결과]
                                    ├── 키워드 2글자+ 입력 → [미리보기 결과]
                                    │                         │
                                    │                         ├── 결과 있음 → 간소화 카드 리스트
                                    │                         └── 결과 없음 → 빈 상태
                                    │
                                    └── ← 뒤로가기 → [메인 피드 복귀]
```

### PC (≥768px)

```
[메인 피드] → 검색창 클릭 → [검색 모달 (드롭다운)]
                                    │
                                    ├── 최근 검색어 탭 → [모달 내 미리보기]
                                    ├── 키워드 2글자+ 입력 → [모달 내 미리보기]
                                    │
                                    └── ESC / 바깥 클릭 → [모달 닫기]
```

- 검색 입력 필드: pill shape, 높이 36px
- 배경: `$bg-tertiary` (#2c2c2c)
- border-radius: `$border-rounded` (9999px)
- placeholder: "핫픽 검색", 좌측 돋보기 아이콘

#### Mobile (<768px)

- 색상: `$text-secondary`

### 7.5 검색 결과 미리보기 카드

- 카드 레이아웃: 좌측 썸네일(48×48, border-radius 8px) + 우측 정보
- 카테고리: `$text-tertiary`, 12px
- 제목: `$white`, 14px, font-weight: 600, 하이라이팅 `<em>` → `$attention` 색상

### 7.6 검색 모달 (PC)

- 너비: 검색 입력 필드와 동일 너비 (min 400px)
- max-height: 480px, overflow-y: auto
- 배경: `$bg-secondary` (#1e1e1e)
- border-radius: `$border-radius-lg` (12px)
- box-shadow: `$shadow-lg`
- backdrop: 반투명 검정 오버레이

### 7.7 빈 결과

- 아이콘: 돋보기 64px, `$text-tertiary` 색상
- 제목: `$white`, 18px, font-weight: 600
- 설명: `$text-tertiary`, 14px

## 8. 접근성

- 검색 입력 필드: `role="searchbox"`, `aria-label="핫픽 검색"`
- 검색 결과 영역: `role="region"`, `aria-label="검색 결과"`
- 최근 검색어 삭제: `aria-label="검색어 '${keyword}' 삭제"`
- 키보드: ESC로 검색 모달/화면 닫기
- 로딩 상태: `aria-busy="true"` on results container
