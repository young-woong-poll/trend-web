## 1. 개요

핫픽 서비스에 **검색 기능**을 추가한다. BE에서 Meilisearch + 데이터 임베딩을 통해 뉘앙스 검색(시맨틱 서치)까지 지원하며, FE에서는 빠르고 직관적인 검색 UX를 제공한다.

### 1.1 목적

- 사용자가 관심 있는 핫픽을 빠르게 찾을 수 있도록 한다
- 카테고리 브라우징 외에 **목적 기반 탐색** 경로를 제공한다
- 정확한 키워드 매칭뿐 아니라 **의미(뉘앙스) 기반 검색**을 지원한다

### 1.2 기술 스택

- **BE**: Meilisearch (오타 허용, 패싯 필터, 하이라이팅, <50ms 응답)
- **FE**: React Query + debounced input → search-as-you-type

## 2. 검색 진입점 (Entry Point)

### 2.1 위치

`MainHeader` 우측에 **돋보기 아이콘 버튼** 추가

```
┌─────────────────────────────────────┐
│ [Logo]  태그라인...        [🔍]     │
└─────────────────────────────────────┘
```

### 2.2 동작

- 아이콘 탭 → **전체 화면 검색 오버레이** 진입
- 오버레이는 기존 메인 피드 위에 z-index로 올라감
- 뒤로가기(←) 또는 취소 버튼으로 닫기

## 4. 검색 UX 스펙

### 4.1 검색 입력

| 항목         | 스펙                                               |
| ------------ | -------------------------------------------------- |
| 디바운스     | 300ms                                              |
| 최소 글자 수 | 1자 (한글 특성상)                                  |
| 최대 글자 수 | 50자                                               |
| 자동 포커스  | 검색 화면 진입 시 자동 포커스 + 키보드 올라옴      |
| 검색어 삭제  | 입력 필드 우측 ✕ 버튼                              |
| 제출 방식    | search-as-you-type (엔터 불필요, 타이핑 즉시 검색) |

### 4.2 검색 결과

| 항목          | 스펙                                                           |
| ------------- | -------------------------------------------------------------- |
| 정렬 기본값   | 관련도순 (Meilisearch 기본 랭킹)                               |
| 정렬 옵션     | 관련도순 / 최신순 / 참여자순                                   |
| 페이지네이션  | 무한 스크롤 (기존 메인 피드와 동일)                            |
| 페이지 크기   | 20건                                                           |
| 하이라이팅    | 검색어 매칭 부분 `<mark>` 처리 (Meilisearch `_formatted` 활용) |
| 카테고리 필터 | 검색 결과 내 카테고리 패싯 필터 (선택 사항)                    |
| 결과 카드     | 기존 `SingleCard` 컴포넌트 재사용                              |

### 4.3 최근 검색어

| 항목      | 스펙                                  |
| --------- | ------------------------------------- |
| 저장 위치 | localStorage                          |
| 최대 개수 | 10개                                  |
| 중복 처리 | 동일 검색어 재검색 시 최상단으로 이동 |
| 삭제      | 개별 삭제(✕) + 전체 삭제              |
| 저장 시점 | 검색 결과 화면 진입 시 (빈 결과 제외) |

### 4.4 인기 검색어

| 항목        | 스펙                                |
| ----------- | ----------------------------------- |
| 데이터 소스 | BE API (`GET /api/search/trending`) |
| 개수        | 최대 10개                           |
| 갱신 주기   | 1시간 (BE 캐싱)                     |
| 표시 형식   | 순위 번호 + 검색어 텍스트           |
| 탭 동작     | 해당 검색어로 즉시 검색             |

### 4.5 Meilisearch 활용 기능

| 기능                           | FE 영향                                              |
| ------------------------------ | ---------------------------------------------------- |
| **오타 허용** (Typo Tolerance) | 별도 처리 불필요, BE에서 자동                        |
| **뉘앙스 검색** (Semantic)     | 별도 처리 불필요, BE 임베딩으로 자동                 |
| **하이라이팅**                 | `_formatted` 필드의 `<em>` 태그를 `<mark>`로 렌더링  |
| **패싯 필터**                  | 카테고리 필터 chip에 각 카테고리별 결과 수 표시 가능 |
| **동의어**                     | BE 설정, FE 영향 없음                                |

## 5. API 스펙 (BE 요청사항)

### 5.1 검색 API

```
GET /api/search?q={query}&category={slug}&sort={sort}&page={page}&size={size}
```

**Request Parameters:**

| 파라미터 | 타입   | 필수 | 설명                                                 |
| -------- | ------ | ---- | ---------------------------------------------------- |
| q        | string | O    | 검색어 (1~50자)                                      |
| category | string | X    | 카테고리 slug 필터                                   |
| sort     | enum   | X    | `relevance` / `newest` / `popular` (기본: relevance) |
| page     | number | X    | 페이지 번호 (기본: 0)                                |
| size     | number | X    | 페이지 크기 (기본: 20)                               |

**Response:**

```json
{
  "query": "대통령 탄핵",
  "totalCount": 12,
  "hotpicks": [
    {
      "hotpickId": 1,

      "type": "SINGLE",
      "election": {
        "title": "<em>대통령</em> <em>탄핵</em> 찬성 vs 반대",
        "totalVoteCount": 15234,
        "totalCommentCount": 892,
        "items": [...]
      },
      "categories": ["정치"],
      "status": "ACTIVE",
      "expiredAt": "2026-04-01T00:00:00Z",
      "likeCount": 342,

        "title": "<em>대통령</em> <em>탄핵</em> 찬성 vs 반대"
```

## 6. 화면 상태 흐름

```
[메인 피드] → 🔍 탭 → [검색 초기 화면]
                          │
                          ├── 최근 검색어 탭 → [검색 결과]
                          ├── 인기 검색어 탭 → [검색 결과]
                          ├── 키워드 입력 → [검색 결과]
                          │                    │
                          │                    ├── 결과 있음 → 카드 리스트 + 필터
                          │                    └── 결과 없음 → 빈 상태 + 추천
                          │
                          └── ← / 취소 → [메인 피드 복귀]
```

## 7. 디자인 스펙

### 7.1 검색 헤더

- 높이: 56px
- 배경: `$bg-primary` (#121212)
- 입력 필드 배경: `$bg-tertiary` (#2c2c2c)
- 입력 필드 border-radius: `$border-rounded` (9999px, pill shape)
- placeholder: "핫픽 검색" 색상 `$text-tertiary`
- 입력 텍스트: `$white`, 16px
- 뒤로가기/취소 버튼: `$text-secondary`

### 7.2 최근 검색어

- 리스트 아이템 높이: 44px
- 검색어 텍스트: `$text-secondary`, 14px
- 삭제 버튼(✕): `$text-tertiary`, 12px
- 섹션 헤더: `$text-tertiary`, 12px, font-weight: 600
- "전체 삭제" 버튼: `$text-tertiary`, 12px

### 7.3 인기 검색어

- 리스트 아이템 높이: 40px
- 순위 번호: `$primary-gradient` 텍스트 (1~3위), `$text-tertiary` (4위~)
- 검색어 텍스트: `$text-secondary`, 14px

### 7.4 검색 결과

- 결과 건수 표시: `$text-tertiary`, 12px
- 정렬 드롭다운: `$text-secondary`, 12px
- 카드: 기존 `SingleCard` 디자인 그대로
- 하이라이팅 `<mark>`: color `$attention` (#DFFF00), background 투명

### 7.5 빈 결과

- 아이콘: 돋보기 64px, `$text-tertiary` 색상
- 제목: `$white`, 18px, font-weight: 600
- 설명: `$text-tertiary`, 14px

## 8. 접근성

- 검색 입력 필드: `role="searchbox"`, `aria-label="핫픽 검색"`
- 검색 결과 영역: `role="region"`, `aria-label="검색 결과"`
- 최근 검색어 삭제: `aria-label="검색어 '${keyword}' 삭제"`
- 키보드: ESC로 검색 화면 닫기
- 로딩 상태: `aria-busy="true"` on results container

## 9. 라우팅

| 경로                             | 설명                           |
| -------------------------------- | ------------------------------ |
| `/search`                        | 검색 초기 화면                 |
| `/search?q=대통령`               | 검색 결과 화면 (URL 공유 가능) |
| `/search?q=대통령&category=정치` | 카테고리 필터 적용             |
| `/search?q=대통령&sort=newest`   | 정렬 적용                      |

> 별도 페이지(`/search`)로 구현하여 URL 공유 및 뒤로가기를 자연스럽게 지원한다.
> 모바일에서는 풀스크린처럼 보이지만, 실제로는 독립 라우트이다.
