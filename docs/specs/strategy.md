# HotPick 콘텐츠 & 성장 전략

> 최종 업데이트: 2026-03-14

## 1. 콘텐츠 가이드라인

### 좋은 싱글 핫픽의 기준 — "3초 룰"

1. **배경 설명 없이 상황이 그려져야 함**
   - ✅ "연인이 전 애인 사진 안 지우면?"
   - ❌ "3년 사귄 여자친구가 전 남친이랑 같은 동네 사는데..." (배경이 특수)
2. **선택지가 대등해야 함** — 50:50에 가까울 것 같은 주제가 가장 매력적
3. **결과가 궁금해야 함** — 80:20 예상 주제는 투표 동기가 약함

### 콘텐츠 3가지 층위

| 층위          | 역할                | 예시                                          |
| ------------- | ------------------- | --------------------------------------------- |
| 고민 해결형   | 리텐션 핵심 (70%)   | "퇴근 후 업무 카톡, 답장해야 할까요?"         |
| 논란/성향형   | 바이럴 포텐셜 (20%) | "연인이 전 애인 사진 안 지우면?"              |
| 시의성 이슈형 | 신규 유입용 (10%)   | "AI 때문에 내 직업이 없어질까 봐 불안한가요?" |

### 기피 기준

- 정치, 종교, 특정 집단 혐오로 이어질 수 있는 주제 금지
- 바이럴은 되지만 브랜드를 태워먹는 콘텐츠 차단

## 4. 성장 전략

### 바이럴 루프

```
번들 결과 카드 SNS 공유 → 친구가 번들 참여 → 싱글도 투표 → 리텐션 → 반복
```

### 초기 성장 우선순위

1. 킬러 번들 콘텐츠 1개에 올인
2. 커뮤니티 시딩 (이미지+워터마크, 직접 링크 금지)
3. 유입 유저 → 싱글 경험 동선 설계
4. SEO 병행

### 오프라인 마케팅 — "핫픽맨이 간다"

가면을 쓴 캐릭터가 22인치 태블릿으로 현장 투표를 받고, 숏폼 영상으로 배포.
장소 × 주제 매칭 (판교=카카오vs네이버, 강남=월세vs전세 등).
"다가가지 말고 끌어당겨라" 원칙 — 서 있기만 하고 호기심 유발.

## 6. 핵심 원칙

| 원칙                     | 설명                                                    |
| ------------------------ | ------------------------------------------------------- |
| 3초 룰                   | 모든 싱글 핫픽은 읽고 3초 안에 고를 수 있어야 함        |
| 숫자의 가치              | 수천 명의 정량적 데이터가 차별점                        |
| 싱글=리텐션, 번들=바이럴 | 역할 분리 후 각각 최적화                                |
| 데이터 정직성            | 더미 데이터 미사용. 투표 수치의 신뢰가 서비스 존재 이유 |
