# Vote 페이지 기획서

> 경로: `/vote/{trendAlias}`

---

## 1. 페이지 목적

5개의 이지선다 투표를 순차적으로 진행하며, 각 질문마다 즉시 결과를 확인할 수 있는 핵심 서비스 페이지.

**핵심 가치:**
- 빠른 의사결정 → 즉각적 피드백 → 다음 질문 → 반복
- "나만 이런 건가?" 궁금증 해소
- 댓글을 통한 의견 공유

---

## 2. 화면 구성

### 2.1 전체 레이아웃

```
┌────────────────────────────────────┐
│           VoteHeader               │  ← 트렌드 제목
├────────────────────────────────────┤
│           ProgressBar              │  ← 1/5, 2/5 ... 진행도
├────────────────────────────────────┤
│                                    │
│                                    │
│            VoteCard                │  ← 질문 + 선택지
│         (슬라이드 영역)              │
│                                    │
│                                    │
├────────────────────────────────────┤
│    [댓글]           [다음 →]       │  ← 하단 고정 버튼
└────────────────────────────────────┘
```

## 3. UI 컴포넌트 상세

### 3.1 VoteHeader

| 요소 | 설명 |
|------|------|
| 뒤로가기 버튼 | 클릭 시 Main 페이지로 이동 |
| 트렌드 제목 | 현재 트렌드의 title 표시 |

**예시:**
```
← 2024 최고의 치킨 브랜드
```

---

### 3.2 ProgressBar

현재 진행 상태를 시각적으로 표시.

| 상태 | 표시 |
|------|------|
| 완료된 질문 | 체크 아이콘 (✓) |
| 현재 질문 | 숫자 강조 |
| 남은 질문 | 비활성 상태 |

**예시 (3번째 질문 진행 중):**
```
[✓] [✓] [3] [ ] [ ]
```

---

### 3.3 VoteCard (핵심)

투표의 핵심 UI. 앞면/뒷면 두 상태를 가지며, 투표 시 3D Flip 애니메이션으로 전환.

#### 3.3.1 앞면 (투표 전)

| 요소 | 설명 |
|------|------|
| 질문 텍스트 | Item의 title (예: "바삭한 치킨 vs 촉촉한 치킨?") |
| 선택지 카드 | 2~4개의 VoteOptionCard 배열 |

**VoteOptionCard 구성:**
| 요소 | 설명 |
|------|------|
| 배경 이미지 | 선택지 대표 이미지 |
| 선택지 텍스트 | 옵션 제목 오버레이 |
| 탭 인터랙션 | 클릭 시 선택 처리 |

**예시:**
```
┌──────────────────────────────────┐
│     바삭한 치킨 vs 촉촉한 치킨?      │
├────────────────┬─────────────────┤
│                │                 │
│   [바삭 이미지]  │  [촉촉 이미지]   │
│                │                 │
│   바삭한 치킨    │   촉촉한 치킨    │
│                │                 │
└────────────────┴─────────────────┘
```

#### 3.3.2 뒷면 (투표 후)

투표 완료 후 카드가 뒤집히며 결과 표시.

| 요소 | 설명 |
|------|------|
| 질문 텍스트 | 동일 |
| 결과 표시 | 각 선택지별 득표율 + 투표 수 |
| 내 선택 강조 | 선택한 옵션에 시각적 강조 |

**VoteOptionCard (결과 상태) 구성:**
| 요소 | 설명 |
|------|------|
| 배경 이미지 | 동일 |
| 프로그레스 바 | 득표율 시각화 (너비로 표현) |
| 투표 수 | 해당 옵션 투표 카운트 (예: "125표") |
| 득표율 | 백분율 표시 (예: "45.2%") |
| 선택 표시 | 내가 선택한 옵션 강조 스타일 |

**예시:**
```
┌──────────────────────────────────┐
│     바삭한 치킨 vs 촉촉한 치킨?      │
├────────────────┬─────────────────┤
│  [바삭 이미지]   │  [촉촉 이미지]   │
│ ████████░░░░░  │ ░░░░░░████████  │
│ 45.2%  (125표) │ 54.8%  (152표)  │ ← 내 선택
│    바삭한 치킨   │   촉촉한 치킨 ✓  │
└────────────────┴─────────────────┘
```

---

### 3.4 하단 버튼 영역 (VoteBottomButtons)

화면 하단에 고정되는 액션 버튼 영역.

| 버튼 | 조건 | 동작 |
|------|------|------|
| 댓글 | 투표 완료 후 활성화 | 댓글 바텀시트 열기 |
| 다음 | 투표 완료 후 활성화 | 다음 Item으로 이동 |

**버튼 상태:**
| 상태 | 스타일 |
|------|--------|
| 비활성 (투표 전) | 흐린 색상, 클릭 불가 |
| 활성 (투표 후) | 강조 색상, 클릭 가능 |
| 로딩 중 | 3개 점 애니메이션 |

**마지막 질문 (5번째):**
- "다음" 버튼 클릭 시 자동으로 결과 제출
- Result 페이지로 이동

## 4. 사용자 플로우

### 4.1 기본 플로우

```
1. 페이지 진입
   ↓
2. 첫 번째 질문 표시 (1/5)
   ↓
3. 선택지 탭 → 카드 뒤집힘 → 결과 확인
   ↓
4. [선택] 댓글 보기/작성
   ↓
5. "다음" 버튼 탭 → 슬라이드 애니메이션
   ↓
6. 다음 질문 표시 (2/5)
   ↓
   ... (3~5번 반복)
   ↓
7. 마지막 질문 완료 → "완료" 탭
   ↓
8. 투표 결과 서버 제출
   ↓
9. Result 페이지 이동
```

### 4.2 상태 전환 조건

| 현재 상태 | 조건 | 다음 상태 |
|----------|------|----------|
| 투표 전 | 선택지 클릭 | 투표 완료 (카드 뒤집힘) |
| 투표 완료 | "다음" 클릭 | 다음 질문으로 슬라이드 |
| 마지막 질문 완료 | "완료" 클릭 | 결과 제출 → Result 이동 |

## 5. 댓글 기능 (CommentBottomSheet)

각 질문(Item)별로 독립적인 댓글 영역 존재.

### 5.1 바텀시트 구조

```
┌────────────────────────────────────┐
│ ─────  (드래그 핸들)                │
├────────────────────────────────────┤
│   [인기순]    [최신순]              │  ← 정렬 탭
├────────────────────────────────────┤
│                                    │
│   댓글 목록 (무한스크롤)              │
│                                    │
├────────────────────────────────────┤
│ [닉네임] [댓글 입력...] [전송]       │  ← 댓글 작성
└────────────────────────────────────┘
```

### 5.2 댓글 목록

| 요소 | 설명 |
|------|------|
| 닉네임 | 댓글 작성자 (익명) |
| 내용 | 댓글 본문 |
| 좋아요 수 | 하트 아이콘 + 카운트 |
| 작성 시간 | 상대 시간 (예: "2시간 전") |
| 더보기 메뉴 | 수정/삭제 (비밀번호 인증) |

**정렬 옵션:**
| 정렬 | 기준 |
|------|------|
| 인기순 | 좋아요 수 높은 순 |
| 최신순 | 작성 시간 최신 순 |

### 5.3 댓글 작성

| 필드 | 설명 |
|------|------|
| 닉네임 | 최초 입력 시 모달 표시, 이후 자동 저장 |
| 비밀번호 | 수정/삭제 시 인증용 (숨김 처리) |
| 내용 | 댓글 본문 입력 |

**작성 후 동작:**
- 정렬을 "최신순"으로 자동 변경
- 스크롤을 맨 위로 이동 (내 댓글 확인)
- 토스트 메시지: "댓글이 등록되었습니다"

### 5.4 댓글 액션

| 액션 | 조건 | 동작 |
|------|------|------|
| 좋아요 | 로그인 불필요 | 카운트 +1 (중복 불가) |
| 수정 | 비밀번호 인증 | 수정 모달 열림 |
| 삭제 | 비밀번호 인증 | 삭제 확인 후 제거 |

## 6. 애니메이션

### 6.1 카드 뒤집기 (3D Flip)

- 트리거: 선택지 클릭
- 방향: Y축 기준 180도 회전
- 속도: 0.6초
- 이징: ease-in-out

### 6.2 카드 슬라이드

- 트리거: "다음" 버튼 클릭
- 방향: 좌측으로 슬라이드
- 속도: 0.3초
- 이징: ease-out

### 6.3 프로그레스 바 채워지기

- 트리거: 결과 표시 시
- 방향: 좌측에서 우측으로 너비 증가
- 속도: 0.5초 (카드 뒤집힌 후)
- 이징: ease-out

## 9. 핵심 UX 원칙

1. **즉각적 피드백**: 선택 즉시 결과 확인 (기다림 없음)
2. **진행감 제공**: ProgressBar로 현재 위치 명확히 인지
3. **몰입 유지**: 한 화면에 하나의 질문만 표시
4. **선택의 불가역성**: 한번 선택하면 변경 불가 (신중한 선택 유도)
5. **소셜 연결**: 댓글로 다른 참여자와 소통 가능
