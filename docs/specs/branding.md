# HotPick 브랜딩 전략

> **최종 업데이트**: 2026-03-01

브랜딩의 핵심 축: '바이럴과 비교' + '매주 업데이트되는 주기성(Retention 전략)'.

---

## 1. 브랜드 아이덴티티 (Brand Identity)

**브랜드명:** 핫픽 (HotPick)

**브랜드 에센스:**

- **Instant & Controversial (즉각적이고 논쟁적인):** 고민 없이 바로 선택해야 하는 직관적인 난제들.
- **Weekly Pulse (매주의 리듬):** 대한민국 트렌드의 최전선을 매주 확인하는 루틴.
- **Social Spark (관계의 불씨):** 친구들과의 대화와 논쟁을 점화시키는 불씨.

브랜드 페르소나:

"트렌드에 민감하고, 논쟁을 즐기며, 돌직구를 던지는 재치 있는 친구"

**타겟 오디언스에게 주고 싶은 이미지:**

- "이거 안 하면 이번 주 대화에 못 낌" (FOMO 자극)
- "짧게 즐기는 도파민 간식" (스낵 컬처)

## 2. 비주얼 아이덴티티 (Visual Identity)

"매주 뜨거워지는 논란의 중심"을 시각화합니다.

### 2.1 컬러 팔레트 (Color Palette)

강렬한 대비를 통해 긴급함과 트렌디함을 강조합니다.

- **Primary Color: 일렉트릭 마젠타 (Electric Magenta, #FF00FF) ~ 네온 오렌지 (Neon Orange, #FF4500) 그라데이션**
  - _의미:_ 단순한 'Hot(Red)'을 넘어선, 디지털 세계의 트렌디한 열기와 논란의 스파크를 상징합니다.
- **Secondary Color: 다크 모드 블랙 (Void Black, #121212)**
  - _의미:_ 콘텐츠(텍스트와 이미지)가 가장 돋보일 수 있는 배경이자 세련된 몰입감을 제공합니다.
- **Accent Color: 라임 그린 (Lime Punch, #DFFF00)**
  - _의미:_ 'NEW', '이번 주 업데이트' 등 새로움을 알리는 신호탄 색상으로 사용합니다.

### 2.2 로고 디자인 (Logo Design)

- **심볼 컨셉:** **'선택(Pick, Check)'**과 **'불꽃(Hot, Spark)'**의 결합.
- **형태:** 날렵하게 체크 표시(✓)를 하는 듯한 형상이 위로 솟구치며 불꽃 모양으로 마무리되는 역동적인 아이콘. 정적인 상태가 아니라 움직이는 찰나를 포착합니다.
- **워드마크 (Typography):**
  - 두껍고, 기울기(Italic)가 적용된 산세리프(Gothic) 폰트.
  - 속도감과 긴급함을 표현하기 위해 글자의 끝부분이 살짝 날카롭게 처리됨.

### 2.3 그래픽 모티프 & 이미지 스타일

- **핵심 모티프: "The Split (균열과 대립)"**
  - A와 B의 대결 구도를 보여줄 때, 단순한 직선 분할 대신 **번개가 치거나 땅이 갈라지는 듯한 사선/지그재그 형태의 분할선**을 사용합니다. 이는 양립할 수 없는 팽팽한 대립을 시각화합니다.
- **이미지 스타일: "High Contrast Meme Style"**
  - 고화질의 정제된 사진보다는, 거칠더라도 임팩트 있는 짤방(Meme) 스타일이나 고대비의 이미지를 사용합니다.
  - 텍스트가 이미지 위를 과감하게 덮는 잡지 표지 같은 레이아웃을 활용합니다.
- **주간 업데이트 강조 요소:**
  - 매주 업데이트되는 콘텐츠에는 라임 그린 컬러의 **[THIS WEEK'S HOTPICK]** 띠배너나 'NEW🔥' 뱃지를 반드시 부착하여 시의성을 강조합니다.

## 3. 브랜드 메시징 (Brand Messaging)

유저들의 행동(투표, 공유, 재방문)을 유도하는 강력한 언어적 장치입니다.

### 3.1 슬로건 (Tagline)

가장 직관적이고, 매주 방문해야 하는 이유를 담았습니다.

> 메인 슬로건:
>
> "이번 주 대한민국은 이걸로 싸운다, 핫픽"
>
> (This week, Korea is fighting over this. HotPick.)

> 서브 슬로건 (바이럴 강조):
>
> "너랑 나랑, 뇌 구조가 같을까? 핫픽"

### 3.2 현재 적용된 SEO/OG 문구

서비스에 실제 구현된 문구입니다. (`src/lib/seo/constants.ts`)

**타이틀:**

- 기본: "핫픽"
- OG: "애매하면? 핫픽"
- 상세 페이지 템플릿: `{투표 제목} | HotPick`

**설명(Description):**

- 메인: "애매하면? 핫픽 🔥 투표하고 사람들의 생각을 확인하세요!"
- OG/공유: "애매한 고민, 사람들의 생각을 확인하세요!"
- 구조화 데이터: "애매하면? 핫픽 — 투표하고 사람들의 생각을 확인하세요!"

**상세 페이지 OG:**

- description: `{선택지A} vs {선택지B} - 지금 바로 투표하세요!`
- 예: "지워야 한다 vs 상관없다 - 지금 바로 투표하세요!"

**키워드:**

핫픽, HotPick, 애매하면 핫픽, 트렌드 투표, 대중 투표, 이지선다, 밸런스 게임, A vs B, 대중 의견, 실시간 투표, 취향 테스트, 연애 투표, 직장인 투표, 논란

### 3.3 OG 이미지 (동적 생성)

Next.js `ImageResponse`를 활용한 동적 OG 이미지 생성:

- **메인 페이지**: 최신 핫픽 1개의 질문 + A/B 선택지를 카드 형태로 렌더링
  - IMAGE 타입: 옵션별 이미지 포함
  - TEXT 타입: 텍스트만 A/B 레이블로 표시
  - Footer: `{N}명 참여` + `투표하고 결과확인하기 →`
  - 폴백: 로고만 표시
  - 캐싱: `revalidate = 7200` (2시간)
- **상세 페이지**: 해당 핫픽의 질문 + A/B 선택지 동일 구조
  - 캐싱: `revalidate = false` (무기한, 투표 정보는 OG에 미포함)
- **디자인**: 다크 배경(#121212) + 카드(#1e1e1e) + A는 마젠타(#ff00ff), B는 오렌지(#ff4500)
- **폰트**: Noto Sans KR (Bold/Regular), 로컬 번들링

### 3.4 구조화 데이터 (JSON-LD)

- **메인 페이지**: `WebSite` + `ItemList` 스키마. 각 핫픽을 `Question`으로 마크업
- **상세 페이지**: `Question` + `suggestedAnswer` 스키마 (Google 리치 결과 대응)
  - 각 선택지를 `Answer`로, `upvoteCount` 포함
  - `interactionStatistic`으로 총 투표 수 표시

### 3.5 상황별 마이크로 카피 (Micro Copy)

서비스 곳곳에서 유저의 클릭을 유도하는 문구입니다.

**1) 메인 페이지 (주간 업데이트 강조)**

- [상단 배너] 🔥 **지금 막 도착한 따끈한 논란거리 (매주 수요일 업데이트!)**
- [카테고리 진입] "연애 난제: 이번 주는 좀 매운맛 🌶️"

**2) 투표 유도 (Action)**

- (기존 '투표하기' 대신) **"내 선택 픽(Pick)하기"**
- (A/B 선택지 사이) **"당신의 핫픽은?"**

**3) 결과 페이지 & 친구 초대 (Viral & Retention)**

- (결과 확인 후) **"나랑 같은 생각한 사람이 45%나? ㅋㅋㅋ"**
- (친구 공유 버튼) **"단톡방에 던져보기 (싸움 구경 꿀잼각🍿)"**
- (다음 주 예고) **"다음 주 난제 알림 받기 (놓치면 손해!)"**

## 4. 브랜딩 적용 예시 (Summary)

| **구분**     | **적용 내용**                                               | **비고**                  |
| ------------ | ----------------------------------------------------------- | ------------------------- |
| **서비스명** | **핫픽 (HotPick)**                                          | 입에 착 감기는 2음절      |
| **로고**     | 불꽃으로 변하는 체크마크(✓) 심볼 + 속도감 있는 볼드 타이포  | 앱 아이콘으로 활용 용이   |
| **컬러**     | 마젠타-오렌지 그라데이션 (Main) / 블랙 (BG) / 라임 (Accent) | 다크모드 기반 디자인 권장 |
| **슬로건**   | "이번 주 대한민국은 이걸로 싸운다, 핫픽"                    | 주기성 + 대립성 강조      |
| **UX 핵심**  | A vs B를 나누는 역동적인 'Split' 그래픽 모티프 활용         | 시각적 재미 부여          |

---

**전문가 코멘트:**

'핫픽'이라는 이름은 서비스의 본질(Hot한 주제를 Pick한다)을 아주 명확하게 보여줍니다. 이번 브랜딩은 이 직관적인 이름을 시각적, 언어적으로 강화하는 데 초점을 맞췄습니다.

특히 **"매주 업데이트된다"**는 새로운 제약조건은 서비스의 생명력을 불어넣는 핵심입니다. 따라서 모든 디자인 요소와 문구에서 "지금 아니면 못 본다", "이번 주가 지나면 쉰 떡밥이다"라는 식의 **'긴급함'과 '시의성'**을 강조하여 유저들이 매주 습관적으로 접속하도록 유도해야 합니다.

## 5. 실제 콘텐츠 예시

현재 `docs/contents/contents-mix.json`에 119개 콘텐츠가 준비되어 있으며, 아래는 카테고리별 대표 예시입니다.

### 5.1 연애 (love)

- "연인이 전 애인 사진 안 지우면?" — 지워야 한다 vs 상관없다
- "연인 핸드폰 비밀번호, 공유해야 할까요?" — 당연히 공유 vs 프라이버시 존중
- "연인이 이성 친구랑 둘이 밥 먹는 거, 괜찮아요?" — 괜찮다 vs 좀 그렇다
- "썸 탈 때 먼저 고백하는 거, 손해일까요?" — 먼저 하는 게 낫다 vs 상대가 먼저 하길 기다린다

### 5.2 재테크 (finance)

- "축의금은 얼마가 기본일까요? (26년 기준)" — 5만원 / 10만원 / 15만원 / 20만원
- "월급 300만원으로 서울에서 자취하면서 저축 가능할까요?" — 빡빡하지만 가능하다 vs 현실적으로 어렵다
- "30에 1억, 많이 모은건가요?" — 많이 모았다 vs 보통이다
- "주식 vs 부동산, 20대에 뭘 먼저 해야 할까요?" — 주식 / 부동산(청약) / 둘 다 아직 이르다

### 5.3 직장 (work)

- "퇴근 후 업무 카톡, 답장해야 할까요?" — 확인만 한다 / 바로 답장한다 / 다음 날 출근해서 한다
- "좋은 팀장 밑에 있는데 연봉이 낮으면, 옮겨야 할까요?" — 사람이 중요하다 vs 결국 돈이다
- "대기업 vs 스타트업, 첫 직장으로 어디가 나을까요?" — 대기업 / 스타트업 / 상관없다, 직무가 중요
- "주 4일제 되면 급여 줄어도 괜찮을까요?" — 줄어도 괜찮다 vs 급여 그대로여야 한다

### 5.4 트렌드 (trend)

- "짜장면 vs 짬뽕, 아직도 고민되죠?" — [IMAGE] 짜장면 vs 짬뽕
- "AI 때문에 내 직업이 없어질까 봐 불안한가요?" — 솔직히 불안하다 vs 별로 걱정 안 된다
- "2026년 지금, 한국 살기 좋다고 생각해요?" — 그래도 살기 좋다 vs 솔직히 힘들다
- "회식 때 소주 vs 맥주?" — [IMAGE] 소주 vs 맥주

### 5.5 인간관계 (relationship)

- "몇년만에 연락온 친구가 돈 빌려달라고 하면?" — 빌려준다 / 절대 안 빌려준다 / 금액에 따라 다르다
- "약속에 몇 분 늦는 게 용서 가능한가요?" — 5분 / 10분 / 15분 / 늦으면 안 된다
- "친구가 뒤에서 내 험담하는 거 알았으면?" — 직접 말한다 vs 조용히 거리둔다

### 5.6 결혼 (marriage)

- "결혼 전 동거, 해봐야 할까요?" — 해봐야 안다 vs 굳이 안 해도 된다
- "부모님이 강경하게 내 결혼 상대 반대하면?" — 설득이 안되면 결혼 못한다 vs 무시하고 결혼한다
- "맞벌이 부부, 집안일은 어떻게 나눠야 할까요?" — 완전 반반 / 수입 비율에 따라 / 잘하는 사람이 더 한다

### 5.7 생활 (life)

- "출퇴근 1시간 반 vs 월세 60만원 내고 회사 근처?" — 멀어도 아낀다 vs 돈 내고 가까이 산다
- "해외여행 중 한식 먹으러 가는 거, 이해돼요?" — [IMAGE] 당연하다 vs 현지 음식 먹어야지
- "카페에서 노트북 오래 쓰는 거, 눈치 보여야 할까요?" — 돈 냈으면 괜찮다 vs 2시간 이상은 좀 그렇다
