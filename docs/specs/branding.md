# HotPick 브랜딩

> 최종 업데이트: 2026-03-14

## 1. 브랜드 아이덴티티

**페르소나:** "트렌드에 민감하고, 논쟁을 즐기며, 돌직구를 던지는 재치 있는 친구"

**톤앤매너:**

- 활기찬 나이트클럽 느낌. 가볍지만 촌스럽지 않은 톤
- "궁금하다 → 확인한다 → 공유한다" 흐름
- 전투적 카피("싸운다") 지양

---

## 2. 비주얼 아이덴티티

### 컬러

- **Primary:** 마젠타(#FF00FF) → 오렌지(#FF4500) 그라디언트
- **Background:** 다크 블랙(#121212)
- **Accent:** 라임 그린(#DFFF00) — 'NEW', 업데이트 강조용

### 로고

- 불꽃 실루엣 안에 체크마크(✓)
- 두껍고 기울기 적용된 산세리프 워드마크
- 마젠타→오렌지 리니어 그라디언트

## 3. 메시징

### 슬로건

- **메인:** "애매하면 핫픽"
- **서브카피:** "투표하고, 대중의 생각을 확인하세요"

### SEO/OG 문구 (현재 적용)

| 위치    | 타이틀                 | 설명                                                  |
| ------- | ---------------------- | ----------------------------------------------------- |
| 메인    | 핫픽                   | 애매하면? 핫픽 — 투표하고 사람들의 생각을 확인하세요! |
| 메인 OG | 애매하면? 핫픽         | 애매한 고민, 사람들의 생각을 확인하세요!              |
| 상세    | {투표 제목} \| HotPick | {선택지A} vs {선택지B} - 지금 바로 투표하세요!        |

### OG 이미지 (동적 생성)

- 다크 배경(#121212) + 카드(#1e1e1e), A=마젠타, B=오렌지
- Footer: `{N}명 참여` + `투표하고 결과확인하기 →`
- 메인: `revalidate = 7200` (2시간) / 상세: `revalidate = false`
- 폰트: Noto Sans KR Bold/Regular

### 마이크로 카피

- 투표 유도: "내 선택 픽(Pick)하기" / "당신의 핫픽은?"
- 결과 후: "나랑 같은 생각한 사람이 45%나?"
- 공유: "단톡방에 던져보기"

## 4. 시딩/공유용 문구 후보

- **숫자 임팩트:** "10만 명이 갈렸던 그 질문, 너는 어느 쪽?"
- **FOMO:** "이미 2,400명이 답 정했는데, 너만 아직"
- **커뮤니티형:** "직장인 익명 커뮤니티 역대 1위 논쟁" (타사 브랜드명 미사용)
