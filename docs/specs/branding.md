# HotPick 브랜딩

> 최종 업데이트: 2026-03-30

## 1. 브랜드 아이덴티티

**페르소나:** "궁금증을 숫자로 풀어주는 재치 있는 친구"

**톤앤매너:**

- 호기심을 자극하는 톤. 가볍지만 신뢰감 있는
- "궁금하다 → 비교한다 → 공유한다" 흐름
- 핵심 동사: "비교하다" (이전: "투표하다")
- 전투적 카피("싸운다") 지양

---

## 2. 비주얼 아이덴티티

### 컬러

- **Primary:** 마젠타(#FF00FF) → 오렌지(#FF4500) 그라디언트
- **Background:** 다크 블랙(#121212)
- **Accent:** 라임 그린(#DFFF00) — 'NEW', 업데이트 강조용

### 로고

- 불꽃 실루엣 안에 체크마크(✓)
- 두껍고 기울기 적용된 산세리프 워드마크
- 마젠타→오렌지 리니어 그라디언트

## 3. 메시징

### 슬로건

- **메인:** "생각을 비교하다, 핫픽"
- **서브카피:** "대중의 생각부터 연인의 가치관까지"

### SEO/OG 문구 (현재 적용)

| 위치    | 타이틀                 | 설명                                                       |
| ------- | ---------------------- | ---------------------------------------------------------- |
| 메인    | 핫픽 - 생각을 비교하다 | 생각을 비교하다, 핫픽 🔥 대중의 생각부터 연인의 가치관까지 |
| 메인 OG | 핫픽 - 생각을 비교하다 | 대중의 생각부터 연인의 가치관까지, 숫자로 비교하세요       |
| 상세    | {투표 제목} \| HotPick | {선택지A} vs {선택지B} - 대중의 생각을 확인하세요          |

### OG 이미지 (동적 생성)

- 다크 배경(#121212) + 카드(#1e1e1e), A=마젠타, B=오렌지
- Footer: `{N}명 참여` + `비교하고 결과확인하기 →`
- 메인: `revalidate = 7200` (2시간) / 상세: `revalidate = false`
- 폰트: Noto Sans KR Bold/Regular

### 마이크로 카피

- 싱글 유도: "내 생각 비교하기" / "당신의 생각은?"
- 결과 후: "대중의 45%가 나와 같은 생각!"
- 공유: "친구 생각도 궁금하다면?"
- 번들 CTA: "우리 생각 비교해볼래?"
- 번들 초대: "{이름}님이 비교를 기다리고 있어요!"
- 번들 결과 공유: "우리 케미, 자랑해볼까?"

## 4. 시딩/공유용 문구 후보

- **숫자 임팩트:** "10만 명이 비교한 그 질문, 너의 답은?"
- **FOMO:** "이미 2,400명이 비교했는데, 너만 아직"
- **커플 시딩:** "커플 케미 테스트 해봤는데 40%... 이거 괜찮은 건가요?"
