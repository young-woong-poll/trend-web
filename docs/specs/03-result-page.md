# Result 페이지 기획서

> 경로: `/vote/{trendAlias}/result?id={resultId}`

---

## 1. 페이지 목적

투표 결과를 기반으로 사용자의 성향 유형을 분석하고, 바이럴 공유를 유도하는 페이지.

**핵심 가치:**
- "나는 어떤 유형일까?" 궁금증 해소
- 대중성 지수로 주류/비주류 여부 파악
- 친구에게 공유하여 비교 유도

---

## 2. 화면 구성

### 2.1 전체 레이아웃

```
┌────────────────────────────────────┐
│          ResultHeader              │  ← 트렌드 제목 + 홈 버튼
├────────────────────────────────────┤
│                                    │
│            TypeCard                │  ← 유형 이미지 + 설명
│                                    │
├────────────────────────────────────┤
│         대중성 지수 슬라이더          │
├────────────────────────────────────┤
│                                    │
│        MY PICK HISTORY             │  ← 5개 선택 결과
│                                    │
├────────────────────────────────────┤
│    [내 유형 자랑하기]                │  ← 공유 버튼
│    [투표 공유하기]                   │
├────────────────────────────────────┤
│       이전/다음 트렌드 추천           │  ← 추가 투표 유도
└────────────────────────────────────┘
```

## 3. UI 컴포넌트 상세

### 3.1 ResultHeader

| 요소 | 설명 |
|------|------|
| 트렌드 제목 | 현재 트렌드 title |
| 홈 버튼 | 클릭 시 Main 페이지로 이동 |

---

### 3.2 TypeCard (유형 카드)

사용자의 투표 성향에 따른 유형을 시각적으로 표현.

#### 3.2.1 유형 분류 로직

**기준:** 5개 투표 중 **50% 이상 득표율**을 기록한 선택지의 개수

| 개수 | 유형명 | 의미 |
|------|--------|------|
| 5개 | 명예 한국인 | 모든 선택이 다수파와 일치 |
| 4개 | 트렌드 레이더 | 대부분 대중적 취향 |
| 3개 | 옴므팜므 파탈 | 대중적이면서도 개성 있음 |
| 2개 | 소셜 카멜레온 | 유연한 취향 |
| 1개 | 한정판 유니크 | 독자적 취향 강함 |
| 0개 | 지구에 온 외계인 | 완전히 독특한 취향 |

#### 3.2.2 TypeCard 구성 요소

| 요소 | 설명 | 예시 |
|------|------|------|
| 유형 이미지 | 캐릭터 일러스트 | 왕관 쓴 캐릭터 (명예 한국인) |
| 유형명 | 분류된 유형 제목 | "명예 한국인" |
| 유형 설명 | 1줄 설명 문구 | "당신의 DNA에는 'K-국룰'이 흐르고 있군요!" |
| 해시태그 | 성격 키워드 2개 | #공감능력200% #인간빅데이터 |

**예시:**
```
┌────────────────────────────────────┐
│                                    │
│         [유형 일러스트]              │
│                                    │
│           명예 한국인                │
│                                    │
│  "당신의 DNA에는 'K-국룰'이           │
│   흐르고 있군요!"                    │
│                                    │
│   #공감능력200%  #인간빅데이터        │
│                                    │
└────────────────────────────────────┘
```

---

### 3.3 대중성 지수 슬라이더

내 선택이 얼마나 대중적인지 수치화하여 표시.

#### 3.3.1 계산 로직

```
대중성 지수 = (5개 선택지의 득표율 합계) / 5
```

**예시:**
- 1번 선택: 65% 득표
- 2번 선택: 42% 득표
- 3번 선택: 78% 득표
- 4번 선택: 55% 득표
- 5번 선택: 30% 득표
- **대중성 지수: (65+42+78+55+30)/5 = 54%**

#### 3.3.2 슬라이더 UI

```
개성 ◀───────────●────────────▶ 주류
0%              54%            100%
```

| 요소 | 설명 |
|------|------|
| 슬라이더 바 | 0~100% 범위 |
| 포인터 | 현재 대중성 지수 위치 |
| 좌측 라벨 | "개성" |
| 우측 라벨 | "주류" |
| 수치 표시 | 정확한 % 값 |
| 툴팁 (?) | "5개 투표에서 내가 선택한 옵션의 득표율 평균값" |

---

### 3.4 MY PICK HISTORY

5개 투표 결과를 리스트 형태로 표시.

#### 3.4.1 각 항목 구성

| 요소 | 설명 |
|------|------|
| 선택지 이미지 | 내가 선택한 옵션의 썸네일 (48x48px) |
| 질문 | Item의 title |
| 내 선택 | 선택한 Option의 title |
| 득표율 | 해당 선택지의 득표율 (%) |

**강조 표시:**
- 득표율 50% 초과: 강조 색상 (성공/주류)
- 득표율 50% 이하: 일반 색상

**예시:**
```
┌────────────────────────────────────┐
│ [이미지]  바삭한 치킨 vs 촉촉한 치킨?  │
│          촉촉한 치킨 선택            │
│                         54.8% ✓   │
├────────────────────────────────────┤
│ [이미지]  양념 vs 후라이드?           │
│          양념 선택                  │
│                         62.1% ✓   │
├────────────────────────────────────┤
│ [이미지]  무 vs 콜라?               │
│          무 선택                    │
│                         38.5%     │  ← 소수파
└────────────────────────────────────┘
```

### 3.5 공유 버튼 영역

바이럴을 위한 두 가지 공유 옵션 제공.

| 버튼 | 스타일 | 동작 | 복사 URL |
|------|--------|------|----------|
| 내 유형 자랑하기 | 그래디언트 (Primary) | 결과 페이지 URL 복사 | `/vote/{alias}/result?id={resultId}` |
| 투표 공유하기 | 아웃라인 (Secondary) | 투표 페이지 URL 복사 | `/vote/{alias}` |

**공유 완료 피드백:**
- 토스트 메시지: "링크가 복사되었습니다"

**의도:**
- "내 유형 자랑하기": 친구가 내 결과를 보고 자신도 해보고 싶게 유도
- "투표 공유하기": 친구가 바로 투표를 시작하도록 유도

---

### 3.6 추가 투표 유도 영역

다른 트렌드로 이동을 유도.

| 요소 | 설명 |
|------|------|
| 이전 트렌드 카드 | 이전 트렌드의 PollCard 미니 버전 |
| 다음 트렌드 카드 | 다음 트렌드의 PollCard 미니 버전 |
| "더 많은 투표 보기" | 클릭 시 Main 페이지로 이동 |

## 4. 사용자 플로우

### 4.1 기본 플로우

```
1. Vote 페이지에서 5개 투표 완료
   ↓
2. 결과 제출 → resultId 발급
   ↓
3. Result 페이지로 리다이렉트
   ↓
4. TypeCard로 유형 확인
   ↓
5. 대중성 지수 확인
   ↓
6. MY PICK HISTORY로 세부 결과 확인
   ↓
7. 공유 또는 다른 트렌드로 이동
```

### 4.2 공유 후 진입 플로우

친구가 공유 링크로 접속한 경우:

```
1. 결과 페이지 직접 접속 (링크 클릭)
   ↓
2. 친구의 TypeCard 및 결과 확인
   ↓
3. "나도 해보기" 또는 "투표하러 가기" 유도
   ↓
4. Vote 페이지로 이동
```

## 5. URL 구조

### 5.1 파라미터

| 파라미터 | 필수 | 설명 |
|----------|------|------|
| trendAlias | O | 트렌드 식별자 (경로) |
| id | O | 결과 고유 ID (쿼리스트링) |

**예시:**
```
/vote/chicken-2024/result?id=abc123def456
```

### 5.2 resultId 없이 접속한 경우

- Main 페이지(`/`)로 자동 리다이렉트
- 직접 투표를 완료해야 결과 확인 가능

## 7. 에러 처리

| 상황 | 대응 |
|------|------|
| resultId 없음 | Main 페이지로 리다이렉트 |
| 유효하지 않은 resultId | "결과를 찾을 수 없습니다" + 재투표 유도 |
| 결과 로딩 실패 | 에러 메시지 + 재시도 버튼 |

---

## 8. SEO / 메타데이터

공유 시 미리보기를 위한 메타 태그 설정.

| 메타 태그 | 내용 |
|----------|------|
| title | "나의 유형: {유형명} - {트렌드 제목}" |
| description | "{유형 설명}" |
| og:image | 유형별 캐릭터 이미지 또는 결과 카드 이미지 |
| og:type | website |

---

## 9. 핵심 UX 원칙

1. **성취감 제공**: 유형 분류로 투표 완료의 보상감
2. **비교 욕구 자극**: 대중성 지수로 "나는 주류인가, 비주류인가?" 궁금증 유발
3. **공유 간편화**: 원클릭 링크 복사로 SNS 공유 유도
4. **연속 참여 유도**: 다른 트렌드 카드 노출로 추가 투표 유도
5. **결과 보존**: resultId로 언제든 동일 결과 재확인 가능
