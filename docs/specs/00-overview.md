# HotPick 서비스 개요

## 1. 서비스 정의

**서비스명:** 핫픽 (HotPick)

**한 줄 요약:** 5개 이지선다 투표 묶음으로 구성된 바이럴 투표 플랫폼

**슬로건:** "오늘 대한민국은 이걸로 싸운다"

---

## 2. 타겟 사용자

| 항목      | 내용                                          |
| --------- | --------------------------------------------- |
| 주 타겟   | 20-40대 한국 남성                             |
| 디바이스  | 모바일 우선 (Mobile First)                    |
| 사용 맥락 | 가벼운 도파민 콘텐츠, 친구와 공유, SNS 바이럴 |

**타겟에게 주고 싶은 이미지:**

- "이거 안 하면 이번 주 대화에 못 낌" (FOMO 자극)
- "짧게 즐기는 도파민 간식" (스낵 컬처)

---

## 3. 브랜드 에센스

### 3.1 핵심 키워드

| 키워드                  | 의미                                          |
| ----------------------- | --------------------------------------------- |
| Instant & Controversial | 고민 없이 바로 선택해야 하는 직관적인 난제들  |
| Weekly Pulse            | 대한민국 트렌드의 최전선을 매주 확인하는 루틴 |
| Social Spark            | 친구들과의 대화와 논쟁을 점화시키는 불씨      |

### 3.2 브랜드 페르소나

> "트렌드에 민감하고, 논쟁을 즐기며, 돌직구를 던지는 재치 있는 친구"

---

## 4. 용어 정의

| 용어               | 정의                                                    | 예시                              |
| ------------------ | ------------------------------------------------------- | --------------------------------- |
| Trend (트렌드)     | 5개 투표 묶음 단위. 하나의 주제 아래 관련 질문들이 묶임 | "2024 최고의 치킨 브랜드"         |
| Item (아이템)      | 개별 투표 질문. 트렌드 내 5개 존재                      | "바삭한 치킨 vs 촉촉한 치킨?"     |
| Option (선택지)    | 투표 선택지. 보통 2~4개                                 | "바삭한 치킨", "촉촉한 치킨"      |
| Result Type (유형) | 투표 결과로 분류되는 6가지 성향                         | "명예 한국인", "지구에 온 외계인" |
| Alias              | 트렌드의 URL용 고유 식별자                              | chicken-2024                      |

## 5. 핵심 사용자 여정

```
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│  Main   │ ──▶ │  Vote   │ ──▶ │ Result  │ ──▶ │  공유   │
│ 트렌드  │     │ 5개     │     │ 유형    │     │ 또는    │
│ 목록    │     │ 순차    │     │ 확인    │     │ 재방문  │
│ 탐색    │     │ 투표    │     │         │     │         │
└─────────┘     └─────────┘     └─────────┘     └─────────┘
```

### 5.1 Main 페이지

- 탭 네비게이션으로 트렌드 / Shorts 전환
- 트렌드 탭: 진행 중인 트렌드 목록 탐색
- Shorts 탭: 단일 투표 Shorts 목록 탐색
- 관심 있는 콘텐츠 선택하여 투표 시작

### 5.2 Vote 페이지

- 5개 질문에 순차적으로 답변
- 각 질문마다 즉시 결과(득표율) 확인
- 댓글로 다른 참여자와 소통

### 5.3 Result 페이지

- 내 투표 성향에 따른 유형 확인
- 대중성 지수로 내 취향의 주류/비주류 파악
- SNS 공유를 통한 바이럴 유도

## 6. 6가지 결과 유형

투표 결과에서 **50% 이상 득표율**을 기록한 선택지의 개수에 따라 유형이 결정됨.

| 50% 이상 개수 | 유형명           | 설명                                        | 해시태그                    |
| ------------- | ---------------- | ------------------------------------------- | --------------------------- |
| 5개           | 명예 한국인      | 당신의 DNA에는 'K-국룰'이 흐르고 있군요!    | #공감능력200% #인간빅데이터 |
| 4개           | 트렌드 레이더    | 대세의 흐름을 본능적으로 감지하는 능력자!   | #눈치100단 #유행선도자      |
| 3개           | 옴므팜므 파탈    | 대중적인 듯하면서도 은근히 튀는 반전 매력!  | #밀당의고수 #치명적매력     |
| 2개           | 소셜 카멜레온    | 어떤 상황에도 맞출 수 있는 유연한 취향!     | #적응력만렙 #예측불가       |
| 1개           | 한정판 유니크    | 남들의 시선보다 내 심장 소리를 따르는 타입! | #확고한취향 #대체불가       |
| 0개           | 지구에 온 외계인 | 전 세계 1%만이 가진 아주 희귀한 취향 발견!  | #천재혹은바보 #레어아이템   |

## 7. 서비스 페이지 구성

| 페이지             | 경로                                 | 설명                                     |
| ------------------ | ------------------------------------ | ---------------------------------------- |
| Main               | `/`                                  | 트렌드 탭 + Shorts 탭, 무한스크롤        |
| Main (Shorts 탭)   | `/?tab=shorts`                       | Shorts 전용 탭                           |
| Shorts 전용        | `/shorts/{alias}`                    | 개별 Shorts 투표 페이지                  |
| Vote               | `/vote/{alias}`                      | 5개 투표 순차 진행                       |
| Result             | `/vote/{alias}/result?id={resultId}` | 투표 결과 및 유형 표시                   |
| Admin              | `/admin/trend`                       | 트렌드 관리 (개발환경 전용)              |
| Admin Trend Create | `/admin/trend/create`                | 트렌드 생성 (개발환경 전용)              |
| Admin Trend Edit   | `/admin/trend/edit`                  | 트렌드 수정 (개발환경 전용)              |
| Admin Shorts       | `/admin/shorts`                      | Shorts 관리 (개발환경 전용)              |

## 8. 콘텐츠 업데이트 전략

### 8.1 주간 업데이트 사이클

- 매주 새로운 트렌드 추가
- 시의성 있는 주제로 재방문 유도
- NEW 배지로 최신 콘텐츠 강조 (24시간 이내)

### 8.2 콘텐츠 특성

- 논쟁적이고 양극화된 주제
- 정답이 없는 취향/가치관 질문
- 친구와 비교하고 싶은 재미 요소

---

## 9. 핵심 기능 요약

| 기능           | 설명                                           |
| -------------- | ---------------------------------------------- |
| 5개 묶음 투표  | 하나의 주제에 5개 관련 질문 순차 진행          |
| 즉시 결과 확인 | 투표 직후 득표율 표시 (카드 뒤집기 애니메이션) |
| 성향 유형 분류 | 6가지 유형으로 사용자 성향 분석                |
| 대중성 지수    | 내 선택이 얼마나 대중적인지 수치화 (0~100%)    |
| 댓글 기능      | 각 투표별 익명 댓글, 좋아요                    |
| 공유 기능      | 내 유형 자랑하기 / 투표 공유하기               |
