## 전략 문서 템플릿

전략 모드에서 사용하는 PRD/방향성 문서 템플릿.

- 파일 경로: `docs/strategy/YYYY-MM-DD-<topic>.md`
- 한국어 문어체, 기존 기획서(`docs/specs/hotpick.md`) 톤 일치
- 이모지 금지

## 템플릿

```markdown

작성일: YYYY-MM-DD
작성자: 웅일 + 병훈
상태: 초안 / 검토중 / 확정 / 보류 / 폐기
관련 문서: docs/specs/..., docs/strategy/...
```

## 사용 가이드

- 비어있는 항목을 그대로 두지 않는다. 답이 안 나오면 "현재 미정 — 이유" 형태로 명시.
- 추측은 "**가설**" 라벨 명시. 검증 일정 함께.
- 변경이 생기면 "변경 이력"에 한 줄 추가.
- 6개월 뒤 이 문서를 처음 보는 사람이 결정의 맥락을 복원할 수 있어야 한다.
